Schnellbild: просмотрщик изображений и видеоплеер, которому не нужен импорт. Откройте папку, посмотрите миниатюры, откройте одно изображение крупно, листайте клавишами. Он остаётся быстрым и на больших папках, и на сетевых дисках.

ИЗОБРАЖЕНИЯ
• JPEG, HEIC, AVIF, JPEG XL, PNG, GIF, WebP, TIFF, PSD, OpenEXR, SVG, PDF и RAW-снимки камер, которые знает macOS
• Сетка, список и полноэкранный просмотр, слайд-шоу по всем подпапкам
• Масштаб, поворот, автоулучшение (экспозиция, контраст, насыщенность, резкость), только для просмотра: ваши файлы остаются как есть
• Сведения о файле с форматом, кодеками и битрейтом; предупреждение, если расширение файла не соответствует содержимому

ВИДЕО
• MP4 и MOV, а также форматы, которые macOS не воспроизводит: MKV, WebM, AVI, WMV, FLV, MPEG, DVD-видео, AVCHD
• Перематывайте видео стрелками, так же как листаете фото

АРХИВЫ КАК ПАПКИ
• ZIP, RAR и 7z открываются как папки, включая комиксы (CBZ, CBR), также с паролем и из нескольких частей
• Ничего не распаковывается на диск; видео воспроизводятся прямо из архива

СОРТИРОВКА В ДВУХ ПАНЕЛЯХ
• Две панели рядом с F-клавишами классического файлового менеджера: отметить, скопировать по F5, переместить по F6
• Переименование, новая папка, корзина, закладки, отмена
• Поиск по именам папок и файлов во всех подпапках

БЕЗОПАСНО С ЧУЖИМИ ФАЙЛАМИ
Schnellbild работает в App Sandbox от Apple: без сети, без других программ, только папки, которые вы ему открыли. Архивы только читаются, а «видео» не может отправить приложение в интернет.

Все клавиши на виду по F1, мини-клавиатура для щелчков по K. На 20 языках.
