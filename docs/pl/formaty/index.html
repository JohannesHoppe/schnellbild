Wszystkie formaty, które pokazuje Schnellbild

Schnellbild pokazuje 127 formatów z 146 rozszerzeniami plików. Obrazy przechodzą przez ImageIO, bibliotekę macOS, więc nowszy macOS czyta więcej; czego macOS nie czyta, Schnellbild dekoduje sam albo z LibRaw. Filmy, których macOS nie odtwarza, przechodzą przez wbudowany silnik VLC, a archiwa otwierają się jak foldery.
