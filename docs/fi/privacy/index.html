Tietosuojaseloste

Schnellbild on kuvien ja videoiden katseluohjelma macOS:lle. Tietosuoja-asetuksen (GDPR) mukainen rekisterinpitäjä on HAUS HOPPE - ITS, Johannes Hoppe; täydellinen osoite löytyy oikeudellisista tiedoista. Tämä seloste koskee ohjelmaa, sekä GitHubista ladattuna että Mac App Storesta ostettuna (molemmat ovat sama ohjelma), sekä tätä verkkosivustoa.

Ohjelma

Schnellbild ei kerää henkilötietoja. Siinä ei ole tiliä, analytiikkaa, mainontaa eikä seurantaa, eikä se ota yhteyttä internetiin: App Sandbox, jossa se toimii, ei anna sille lainkaan verkkoyhteyttä.

Nämä pysyvät Macillasi, eivätkä missään muualla:

  • Asetukset (viimeisin kansio, lajittelujärjestys, kirjanmerkit, äänenvoimakkuus …) ohjelman omissa asetuksissa.
  • Kansioiden käyttö: kansiot, jotka olet avannut Schnellbildille, macOS-kirjanmerkkeinä, jotta se voi näyttää ne uudelleen käynnistyksen jälkeen. Asetukset → Unohda kansioiden käyttö unohtaa ne.
  • Arkistojen salasanat, jotka olet kirjoittanut, kirjautumisavainnipussasi (kohde ”Schnellbild archive passwords”); Asetukset → Unohda tallennetut salasanat poistaa ne.
  • Miniatyyrit macOS:n omassa miniatyyrivälimuistissa.

Schnellbild lukee kuviasi, videoitasi ja arkistojasi vain näyttääkseen ne sinulle. Se ei koskaan lähetä niitä, niiden nimiä tai mitään niistä minnekään. Apple hoitaa latauksen ja oston oman tietosuojakäytäntönsä mukaisesti ja antaa meille vain lukuja ilman henkilöllisyyttäsi: myynnit sekä kaatumisraportit ja käyttötilastot, jos olet sallinut macOS:ssä niiden jakamisen appien kehittäjien kanssa.

Tämä verkkosivusto

Tämä verkkosivusto ei käytä evästeitä, analytiikkaa eikä muilta palvelimilta ladattavaa sisältöä (ei verkkofontteja, ei upotettuja videoita). Sitä ylläpidetään GitHub Pagesissa, joka on GitHub, Inc:n (Yhdysvallat) palvelu. Kun vierailet sivustolla, GitHub kirjaa ja tallentaa IP-osoitteesi turvallisuussyistä; katso GitHub Pages: data collection ja GitHubin tietosuojaseloste. Sen, kuinka kauan GitHub säilyttää näitä lokeja, päättää GitHub; meillä ei ole pääsyä niihin. GitHub osallistuu EU:n ja Yhdysvaltojen väliseen tietosuojakehykseen (EU-U.S. Data Privacy Framework), jonka osalta Euroopan komissio on todennut Yhdysvaltojen tarjoavan riittävän tietosuojan tason (tietosuoja-asetuksen 45 artikla). Käsittelyn oikeusperuste on oikeutettu etumme toimittaa verkkosivusto turvallisesti (tietosuoja-asetuksen 6 artiklan 1 kohdan f alakohta). Myös ohjelman lataus tulee GitHubista.

Oikeutesi

EU:n yleisen tietosuoja-asetuksen (GDPR) mukaan sinulla on oikeus saada pääsy tietoihin, oikaista ja poistaa ne, rajoittaa niiden käsittelyä ja siirtää ne järjestelmästä toiseen sekä oikeus tehdä valitus tietosuojavalvontaviranomaiselle. <strong>Sinulla on oikeus vastustaa</strong> oikeutettuun etuumme perustuvaa käsittelyä erityiseen tilanteeseesi liittyvällä perusteella (tietosuoja-asetuksen 21 artikla). Koska ohjelma ja tämä verkkosivusto eivät säilytä omia henkilötietoja, meillä ei yleensä ole mitään tarkistettavaa tai poistettavaa.
