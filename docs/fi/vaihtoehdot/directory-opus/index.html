Directory Opus Macille? Tässä on vaihtoehto

Schnellbild on ilmainen Mac-sovellus kansioidesi kuville ja videoille: avaa kansio, niin esikatselukuvat ovat heti esillä, ja yksi näppäin näyttää kuvan suurena. Se toistaa MKV-, AVI- ja WebM-videot, avaa ZIP- ja RAR-arkistot kuin kansiot ja toimii ilman tiliä ja ilman verkkoyhteyttä.

Schnellbild ohjelman Directory Opus tilalle?

Schnellbild ei ole tiedostonhallinta vaan kahden paneelin katseluohjelma: F5 kopioi ja F6 siirtää merkityt kuvat toiseen paneeliin, ja molemmat voi perua. Kaksi paneelia, funktionäppäimet ja lihasmuisti, joka on vanhempi kuin osa työkavereista. Sitten tuli Mac, eikä Directory Opus päässyt sisään.

Mistä ohjelman Directory Opus fanit pitävät ja miten se toimii Schnellbildissä

  • Selaus näppäimistöllä: Välilyönti avaa kuvan, ← → selaavat kansiota.
  • Selaa kansioita suoraan, ilman tuontia: Avaa kansio ⌘O:lla tai pudota se ikkunaan.
  • Miniatyyriruudukko kansioiden esikatseluineen: Kansiot näyttävät ensimmäiset kuvansa; kansiot ilman kuvia näkyvät himmeinä.
  • HEIC, AVIF, JPEG XL, WebP: macOS:n oman ImageIO:n kautta.
  • Kameran RAW: RAW-formaatit, jotka macOS tuntee, macOS:n kehittäminä.
  • Animoitu GIF, PNG, WebP: Ne toistuvat, ja niitä voi lähentää ja kiertää kuten muitakin kuvia.
  • Lähennä, panoroi, kierrä (vain näkymä): + − tai nipistys lähentää, ⌥← ⌥→ kiertää; tiedosto pysyy ennallaan.
  • ZIP, RAR, 7z aukeavat kuin kansiot: Aukeavat kuin kansiot, mitään ei pureta levylle.

Missä Directory Opus on yhä edellä

  • Valtava muokattavuus ja skriptaus
  • Kumoamisloki tiedostotoiminnoille
  • Merkinnät, arviot, tunnisteet, metatietojen muokkaus
  • Kuvamuunnin ja eränimeäminen
  • Kaksoiskappaleiden etsintä, synkronointi, Everything-integraatio
  • Diaesitys ristihäivytyksellä

Jätetty pois tarkoituksella

  • Äänitiedostot, musiikkitila: Vain kuvat ja videot; äänitiedostot aukeavat omassa apissaan.
  • Muokkaa kuvia (rajaus, koon muutos, tallennus): Näyttää kuvat muuttamatta niitä: tiedostosi pysyvät ennallaan.
  • Eräkäsittely: muunnos tai uudelleennimeäminen: Erämuunnokset ja eränimeämisen Schnellbild jättää muille ohjelmille.
  • Kirjasto, luettelointi, tunnisteet, arviot: Kansiot kirjaston sijaan: ei mitään tuotavaa.
  • Pilvisynkronointi, jakaminen verkossa: Ei koskaan mene verkkoon, periaatteesta.
