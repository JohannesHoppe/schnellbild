Path Finder: ilmainen vaihtoehto Macille

Schnellbild on ilmainen Mac-sovellus kansioidesi kuville ja videoille: avaa kansio, niin esikatselukuvat ovat heti esillä, ja yksi näppäin näyttää kuvan suurena. Se toistaa MKV-, AVI- ja WebM-videot, avaa ZIP- ja RAR-arkistot kuin kansiot ja toimii ilman tiliä ja ilman verkkoyhteyttä.

Schnellbild ohjelman Path Finder tilalle?

Schnellbild ei ole tiedostonhallinta vaan kahden paneelin katseluohjelma: F5 kopioi ja F6 siirtää merkityt kuvat toiseen paneeliin, ja molemmat voi perua. Schnellbild ja Path Finder rinnakkain: kumpi tekee mitäkin paremmin, ja sitten jokainen ominaisuus lähteineen.

Schnellbild ei ole täydellinen tiedostonhallinta: ei FTP-, SFTP- tai pilviyhteyksiä, ei kansioiden synkronointia, ei arkistojen pakkaamista. Se on tehty kuvien ja videoiden selaamiseen ja lajitteluun: miniatyyrit kaikesta, kaksi paneelia rinnakkain, F5 kopioi ja F6 siirtää, arkistot aukeavat kuin kansiot.

Missä Path Finder on vahvempi

  • Moduulit: esikatselu, tiedot, pääte, Drop Stack, Git, heksa- ja tekstieditori
  • Kokoselain sekä kansioiden synkronointi ja yhdistäminen
  • Eränimeäminen, turvallinen poisto, ylläpitäjän oikeudet
  • 20 käyttöliittymän kieltä
  • Kirjanmerkkipalkki, välilehtien esiasetukset

Missä Schnellbild on vahvempi

  • Ilmainen, kaikki ominaisuudet
  • ZIP, RAR, 7z aukeavat kuin kansiot
  • Sarjakuvat CBZ, CBR
  • Toistaa videot suoraan arkistosta
  • Diaesitys kaikista alikansioista, kuvat ja videot sekaisin
  • Automaattinen parannus ja liukusäätimet tiedostoa muuttamatta
  • Videoiden pikaselaus nuolinäppäimillä
