Бесплатная альтернатива YACReader для Mac

Schnellbild: бесплатное приложение для Mac для фото и видео в ваших папках. Открываете папку, и миниатюры уже на месте, одна клавиша показывает изображение крупно. Оно воспроизводит MKV, AVI и WebM, открывает архивы ZIP и RAR как папки и работает без учётной записи и без доступа к сети.

Schnellbild вместо YACReader?

Schnellbild открывает CBZ, CBR, ZIP, RAR и 7z как папки, ничего не распаковывая на диск, а страницы листаются стрелками. Schnellbild и YACReader рядом: что каждый делает лучше, а затем все функции с источниками.

Где сильнее YACReader

  • Полноценная библиотека комиксов: метаданные Comic Vine, списки чтения, смарт-списки, оценки
  • Сервер и приложения для iOS/Android с синхронизацией прогресса
  • Режим манги, разворот, непрерывная прокрутка для вебтунов
  • Яркость, контраст и гамма для старых сканов
  • 12 тем и редактор тем; переназначаемые клавиши
  • Версии для Windows и Linux

Где сильнее Schnellbild

  • Фото и видео вместе в одной сетке
  • Воспроизводит MKV, WebM, AVI, WMV, FLV
  • Воспроизводит видео прямо из архива
  • Две панели рядом (F5 копирует, F6 перемещает)
  • Слайд-шоу по всем подпапкам, фото и видео вперемешку
  • Перемотка видео стрелками
  • Никогда не выходит в сеть
