Бесплатная альтернатива qView для Mac

Schnellbild: бесплатное приложение для Mac для фото и видео в ваших папках. Открываете папку, и миниатюры уже на месте, одна клавиша показывает изображение крупно. Оно воспроизводит MKV, AVI и WebM, открывает архивы ZIP и RAR как папки и работает без учётной записи и без доступа к сети.

Скачать бесплатноSchnellbild.dmg Mac App Storeскоро, в поддержку проекта

Schnellbild вместо qView?

Schnellbild сразу открывает папку, без импорта, а изображения листаются стрелками: HEIC, RAW, PSD, анимированные GIF и PDF, а видео из папки в той же сетке. Schnellbild и qView рядом: что каждый делает лучше, а затем все функции с источниками.

Где сильнее qView

  • Предельно минималистичное окно без лишних элементов
  • Работает и в Windows и Linux, и на старых macOS (сборка legacy для 10.13+)
  • Покадровый просмотр анимации и выбор скорости
  • Открывает изображение прямо по URL

Где сильнее Schnellbild

  • Фото и видео вместе в одной сетке
  • Воспроизводит MKV, WebM, AVI, WMV, FLV
  • ZIP, RAR, 7z открываются как папки
  • Комиксы CBZ, CBR
  • Воспроизводит видео прямо из архива
  • Две панели рядом (F5 копирует, F6 перемещает)
  • Слайд-шоу по всем подпапкам, фото и видео вперемешку
