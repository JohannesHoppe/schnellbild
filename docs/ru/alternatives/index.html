Schnellbild как альтернатива

Schnellbild: альтернатива с чёткой позицией. Папки вместо плейлистов и медиатеки: откройте папку, и список уже готов, а слайд-шоу само составляет плейлист. Ничего из интернета, принципиально: ни учётной записи, ни слежки, ни сети вообще. И бесплатно, вместе со своими сочетаниями клавиш, за которые некоторые другие программы берут деньги.

Вот как он выглядит рядом с программами, которые ищут для Mac, с источником для каждой ячейки. Где другая программа лучше, так и написано.
