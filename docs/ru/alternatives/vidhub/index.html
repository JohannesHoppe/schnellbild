Бесплатная альтернатива VidHub для Mac

Schnellbild: бесплатное приложение для Mac для фото и видео в ваших папках. Открываете папку, и миниатюры уже на месте, одна клавиша показывает изображение крупно. Оно воспроизводит MKV, AVI и WebM, открывает архивы ZIP и RAR как папки и работает без учётной записи и без доступа к сети.

Schnellbild вместо VidHub?

Schnellbild не полноценный медиаплеер. Он показывает видео из папки миниатюрами рядом с фото, воспроизводит MKV, AVI и WebM, а стрелки перематывают видео на десятую часть. Schnellbild и VidHub рядом: что каждый делает лучше, а затем все функции с источниками.

Где сильнее VidHub

  • Медиатека фильмов и сериалов с постерами и метаданными
  • Синхронизация через iCloud между iPhone, iPad, Apple TV, Mac
  • Облачные диски, NAS, Emby/Jellyfin/Plex
  • Поиск субтитров в интернете
  • Трансляция через DLNA, Chromecast, Roku, AirPlay

Где сильнее Schnellbild

  • Фото и видео вместе в одной сетке
  • ZIP, RAR, 7z открываются как папки
  • Комиксы CBZ, CBR
  • Воспроизводит видео прямо из архива
  • Две панели рядом (F5 копирует, F6 перемещает)
  • Слайд-шоу по всем подпапкам, фото и видео вперемешку
  • Открытый исходный код
