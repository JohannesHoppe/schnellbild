Чем хорош Photo Mechanic

Photo Mechanic: быстрый инструмент для импорта, отбора и метаданных для профессиональных фотографов, особенно репортёров, спортивных и свадебных. Открывает папки и карты памяти напрямую, мгновенно показывает RAW по встроенным превью и превосходно справляется с подписями, метаданными IPTC, ключевыми словами, пакетным переименованием и загрузкой к дедлайну.

Где сильнее Photo Mechanic

  • Импорт с нескольких карт памяти сразу, с переименованием и метаданными при копировании
  • Метаданные IPTC/XMP, коды замены, переменные и структурированные ключевые слова для подписей к дедлайну
  • Звёздные оценки, цветовые классы и теги для быстрого отбора тысяч RAW
  • Пакетное переименование, «Сохранить как», размер, водяной знак и загрузка на FTP, Dropbox, S3, PhotoShelter и др.
  • Поиск и замена по регулярным выражениям в именах файлов и метаданных
  • Полностью настраиваемые клавиши с пресетами и PDF-шпаргалки для печати
  • Версия для Windows с тем же набором функций

Где сильнее Schnellbild

  • Бесплатно, все функции
  • ZIP, RAR, 7z открываются как папки
  • Комиксы CBZ, CBR
  • Воспроизводит видео прямо из архива
  • Две панели рядом (F5 копирует, F6 перемещает)
  • Автоулучшение и регуляторы без изменения файла
  • Перемотка видео стрелками
