Чем хорош Commander One

Двухпанельный файловый менеджер для macOS в духе Total Commander: работа с функциональными клавишами, поиск по регулярным выражениям, встроенный просмотрщик F3 (текст, hex, изображения, медиа) и работа с архивами. PRO Pack добавляет RAR/7z, FTP/SFTP, облачные диски, терминал и темы.

Schnellbild не полноценный файловый менеджер: нет FTP, SFTP и облачных подключений, нет синхронизации папок, он не упаковывает архивы. Он сделан, чтобы просматривать и сортировать фото и видео: миниатюры всего подряд, две панели рядом, F5 копирует, F6 перемещает, архивы открываются как папки.

Где сильнее Commander One

  • Классическая работа коммандера на F-клавишах и очередь операций
  • Поиск по regex и по содержимому, также в архивах и на FTP
  • PRO: FTP/SFTP и много облачных сервисов, устройства MTP/iOS/Android
  • Встроенный просмотр hex, текста и двоичных файлов
  • Просмотр процессов, терминал (PRO)

Где сильнее Schnellbild

  • Воспроизводит MKV, WebM, AVI, WMV, FLV
  • Комиксы CBZ, CBR
  • Слайд-шоу по всем подпапкам, фото и видео вперемешку
  • Автоулучшение и регуляторы без изменения файла
  • Перемотка видео стрелками
  • Отмена переименования, перемещения, удаления в Корзину
  • Открытый исходный код
