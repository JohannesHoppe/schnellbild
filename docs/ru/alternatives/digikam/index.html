Чем хорош digiKam

digiKam: полноценный пакет управления фото с открытым кодом от KDE для больших коллекций. Индексирует папки в базу данных и предлагает теги, распознавание лиц, геопривязку, поиск похожих, мощный редактор изображений, пакетную обработку и много направлений экспорта.

Где сильнее digiKam

  • База данных с тегами, метками, распознаванием лиц, поиском похожих и дубликатов, по карте и по времени
  • Поиск на естественном языке и расширенный поиск по всем коллекциям
  • Полноценный редактор и пакетная очередь с версиями
  • Обработка RAW через LibRaw, 16 бит и управление цветом
  • Скорость воспроизведения видео и переход по кадрам
  • Много направлений экспорта (Dropbox, OneDrive, Flickr, Piwigo, HTML-галереи) и DLNA
  • Бесплатно, открытый код, работает и в Linux и Windows

Где сильнее Schnellbild

  • ZIP, RAR, 7z открываются как папки
  • Комиксы CBZ, CBR
  • Воспроизводит видео прямо из архива
  • Перемотка видео стрелками
  • Никогда не выходит в сеть
