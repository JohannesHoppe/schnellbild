Бесплатная альтернатива Lyn для Mac

Schnellbild: бесплатное приложение для Mac для фото и видео в ваших папках. Открываете папку, и миниатюры уже на месте, одна клавиша показывает изображение крупно. Оно воспроизводит MKV, AVI и WebM, открывает архивы ZIP и RAR как папки и работает без учётной записи и без доступа к сети.

Schnellbild вместо Lyn?

Schnellbild сразу открывает папку, без импорта, а изображения листаются стрелками: HEIC, RAW, PSD, анимированные GIF и PDF, а видео из папки в той же сетке. Schnellbild и Lyn рядом: что каждый делает лучше, а затем все функции с источниками.

Где сильнее Lyn

  • Геотеги на карте
  • Неразрушающая правка цвета
  • Открывает медиатеки Фото, Aperture и Lightroom
  • Публикация во Flickr, Dropbox, SmugMug
  • Работает на старых macOS (10.13+)

Где сильнее Schnellbild

  • Бесплатно, все функции
  • Воспроизводит MKV, WebM, AVI, WMV, FLV
  • ZIP, RAR, 7z открываются как папки
  • Комиксы CBZ, CBR
  • Воспроизводит видео прямо из архива
  • Отмена переименования, перемещения, удаления в Корзину
  • Открытый исходный код
