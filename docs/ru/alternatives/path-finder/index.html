Чем хорош Path Finder

Давняя замена Finder с двумя панелями, модулями (просмотр, сведения, терминал, Drop Stack), анализом размеров, пакетным переименованием и синхронизацией папок. Хорош для опытных пользователей, которым нужно много инструментов вокруг браузера в духе Finder.

Schnellbild не полноценный файловый менеджер: нет FTP, SFTP и облачных подключений, нет синхронизации папок, он не упаковывает архивы. Он сделан, чтобы просматривать и сортировать фото и видео: миниатюры всего подряд, две панели рядом, F5 копирует, F6 перемещает, архивы открываются как папки.

Где сильнее Path Finder

  • Модули: просмотр, сведения, терминал, Drop Stack, Git, редактор hex и текста
  • Анализ размеров и синхронизация или слияние папок
  • Пакетное переименование, надёжное удаление, доступ администратора
  • 20 языков интерфейса
  • Панель закладок, пресеты вкладок

Где сильнее Schnellbild

  • Бесплатно, все функции
  • ZIP, RAR, 7z открываются как папки
  • Комиксы CBZ, CBR
  • Воспроизводит видео прямо из архива
  • Слайд-шоу по всем подпапкам, фото и видео вперемешку
  • Автоулучшение и регуляторы без изменения файла
  • Перемотка видео стрелками
