Политика конфиденциальности

Schnellbild является просмотрщиком изображений и видео для macOS. Ответственным лицом (контролёром по смыслу GDPR) является HAUS HOPPE - ITS, Johannes Hoppe; полный адрес указан в разделе «Правовая информация». Эта политика распространяется на приложение, как загруженное с GitHub, так и купленное в Mac App Store (это одно и то же приложение), а также на этот сайт.

Приложение

Schnellbild не собирает персональные данные. В нём нет учётной записи, аналитики, рекламы и отслеживания, и оно не подключается к интернету: App Sandbox, в которой оно работает, вообще не даёт ему доступа к сети.

Что хранится на вашем Mac, и только там:

  • Настройки (последняя папка, порядок сортировки, закладки, громкость…) хранятся в собственных настройках приложения.
  • Доступ к папкам: папки, которые вы открыли для Schnellbild, в виде закладок macOS, чтобы после перезапуска он мог снова их показать. Настройки → Забыть доступ к папкам их забывает.
  • Пароли архивов, которые вы ввели, хранятся в вашей связке ключей входа (запись «Schnellbild archive passwords»); Настройки → Забыть сохранённые пароли их удаляет.
  • Миниатюры хранятся в собственном кэше миниатюр macOS.

Schnellbild читает ваши изображения, видео и архивы только для того, чтобы показать их вам. Он никогда и никуда не отправляет ни их самих, ни их имена, ни какие-либо сведения о них. Загрузку и покупку обеспечивает Apple в соответствии со своей политикой конфиденциальности и передаёт нам только цифры без сведений о вашей личности: продажи, а также отчёты о сбоях и статистику использования, если вы разрешили в macOS делиться ими с разработчиками приложений.

Этот сайт

Этот сайт не использует файлы cookie, аналитику и контент с других серверов (никаких веб-шрифтов, никаких встроенных видео). Он размещён на GitHub Pages, сервисе компании GitHub, Inc. (США). При посещении сайта GitHub в целях безопасности записывает и хранит ваш IP-адрес; см. GitHub Pages: сбор данных и Заявление GitHub о конфиденциальности (на английском). Как долго GitHub хранит эти журналы, решает GitHub; у нас нет к ним доступа. GitHub участвует в EU-U.S. Data Privacy Framework, рамочной программе, в отношении которой Европейская комиссия признала, что США обеспечивают надлежащий уровень защиты (ст. 45 GDPR). Правовым основанием служит наш законный интерес в безопасной доставке сайта (подп. «f» п. 1 ст. 6 Общего регламента ЕС по защите данных, GDPR). Приложение тоже загружается с GitHub.

Ваши права

Согласно GDPR вы имеете право на доступ к данным, их исправление, удаление, ограничение обработки и переносимость данных, а также право подать жалобу в надзорный орган по защите данных. Вы вправе возразить по причинам, связанным с вашей конкретной ситуацией, против обработки на основании нашего законного интереса (ст. 21 GDPR). Поскольку ни приложение, ни этот сайт не хранят собственных персональных данных, с нашей стороны проверять или удалять совершенно нечего. Поэтому ответ на запрос о доступе будет очень коротким: мы ничего о вас не знаем.
