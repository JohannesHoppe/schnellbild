Gizlilik politikası

Schnellbild, HAUS HOPPE - ITS (Johannes Hoppe) tarafından geliştirilen, macOS için bir görüntü ve video görüntüleyicidir; tam adres künyede yer alır. Bu politika, GitHub’dan indirilen ve Mac App Store’dan satın alınan uygulamayı (ikisi de aynı uygulamadır) ve bu web sitesini kapsar.

Uygulama

Schnellbild hiçbir kişisel veri toplamaz. Hesap, analiz, reklam veya izleme içermez ve internete bağlanmaz: İçinde çalıştığı App Sandbox ona hiçbir ağ erişimi vermez.

Mac’inizde, yalnızca orada kalanlar:

  • Ayarlar (son klasör, sıralama düzeni, yer işaretleri, ses düzeyi …) uygulamanın kendi tercihlerinde.
  • Klasör erişimi: Schnellbild’e açtığınız klasörler, yeniden başlatmadan sonra onları tekrar gösterebilmesi için macOS yer işaretleri olarak. Ayarlar → Klasör erişimi bunları unutur.
  • Girdiğiniz arşiv parolaları, giriş anahtar zincirinizde (“Schnellbild archive passwords” kaydı); Ayarlar → Kayıtlı parolaları unut bunları siler.
  • Küçük resimler, macOS’in kendi küçük resim önbelleğinde.

Schnellbild resimlerinizi, videolarınızı ve arşivlerinizi yalnızca size göstermek için okur. Onları, adlarını veya onlarla ilgili herhangi bir şeyi asla hiçbir yere göndermez. Apple, indirme veya satın alma hakkında kendi gizlilik politikası kapsamında veri toplayabilir; Schnellbild bunların hiçbirini almaz.

Bu web sitesi

Bu web sitesi çerez, analiz veya başka sunuculardan içerik (web yazı tipleri, gömülü videolar) kullanmaz. GitHub, Inc. (ABD) hizmeti olan GitHub Pages üzerinde barındırılır. Siteyi ziyaret ettiğinizde GitHub, güvenlik amacıyla IP adresinizi kaydeder; bkz. GitHub Pages: data collection ve GitHub gizlilik bildirimi. Hukuki dayanak, web sitesini güvenli bir şekilde sunmaya yönelik meşru menfaatimizdir (GDPR md. 6/1-f). Uygulamanın indirilmesi de GitHub üzerinden gerçekleşir.

Haklarınız

AB Genel Veri Koruma Tüzüğü (GDPR) kapsamında erişim, düzeltme, silme, işlemenin kısıtlanması, veri taşınabilirliği ve itiraz haklarına ve bir veri koruma denetim makamına şikâyette bulunma hakkına sahipsiniz. Ne uygulama ne de bu web sitesi kendine ait kişisel veri tutmadığından, genellikle bizim tarafımızda bakılacak veya silinecek bir şey yoktur.
