Gizlilik politikası

Schnellbild, macOS için bir görüntü ve video görüntüleyicidir. GDPR kapsamında veri sorumlusu HAUS HOPPE - ITS, Johannes Hoppe’dir; tam adres künyede yer alır. Bu politika, GitHub’dan indirilen ve Mac App Store’dan satın alınan uygulamayı (ikisi de aynı uygulamadır) ve bu web sitesini kapsar.

Uygulama

Schnellbild hiçbir kişisel veri toplamaz. Hesap, analiz, reklam veya izleme içermez ve internete bağlanmaz: İçinde çalıştığı App Sandbox ona hiçbir ağ erişimi vermez.

Mac’inizde, yalnızca orada kalanlar:

  • Ayarlar (son klasör, sıralama düzeni, yer işaretleri, ses düzeyi …) uygulamanın kendi tercihlerinde.
  • Klasör erişimi: Schnellbild’e açtığınız klasörler, yeniden başlatmadan sonra onları tekrar gösterebilmesi için macOS yer işaretleri olarak. Ayarlar → Klasör Erişimini Unut bunları unutur.
  • Girdiğiniz arşiv parolaları, giriş anahtar zincirinizde (“Schnellbild archive passwords” kaydı); Ayarlar → Kayıtlı parolaları unut bunları siler.
  • Küçük resimler, macOS’in kendi küçük resim önbelleğinde.

Schnellbild resimlerinizi, videolarınızı ve arşivlerinizi yalnızca size göstermek için okur. Onları, adlarını veya onlarla ilgili herhangi bir şeyi asla hiçbir yere göndermez. İndirme ve satın alma işlemlerini Apple kendi gizlilik politikası kapsamında yürütür ve bize yalnızca kimliğinizi içermeyen rakamlar iletir: satışlar ve macOS’ta uygulama geliştiricileriyle paylaşılmasına izin verdiyseniz çökme raporları ile kullanım istatistikleri.

Bu web sitesi

Bu web sitesi çerez, analiz veya başka sunuculardan içerik (web yazı tipleri, gömülü videolar) kullanmaz. GitHub, Inc. (ABD) hizmeti olan GitHub Pages üzerinde barındırılır. Siteyi ziyaret ettiğinizde GitHub, güvenlik amacıyla IP adresinizi kaydeder ve saklar; bkz. GitHub Pages: data collection ve GitHub gizlilik bildirimi. Bu kayıtların ne kadar süre saklanacağına GitHub karar verir; bunlara erişimimiz yoktur. GitHub, Avrupa Komisyonu’nun ABD’nin yeterli düzeyde koruma sağladığına karar verdiği EU-U.S. Data Privacy Framework’e katılmaktadır (GDPR md. 45). Hukuki dayanak, web sitesini güvenli bir şekilde sunmaya yönelik meşru menfaatimizdir (GDPR md. 6/1-f). Uygulamanın indirilmesi de GitHub üzerinden gerçekleşir.

Haklarınız
