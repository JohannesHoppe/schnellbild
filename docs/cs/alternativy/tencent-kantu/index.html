V čem je 看图 Kantu dobrý

Bezplatný prohlížeč a organizér obrázků od Tencentu pro Mac: prochází složky jako Stažené soubory bez importu, importuje z telefonů a fotoaparátů, třídí podle tváří, míst a data, hledá duplicity a sestavuje vybraná alba. Od roku 2019 se neaktualizuje.

Kde je silnější 看图 Kantu

  • Rozpoznávání tváří, mapa míst, hledání duplicit, vybraná alba
  • Import přímo z telefonů, fotoaparátů a zařízení PTP
  • Hodnocení a filtry pro velké soubory

Kde je silnější Schnellbild

  • ZIP, RAR, 7z se otevírají jako složky
  • Automatické vylepšení a posuvníky bez změny souboru
  • Procházení videí šipkami
  • Open source
  • Nikdy se nepřipojuje k internetu
