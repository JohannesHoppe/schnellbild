Všechny formáty, které Schnellbild zobrazí

Schnellbild zobrazí 127 formátů se 146 příponami souborů. Obrázky jdou přes ImageIO, knihovnu macOS, takže novější macOS jich přečte víc; co macOS nepřečte, dekóduje Schnellbild sám nebo s LibRaw. Videa, která macOS nepřehraje, jdou přes vestavěné jádro VLC a archivy se otevírají jako složky.
