Informativa sulla privacy

Schnellbild è un visualizzatore di immagini e video per macOS. Titolare del trattamento ai sensi del GDPR è HAUS HOPPE - ITS, Johannes Hoppe; l’indirizzo completo si trova nelle note legali. La presente informativa riguarda l’app, sia scaricata da GitHub sia acquistata sul Mac App Store (si tratta della stessa app), e questo sito web.

L’app

Schnellbild non raccoglie dati personali. Non ha account, analisi, pubblicità né tracciamento, e non si connette a internet: l’App Sandbox in cui viene eseguita non le concede alcun accesso alla rete.

Cosa resta sul tuo Mac, e solo lì:

  • Impostazioni (l’ultima cartella, l’ordinamento, i segnalibri, il volume…) nelle preferenze dell’app.
  • Accesso alle cartelle: le cartelle che hai aperto a Schnellbild, come segnalibri di macOS, così può mostrarle di nuovo dopo un riavvio. Impostazioni → Dimentica accesso alle cartelle le dimentica.
  • Password degli archivi che hai digitato, nel tuo portachiavi login (voce «Schnellbild archive passwords»); Impostazioni → Dimentica password salvate le rimuove.
  • Miniature, nella cache delle miniature di macOS.

Schnellbild legge le tue immagini, i tuoi video e i tuoi archivi solo per mostrarteli. Non invia mai da nessuna parte né i file, né i loro nomi, né alcuna informazione che li riguardi. Apple gestisce il download e l’acquisto secondo la propria informativa sulla privacy e ci trasmette solo dati numerici che non ti identificano: le vendite e, se in macOS hai consentito di condividerli con gli sviluppatori di app, i rapporti sui crash e le statistiche di utilizzo.

Questo sito web

Questo sito web non usa cookie, strumenti di analisi né contenuti di altri server (niente web font, niente video incorporati). È ospitato su GitHub Pages, un servizio di GitHub, Inc. (USA). Quando lo visiti, GitHub registra e conserva il tuo indirizzo IP per motivi di sicurezza; vedi GitHub Pages: raccolta dei dati e l’informativa sulla privacy di GitHub (in inglese). Per quanto tempo GitHub conserva questi registri lo stabilisce GitHub; noi non vi abbiamo accesso. GitHub aderisce all’EU-U.S. Data Privacy Framework, per il quale la Commissione europea ha stabilito che gli Stati Uniti garantiscono un livello di protezione adeguato (art. 45 del GDPR). La base giuridica è il nostro legittimo interesse a fornire il sito web in modo sicuro (art. 6, par. 1, lett. f) del GDPR). Anche il download dell’app avviene da GitHub.

I tuoi diritti

Ai sensi del GDPR hai diritto di accesso, rettifica, cancellazione, limitazione del trattamento e portabilità dei dati, nonché il diritto di proporre reclamo a un’autorità di controllo per la protezione dei dati. <strong>Hai il diritto di opporti</strong>, per motivi connessi alla tua situazione particolare, al trattamento basato sul nostro legittimo interesse (art. 21 del GDPR). Poiché né l’app né questo sito web conservano dati personali propri, di solito da parte nostra non c’è nulla da consultare o cancellare.
