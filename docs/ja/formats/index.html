Schnellbildが表示できるすべてのフォーマット

Schnellbildは127種類のフォーマット、146種類の拡張子を表示します。画像、カメラRAW、書類、動画、そしてフォルダのように開くアーカイブです。

  • 写真とグラフィック
  • HDR、画像編集、医療
  • テクスチャ
  • 書類とドローイング
  • カメラRAW
  • 動画
  • アーカイブ（フォルダのように開く）
