Schnellbild

イライラしない、macOSのための画像・ビデオビューア。

フォルダを開けば、サムネールが並びます。1枚を大きく表示して、キーボードで次々にめくれます。ビデオもその場で再生。MKV、AVI、WebMも。読み込むライブラリも、待ち時間も、余計なものもありません。

イライラしない理由

広告なし、トラッキングなし、アカウント不要

写真を表示するだけ。どこにも話しかけません。

しつこい勧誘なし

Pro版も、サブスクリプションも、「ロック解除」ボタンもありません。最初からすべての機能が入っています。

余計なものなし

読み込むライブラリも、編集機能も、クラウドもなし。写真とビデオを見ること。それをきちんとやります。

高速

スクロールしているそばからサムネールが表示されます。大きなフォルダでも、ネットワーク共有でも。

最初から安全

他人から届いた画像、ビデオ、アーカイブが何かを実行したり、ネットに接続したりすることはありません。事前の設定も不要です。

落ちない

壊れたファイル、変わったフォーマット、遅いディスクでも、Appが落ちる代わりにプレースホルダが表示されます。

できること

大きく表示して、キーでめくる

スペースキーで画像をウインドウいっぱいに表示し、← →でフォルダ内をめくります。トラックパッドか+ −で拡大、⌥← ⌥→で回転、fでフルスクリーン。アニメーションGIF、SVG、PDFにも対応しています。

スライドショー（s）は、フォルダとそのすべてのサブフォルダを写真もビデオもまとめて再生します。

macOSで再生できないビデオも

MP4とMOVはmacOS自体で、MKV、WebM、AVI、WMV、FLV、MPEG、DVDビデオ、AVCHDは内蔵のVLCエンジンで再生します。

  • ← →でビデオの10分の1、⇧← ⇧→で100分の1ジャンプ
  • ↑ ↓で音量を調整。すべてのビデオに共通です
  • MKV、WebM、WMV、FLV、VOBのサムネールもFinderとクイックルックで表示されます

アーカイブをフォルダのように開く

ZIP、RAR、7z、コミック（CBZ、CBR）にも対応。パスワード付きや分割されたものも開けます。ディスクには何も展開せず、ビデオもアーカイブから直接再生します。

旅行の写真をNorton Commanderのように整理

Dで2つのフォルダを並べて表示。画像をマークしたら、F5で反対側にコピー、F6で移動。ドラッグでも移せます。

名前の変更、新規フォルダ、ゴミ箱、ブックマーク。そのすべてを取り消せます。

すべてのサブフォルダを検索

検索フィールドは、表示中のフォルダとその下にあるすべての場所から、フォルダ、アーカイブ、画像、ビデオの名前を探します。結果は検索しながら次々に表示されます。遅いネットワーク共有でも同じです。大文字と小文字を区別しない検索、区別する検索、正規表現から選べます。

見た目はきれいに、ファイルはそのまま

Eで露出、コントラスト、彩度、シャープネスを自動補正。写真にもビデオにも使えます。Aでスライダを表示。変わるのは表示だけで、ファイルはそのままです。

ファイルの正体がわかる

Iでフォーマット、解像度、コーデック、ビットレート、ビット深度、カラープロファイル、カメラを表示。ファイルの拡張子と中身が一致しないときは、そのことも知らせます。

すべてのキーがすぐわかる

F1ですべてのキーを一覧表示。印刷もできます。Kでクリックして使える小さなキーボードを表示。グリッドとリスト（L）の切り替え、名前、種類、日付、サイズでの並べ替え、複数のウインドウ、そしてボスキー（X）も。

他人から届いたファイルも安全に

知らない人から届いた画像、ビデオ、アーカイブを見るのは、ビューアの本来の仕事です。だからSchnellbildは、最初からすべてのファイルを危険なものとして扱います。

  • AppleのApp Sandbox内で動作。 ネットワークには一切つながらず、ほかのプログラムも起動しません。アクセスできるのは、あなたが開いたフォルダだけです。
  • 読み取るだけ。 見るだけでファイルが変わることも、ディスクに展開されることもありません。
  • ビデオがネットにつながらない。 実はインターネットを指すプレイリストだった「ビデオ」は、何も再生しません。
  • ダブルクリックで開くのは書類だけ。プログラムは開きません。 App、スクリプト、インストーラは、画像の名前に偽装していても決して開きません。
  • 署名と公証済み。 AppleのHardened Runtime付き。

具体的に何をしているのか、そしてどこに限界があるのか：他人から届いたファイルも安全に。

Phiewer、IINA、Norton Commanderから乗り換えますか？

どれもお手本になりました。キーボードで画像を見ていくPhiewer、ビデオをすばやく扱えるIINA、そしてデュアルペインのNorton Commander。Schnellbildとの比較はこちら：Phiewerの無料の代替、ビデオを見るためのIINAの無料の代替。
