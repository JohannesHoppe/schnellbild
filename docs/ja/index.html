Schnellbild

イライラしない、Mac用の画像・動画ビューア。

フォルダの中の写真も動画も、ひとつの無料アプリで。フォルダを開けば、サムネールが並びます。1枚を大きく表示して、キーボードで次々にめくれます。動画もその場で再生。MKV、AVI、WebMも。読み込むライブラリも、待ち時間もありません。

Schnellbildでイライラしない理由

広告なし、トラッキングなし、アカウント不要

インターネット通信ゼロ

写真を表示するだけで、どこにも通信しません。

しつこい勧誘なし

Pro版も、サブスクリプションも、「ロック解除」ボタンもありません。最初からすべての機能が入っています。

余計なものなし

読み込むライブラリも、編集機能も、クラウドもなし。

高速

スクロールしているそばからサムネールが表示されます。大きなフォルダでも、ネットワーク共有でも。

最初から安全

他人から届いた画像、動画、アーカイブが何かを実行したり、ネットに接続したりすることはありません。事前の設定も不要です。

落ちない

壊れたファイル、変わったフォーマット、遅いディスクでも、プレースホルダが表示され、Appは動き続けます。

4つの表示

L キーで、グリッドからリスト、そしてアトラスへ。アトラスは、写真を撮った場所を地図や地球儀の上に示します。

できること

大きく表示してキーでめくる、スライドショーも

スペースキーで画像をウインドウいっぱいに表示し、◀ / ▶でフォルダ内をめくります。トラックパッドか+ / −で拡大、⌥ + ◀ / ⌥ + ▶で回転、Fでフルスクリーン。アニメーション付きのGraphics Interchange Format（.gif）、Scalable Vector Graphics（.svg）にも対応し、Portable Document Format（.pdf）は1ページずつ表示します（すべてのフォーマット）。

スライドショー（S）は、フォルダとそのすべてのサブフォルダを写真も動画もまとめて再生します。スライドショーで再生されるものが、そのままプレイリストです。Pで開いて、並べ替えたり、不要な項目を外したりできます。

写真を地図と地球儀の上に

Lでグリッド、リスト、アトラスの順に切り替わります。アトラスは、フォルダとサブフォルダの写真や動画を撮影した場所に並べます。大きくズームアウトすると地図は星空を背にした地球儀になり、昼と夜を表示すれば夜の側に街の明かりがともります。ズームインすると平らな地図に変わります。

  • タイムラインは旅を時間順に並べます。一部をドラッグすると、地図にはその部分だけが表示されます
  • 地球儀は地平線の方へ傾けられ、起伏を強調すればフィヨルドや山が浮かび上がります
  • Tで旅を再生。地図が場所から場所へ移動し、写真が大きく表示され、動画が数秒再生されます
  • 地図はアプリに内蔵。インターネットには接続せず、位置情報がMacの外に出ることはありません

macOSで再生できないAVIやMKVも再生

どれもHDRを含めて再生できます。MPEG-4 Part 14（.mp4）、QuickTime File Format（.mov .qt）、Advanced Video Coding High Definition（AVCHD、.mts .m2ts）、Matroska Video（.mkv）、WebM（.webm）、Audio Video Interleave（.avi）、Windows Media Video（.wmv）、Flash Video（.flv）、MPEG Program Stream（MPEG-PS、.mpg .mpeg）、DVD Video Object（.vob）、RealMedia（.rm）、Material Exchange Format（.mxf）など（すべての動画フォーマット）。

  • ◀ / ▶で動画の10分の1、⇧ + ◀ / ⇧ + ▶で100分の1ジャンプ
  • ▲ / ▼で音量を調整。すべての動画に共通です
  • ⌘ + ▶で次の動画へ、⌘ + ◀で戻ると、前の動画は止めた位置から続きます
  • 動画内の字幕（V）は最初から表示。再生の途中でオンにしても、表示中のセリフがすぐに出ます。ASS字幕は位置、色、フォントもそのままです
  • オーディオトラック、速度（< / >）、すべての動画に共通のコントロールバー。ドラッグした場所にとどまります
  • .mkv、.webm、.wmv、.flv、.vobのサムネールもFinderとクイックルックで表示されます

ZIPやRARの漫画も、フォルダのように開く

ZIP Archive（.zip）、Roshal Archive（.rar）、7-Zip Archive（.7z）に対応し、コミックのComic Book ZIP Archive（.cbz）、Comic Book RAR Archive（.cbr）、Comic Book 7z Archive（.cb7）も開けます。分割されたものも開け、ZIPとRARはパスワード付きにも対応します。ディスクには何も展開せず、動画もアーカイブから直接再生します。

旅行の写真をNorton Commanderのように整理

Dで2つのフォルダを並べて表示。画像をマークしたら、F5で反対側にコピー、F6で移動。ドラッグでも移せます。

名前の変更、新規フォルダ、ゴミ箱、ブックマーク。名前の変更、ゴミ箱への移動、コピー、移動は取り消せます。

すべてのサブフォルダを検索

検索フィールドは、表示中のフォルダとその下にあるすべての場所から、フォルダ、アーカイブ、画像、動画の名前を探します。結果は検索しながら次々に表示されます。遅いネットワーク共有でも同じです。大文字と小文字を区別しない検索、区別する検索、正規表現から選べます。

見た目はきれいに、ファイルはそのまま

Eで露出、コントラスト、彩度、シャープネスを自動補正。写真にも動画にも使えます。Aでスライダを表示。変わるのは表示だけで、ファイルはそのままです。

ファイルの正体がわかる

Iまたは⌘ + Iで、画像の横にファイル情報を表示。撮影日時と撮影場所（小さな地図と近くの地名つき）、カメラとレンズ、フォーマット、解像度、コーデック、ビットレート、ビット深度、カラープロファイル、そしてすべてのメタデータ（EXIF、GPS、IPTC、XMP、QuickTime）をフィルタしてコピーできます。日時と場所は、XMPサイドカー、GoProやDJIドローンのGPSデータ、ソニーのクリップファイル、フォルダ内のGPXトラックからも読み取ります。

拡張子と中身が一致しないファイルには、そのことを表示します。名前から形式がわからないファイルは中身で判断し、ダウンロード中のファイル（.part、.crdownloadなど）は届いたところまで表示します。

すべてのキーがすぐわかる

F1ですべてのキーを一覧表示。印刷もできます。Kでクリックして使える小さなキーボードを表示。キーは自分で割り当てることも、Phiewerと同じ配置にすることもできます。グリッド、リスト、アトラス（L）の切り替え、名前、種類、日付、サイズ、ある場所からの距離での並べ替え、複数のウインドウ、そしてボスキー（X）も。VoiceOverはすべてのタイルを読み上げ、「視差効果を減らす」をオンにすれば何も動きません。

ライトかダークか、お好みで

ダークモード派もいれば、苦手な人もいます。だから選ぶのはあなた。設定（⌘ + ,）で「システムと同じ」「ライト」「ダーク」から選べます。

他人から届いたファイルも安全に

知らない人から届いた画像、動画、アーカイブを見るのは、ビューアの本来の仕事です。だからSchnellbildは、最初からすべてのファイルを危険なものとして扱います。

  • AppleのApp Sandbox内で動作。 ネットワークには一切つながらず、自分からほかのプログラムを起動することもありません。アクセスできるのは、あなたが開いたフォルダと「ピクチャ」だけです。 これを強制しているのはmacOSなので、たとえ私たちがその気になってもごまかすことはできません。アプリはそもそもインターネットに接続できないのです。
  • 読み取るだけ。 見るだけでファイルが変わることも、ディスクに展開されることもありません。
  • 動画がネットにつながらない。 実はインターネットを指すプレイリストだった「動画」は、何も再生しません。
  • ダブルクリックで開くのは書類だけ。プログラムは開きません。 App、スクリプト、インストーラは、画像の名前に偽装していても決して開きません。
  • 署名と公証済み。 AppleのHardened Runtime付き。
  • 公開ソースコードからビルドされたことを証明できます。 各ダウンロードがどのコミットとどのビルドから作られたかを、GitHubが署名付きで証明します。誰でも確認できます。

具体的に何をしているのか、そしてどこに限界があるのか：他人から届いたファイルも安全に。

Phiewer、IINA、Norton Commanderから乗り換えますか？

Phiewerは有料のPRO版がある高速なフォトビューア、IINAは動画を観るための本格的なプレーヤー。どちらもSchnellbildのお手本で、デュアルペインはNorton Commanderがお手本です。Schnellbildは、フォルダの中の写真と動画をひとつの無料アプリで扱えます。キーはPhiewerと同じ配置にもできます。Schnellbildとの比較はこちら：Phiewerの無料の代替、動画を見るためのIINAの無料の代替、Norton CommanderからMacへ。 WindowsでHoneyview、MassiGra、Leeyesを使っていた方も、Macで同じようにフォルダやZIP・RARの画像をキーボードでめくれます。
