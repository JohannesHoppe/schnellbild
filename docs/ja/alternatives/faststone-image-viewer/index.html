FastStone Image ViewerのMac版をお探しですか？代わりのアプリはこちら

Schnellbildは、フォルダの中の画像と動画のための無料のMacアプリです。フォルダを開けばサムネールがすぐに並び、キーひとつで画像を大きく表示。MKV、AVI、WebMも再生し、ZIPやRARのアーカイブをフォルダのように開きます。アカウントもネットワーク接続も要りません。

FastStone Image Viewerの代わりにSchnellbild？

Schnellbildはフォルダをすぐに開き、読み込みの手間はありません。画像は矢印キーでめくれます。HEIC、RAW、PSD、アニメーションGIF、PDFにも対応し、フォルダの動画も同じグリッドに並びます。Macへのお引っ越し、おつかれさまでした。写真も、指が覚えた操作も一緒に来たのに、FastStone Image Viewerだけは前のパソコンでお留守番のようです。このままにしておく必要はありません。

FastStone Image Viewerの愛用者に好まれている点と、Schnellbildでの使い方

  • キーボードでめくる: スペースで画像を開き、← →でフォルダ内をめくる。
  • 読み込み不要でフォルダを直接表示: ⌘Oでフォルダを開くか、ウインドウにドロップ。
  • HEIC、AVIF、JPEG XL、WebP: macOS自体のImageIOで表示。
  • カメラのRAW: macOSが対応するRAW形式を、macOSが現像。
  • アニメーションGIF、PNG、WebP: 再生され、ほかの画像と同じように拡大・回転できます。
  • 拡大、移動、回転（表示のみ）: + −かピンチで拡大、⌥← ⌥→で回転。ファイルはそのまま。
  • MKV、WebM、AVI、WMV、FLVを再生: 内蔵のVLCエンジンで再生。
  • スライドショー: Sで開始、スペースで一時停止。

FastStone Image Viewerのほうが優れている点

  • 編集ツール：トーンカーブ、レベル補正、コピースタンプ、修復ブラシ、赤目補正
  • 最大4枚を並べて比較
  • 一括変換とリネーム、コンタクトシート、印刷レイアウト
  • タグと1〜5の星による評価
  • スキャナ対応と画面キャプチャ
  • 150種類以上のトランジション付き、音楽入りスライドショー

あえて搭載していない機能

  • 音声ファイル、音楽モード: 画像と動画だけ。音声ファイルは専用のAppで。
  • 画像の編集（切り抜き、サイズ変更、保存）: 画像を表示するだけで、変更はしません。ファイルはそのままです。
  • 一括変換・一括リネーム: 一括での変換やリネームは、ほかのアプリにおまかせしています。
  • ライブラリ、カタログ、タグ、評価: ライブラリではなくフォルダ。読み込みは不要です。
  • クラウド同期、オンライン共有: 方針として、ネットには一切つながりません。
