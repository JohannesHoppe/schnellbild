Macで使える、OpenComicの無料の代替アプリ

Schnellbildは、フォルダの中の画像と動画のための無料のMacアプリです。フォルダを開けばサムネールがすぐに並び、キーひとつで画像を大きく表示。MKV、AVI、WebMも再生し、ZIPやRARのアーカイブをフォルダのように開きます。アカウントもネットワーク接続も要りません。

無料でダウンロードSchnellbild.dmg Mac App Store近日公開。開発を応援できます

OpenComicの代わりにSchnellbild？

SchnellbildはCBZ、CBR、ZIP、RAR、7zをフォルダのように開き、ディスクには何も展開しません。ページは矢印キーでめくれます。SchnellbildとOpenComicを並べました。まずそれぞれの得意なこと、続いてすべての機能を出典付きで。

OpenComicが優れている点

  • EPUB、MOBI、SVG、JPEG XL、ACE・LZHアーカイブなど多くの形式
  • 漫画、ウェブトゥーン、見開き、ガイド表示
  • SMB/FTP/SFTP/WebDAV/S3への直接接続とOPDS
  • AIによるアップスケール、網点除去、ノイズ除去
  • タブと複数のウインドウ、ショートカットの変更とゲームパッド

Schnellbildが優れている点

  • 写真と動画を1つのグリッドに
  • MKV、WebM、AVI、WMV、FLVを再生
  • アーカイブ内の動画を直接再生
  • 2つのペインを並べる（F5でコピー、F6で移動）
  • すべてのサブフォルダを写真も動画もまとめてスライドショー
  • 矢印キーで動画を飛ばし見
  • 名前の変更、移動、ゴミ箱を取り消す
