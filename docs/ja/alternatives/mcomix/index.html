MComixのMac版をお探しですか？代わりのアプリはこちら

Schnellbildは、フォルダの中の画像と動画のための無料のMacアプリです。フォルダを開けばサムネールがすぐに並び、キーひとつで画像を大きく表示。MKV、AVI、WebMも再生し、ZIPやRARのアーカイブをフォルダのように開きます。アカウントもネットワーク接続も要りません。

無料でダウンロードSchnellbild.dmg Mac App Store近日公開。開発を応援できます

MComixの代わりにSchnellbild？

SchnellbildはCBZ、CBR、ZIP、RAR、7zをフォルダのように開き、ディスクには何も展開しません。ページは矢印キーでめくれます。漫画たちは文句ひとつ言わずにMacまでついて来てくれました。MComixは、残念ながらご一緒できなかったようです。

MComixの愛用者に好まれている点と、Schnellbildでの使い方

  • キーボードでめくる: スペースで画像を開き、← →でフォルダ内をめくる。
  • 読み込み不要でフォルダを直接表示: ⌘Oでフォルダを開くか、ウインドウにドロップ。
  • フォルダのプレビュー付きサムネールグリッド: フォルダには最初の画像を表示。画像のないフォルダはグレー表示。
  • HEIC、AVIF、JPEG XL、WebP: macOS自体のImageIOで表示。
  • アニメーションGIF、PNG、WebP: 再生され、ほかの画像と同じように拡大・回転できます。
  • 拡大、移動、回転（表示のみ）: + −かピンチで拡大、⌥← ⌥→で回転。ファイルはそのまま。
  • ZIP、RAR、7zをフォルダのように開く: フォルダのように開き、ディスクには何も展開しません。
  • 漫画のCBZ、CBR: CBZとCBRをフォルダのように開き、← →でめくる。

MComixのほうが優れている点

  • 見開きと漫画モード
  • 画像の補正（明るさ、コントラスト、シャープネス、自動コントラスト）
  • キーボードショートカットを変更可能
  • アーカイブエディタと、コレクション付きのライブラリ（任意）
  • 25言語のインターフェイス
  • Linux版とWindows版

あえて搭載していない機能

  • 見開き表示、右綴じの漫画モード: 1度に1枚を、ウインドウいっぱいに。
  • ライブラリ、カタログ、タグ、評価: ライブラリではなくフォルダ。読み込みは不要です。
