Macで使える、FlowVisionの無料の代替アプリ

Schnellbildは、フォルダの中の画像と動画のための無料のMacアプリです。フォルダを開けばサムネールがすぐに並び、キーひとつで画像を大きく表示。MKV、AVI、WebMも再生し、ZIPやRARのアーカイブをフォルダのように開きます。アカウントもネットワーク接続も要りません。

無料でダウンロードSchnellbild.dmg Mac App Store近日公開。開発を応援できます

FlowVisionの代わりにSchnellbild？

Schnellbildはフォルダをすぐに開き、読み込みの手間はありません。画像は矢印キーでめくれます。HEIC、RAW、PSD、アニメーションGIF、PDFにも対応し、フォルダの動画も同じグリッドに並びます。SchnellbildとFlowVisionを並べました。まずそれぞれの得意なこと、続いてすべての機能を出典付きで。

FlowVisionが優れている点

  • ウォーターフォール型と均等割り付けのサムネール配置
  • 右クリックのマウスジェスチャでフォルダ間を移動
  • Finderタグと、絞り込みのできるXMPの評価
  • HDR表示
  • レイアウトのプリセットを保存するプロファイル
  • macOS 11以降で動作

Schnellbildが優れている点

  • ZIP、RAR、7zをフォルダのように開く
  • 漫画のCBZ、CBR
  • アーカイブ内の動画を直接再生
  • 2つのペインを並べる（F5でコピー、F6で移動）
  • ファイルを変えずに自動補正とスライダ
  • 名前の変更、移動、ゴミ箱を取り消す
  • AppleのApp Sandbox内で動作

ウォーターフォール型・均等割り付けのサムネール配置と、Finderのようなファイル管理を中心にした、ネイティブでオープンソースのmacOS用画像ビューア。非常に大きなフォルダ向けに調整され、Mac標準の動画形式を再生し、サブフォルダを含めた表示、Finderタグ、評価、フォルダ間を移動するマウスジェスチャを備えます。
