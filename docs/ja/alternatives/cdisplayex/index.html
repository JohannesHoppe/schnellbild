漫画たちは文句ひとつ言わずにMacまでついて来てくれました。CDisplayExは、残念ながらご一緒できなかったようです。

CDisplayExの得意なこと

CDisplayの後継で、長く愛されている軽量なWindows用コミックリーダー。読み込みの速さ、Lanczosによるリサイズ、自由に設定できるキーで知られています。デスクトップ版の開発は終了しており、Androidアプリの開発が続いています。

CDisplayExの愛用者に好まれている点と、Schnellbildでの使い方

  • キーボードでめくる: スペースで画像を開き、← →でフォルダ内をめくる。
  • フォルダのプレビュー付きサムネールグリッド: フォルダには最初の画像を表示。画像のないフォルダはグレー表示。
  • HEIC、AVIF、JPEG XL、WebP: macOS自体のImageIOで表示。
  • アニメーションGIF、PNG、WebP: 再生され、ほかの画像と同じように拡大・回転できます。
  • 拡大、移動、回転（表示のみ）: + −かピンチで拡大、⌥← ⌥→で回転。ファイルはそのまま。
  • ZIP、RAR、7zをフォルダのように開く: フォルダのように開き、ディスクには何も展開しません。
  • 漫画のCBZ、CBR: CBZとCBRをフォルダのように開き、← →でめくる。
  • スライドショー: Sで開始、スペースで一時停止。

CDisplayExのほうが優れている点

  • すべての機能を自分好みのキーに割り当てられる
  • 古いスキャン向けの自動色補正とガンマ
  • 見開きと日本式（右綴じ）モード
  • Windowsのエクスプローラで漫画ファイルのサムネール

あえて搭載していない機能

  • 見開き表示、右綴じの漫画モード: 1度に1枚を、ウインドウいっぱいに。
