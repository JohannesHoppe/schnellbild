Macで使える、GraphicConverterの無料の代替アプリ

Schnellbildは、フォルダの中の画像と動画のための無料のMacアプリです。フォルダを開けばサムネールがすぐに並び、キーひとつで画像を大きく表示。MKV、AVI、WebMも再生し、ZIPやRARのアーカイブをフォルダのように開きます。アカウントもネットワーク接続も要りません。

無料でダウンロードSchnellbild.dmg Mac App Store近日公開。開発を応援できます

GraphicConverterの代わりにSchnellbild？

Schnellbildはフォルダをすぐに開き、読み込みの手間はありません。画像は矢印キーでめくれます。HEIC、RAW、PSD、アニメーションGIF、PDFにも対応し、フォルダの動画も同じグリッドに並びます。SchnellbildとGraphicConverterを並べました。まずそれぞれの得意なこと、続いてすべての機能を出典付きで。

GraphicConverterが優れている点

  • 約200の画像形式を開き、約80の形式で書き出し。古い形式や科学系の形式も
  • 本格的な画像エディタと、アクションを使った一括変換
  • メタデータ編集（EXIF/IPTC/XMP、顔、GPSマップ）
  • 多くのスライドショーのオプション（トランジション、ランダム、メタデータ、再生中の並べ替え）
  • リスト、Cover Flow、サムネール表示、すべてのサブフォルダのフラット表示
  • 重複検出、コンタクトシート、Webギャラリー
  • ショートカットの変更、14言語、ライト・ダークの設定

Schnellbildが優れている点

  • 無料ですべての機能
  • MKV、WebM、AVI、WMV、FLVを再生
  • 漫画のCBZ、CBR
  • アーカイブ内の動画を直接再生
  • 2つのペインを並べる（F5でコピー、F6で移動）
  • オープンソース
  • ネットに一切つながらない

長年続くMac用の「画像の万能ナイフ」。ファイル・画像ブラウザ、スライドショー、エディタ、一括変換を兼ね、約200の形式を開けます。ブラウザではQuickTime互換の動画や音声も再生でき、充実したメタデータの扱い、重複検出、サブフォルダをまとめて表示するフラット表示、Spotlight検索を備えます。
