En qué destaca MComix

MComix es un visor de cómics e imágenes personalizable en GTK para Linux y Windows, un fork de Comix. Lee CBR/CBZ/CB7/CBT/LHA y PDF, tiene modos de doble página y manga, mejora de imagen, pase de diapositivas y una biblioteca opcional.

Lo que gusta de MComix y cómo funciona en Schnellbild

  • Pasar imágenes con el teclado: La barra espaciadora abre una imagen, ← → recorren la carpeta.
  • Explora carpetas directamente, sin importar: Abre una carpeta con ⌘O o suéltala en la ventana.
  • Cuadrícula de miniaturas con previsualización de carpetas: Las carpetas muestran sus primeras imágenes; las que no tienen ninguna aparecen en gris.
  • HEIC, AVIF, JPEG XL, WebP: Con ImageIO, el de macOS.
  • GIF, PNG y WebP animados: Se reproducen, y se amplían y giran como cualquier imagen.
  • Ampliar, desplazar, girar (solo la vista): + − o pellizcar para ampliar, ⌥← ⌥→ para girar; el archivo no cambia.
  • ZIP, RAR, 7z se abren como carpetas: Se abren como carpetas, sin descomprimir nada en el disco.
  • Cómics CBZ, CBR: CBZ y CBR se abren como carpetas; pasa páginas con ← →.

Dónde MComix sigue por delante

  • Doble página y modo manga
  • Mejora de imagen (brillo, contraste, nitidez, contraste automático)
  • Atajos de teclado editables
  • Editor de archivos comprimidos y biblioteca opcional con colecciones
  • Interfaz en 25 idiomas
  • Versiones para Linux y Windows

Omitido a propósito

  • Doble página, modo manga de derecha a izquierda: Una imagen cada vez, tan grande como la ventana.
  • Biblioteca, catálogo, etiquetas, valoraciones: Carpetas en lugar de biblioteca: nada que importar.
