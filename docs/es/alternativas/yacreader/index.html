Una alternativa gratis a YACReader para Mac

Schnellbild es una app gratuita para Mac para las imágenes y los vídeos de tus carpetas: abres una carpeta y las miniaturas ya están, una tecla muestra una imagen en grande. Reproduce MKV, AVI y WebM, abre archivos ZIP y RAR como carpetas y funciona sin cuenta y sin acceso a la red.

Descargar gratisSchnellbild.dmg Mac App Storepronto, por 0,99 € para apoyarlo

¿Schnellbild en lugar de YACReader?

Schnellbild abre CBZ, CBR, ZIP, RAR y 7z como carpetas, sin descomprimir nada en el disco, y pasas las páginas con las flechas. Schnellbild y YACReader, uno junto a otro: lo que cada uno hace mejor y, después, cada función con su fuente.

Dónde es más fuerte YACReader

  • Biblioteca de cómics completa: metadatos de Comic Vine, listas de lectura, listas inteligentes, valoraciones
  • Servidor y apps para iOS/Android con el progreso de lectura sincronizado
  • Modo manga, doble página, desplazamiento continuo para webtoons
  • Brillo, contraste y gamma para escaneos antiguos
  • 12 temas más editor de temas; atajos reasignables
  • Versiones para Windows y Linux

Dónde es más fuerte Schnellbild

  • Fotos y vídeos juntos en una cuadrícula
  • Reproduce MKV, WebM, AVI, WMV, FLV
  • Reproduce vídeos directamente desde archivos comprimidos
  • Dos paneles uno junto a otro (F5 copiar, F6 mover)
  • Pase de diapositivas por todas las subcarpetas, fotos y vídeos mezclados
  • Recorrer vídeos con las flechas
  • Nunca se conecta a internet
