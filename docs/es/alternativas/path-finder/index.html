Una alternativa gratis a Path Finder para Mac

Schnellbild es una app gratuita para Mac para las imágenes y los vídeos de tus carpetas: abres una carpeta y las miniaturas ya están, una tecla muestra una imagen en grande. Reproduce MKV, AVI y WebM, abre archivos ZIP y RAR como carpetas y funciona sin cuenta y sin acceso a la red.

¿Schnellbild en lugar de Path Finder?

Schnellbild no es un gestor de archivos, sino un visor con dos paneles: F5 copia y F6 mueve las imágenes marcadas al otro panel, y ambas cosas se pueden deshacer. Schnellbild y Path Finder, uno junto a otro: lo que cada uno hace mejor y, después, cada función con su fuente.

Schnellbild no es un gestor de archivos completo: no tiene conexiones FTP, SFTP ni a la nube, no sincroniza carpetas ni crea archivos comprimidos. Está hecho para recorrer fotos y vídeos y ordenarlos: miniaturas de todo, dos paneles uno junto a otro con F5 para copiar y F6 para mover, y archivos comprimidos que se abren como carpetas.

Dónde es más fuerte Path Finder

  • Módulos: Previsualización, Información, Terminal, Drop Stack, Git, editor hex y de texto
  • Explorador de tamaños y sincronización o fusión de carpetas
  • Renombrado por lotes, borrado seguro, acceso de administrador
  • Interfaz en 20 idiomas
  • Barra de marcadores, pestañas predefinidas

Dónde es más fuerte Schnellbild

  • Gratis, con todas las funciones
  • ZIP, RAR, 7z se abren como carpetas
  • Cómics CBZ, CBR
  • Reproduce vídeos directamente desde archivos comprimidos
  • Pase de diapositivas por todas las subcarpetas, fotos y vídeos mezclados
  • Mejora automática y reguladores sin cambiar el archivo
  • Recorrer vídeos con las flechas
