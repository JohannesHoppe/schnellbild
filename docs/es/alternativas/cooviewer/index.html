Una alternativa gratis a cooViewer para Mac

Schnellbild es una app gratuita para Mac para las imágenes y los vídeos de tus carpetas: abres una carpeta y las miniaturas ya están, una tecla muestra una imagen en grande. Reproduce MKV, AVI y WebM, abre archivos ZIP y RAR como carpetas y funciona sin cuenta y sin acceso a la red.

¿Schnellbild en lugar de cooViewer?

Schnellbild abre CBZ, CBR, ZIP, RAR y 7z como carpetas, sin descomprimir nada en el disco, y pasas las páginas con las flechas. Schnellbild y cooViewer, uno junto a otro: lo que cada uno hace mejor y, después, cada función con su fuente.

Dónde es más fuerte cooViewer

  • Lector de manga dedicado: doble página de derecha a izquierda con detección automática de páginas sueltas, guardada por libro
  • Marcadores de página con nombre y última página recordada por libro
  • Todas las teclas y acciones de ratón asignables, con valores por defecto para una sola mano
  • Abre una gama enorme de formatos comprimidos, incluidos RAR/ZIP en varias partes y archivos con contraseña
  • Filtros de Core Image para la vista, lupa
  • Miniaturas en el Finder y Vista Rápida para CBZ/CBR/ZIP/RAR/7z

Dónde es más fuerte Schnellbild

  • Fotos y vídeos juntos en una cuadrícula
  • Reproduce MKV, WebM, AVI, WMV, FLV
  • Reproduce vídeos directamente desde archivos comprimidos
  • Dos paneles uno junto a otro (F5 copiar, F6 mover)
  • Buscar nombres en todas las subcarpetas
  • Recorrer vídeos con las flechas
  • Deshacer cambios de nombre, traslados, papelera
