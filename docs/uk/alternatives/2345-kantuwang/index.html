Сильні сторони 2345看图王

Один із найпоширеніших переглядачів зображень для Windows у Китаї: швидко відкриває близько 98 форматів, серед них PSD, RAW, SVG і AVIF, а також PDF/OFD і CAD. Має простий редактор, пакетні інструменти, OCR, фото на документи й AI-вирізання тла, частину з них лише з VIP-підпискою.

Що люблять шанувальники 2345看图王 і як це працює в Schnellbild

  • Гортання клавіатурою: Пробіл відкриває зображення, ← → гортають папку.
  • Відкриває папки напряму, без імпорту: Відкрийте папку через ⌘O або перетягніть її у вікно.
  • Сітка мініатюр із прев’ю папок: Папки показують свої перші зображення; папки без них сірі.
  • HEIC, AVIF, JPEG XL, WebP: Через ImageIO, власний засіб macOS.
  • RAW з камер: RAW-формати, які знає macOS, проявляє macOS.
  • Анімовані GIF, PNG, WebP: Програються, масштабуються й повертаються, як будь-яке зображення.
  • Масштаб, зсув, поворот (лише перегляд): + − або жест зведення пальців для масштабу, ⌥← ⌥→ для повороту; файл лишається як є.
  • ZIP, RAR, 7z відкриваються як папки: Відкриваються як папки, нічого не розпаковується на диск.

Де 2345看图王 і далі попереду

  • Дуже широкий список форматів (PSD/PSB, AI, RAW, CAD, OFD)
  • Вбудоване редагування, пакетне конвертування й перейменування, OCR, фото на документи, друк
  • Звичний для китайських користувачів Windows, клавіші сумісні з ACDSee

Свідомо не додано

  • Редагує зображення (обтинання, розмір, збереження): Показує зображення, не змінюючи їх: ваші файли лишаються як є.
  • Пакетне конвертування чи перейменування: Пакетне конвертування й перейменування Schnellbild залишає іншим програмам.
  • Медіатека, каталог, теги, оцінки: Папки замість медіатеки: нічого імпортувати.
  • Хмарна синхронізація, спільний доступ онлайн: Ніколи не виходить у мережу, із принципу.
