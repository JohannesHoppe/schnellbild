Безкоштовна альтернатива Path Finder для Mac

Schnellbild: безплатний застосунок для Mac для фото й відео у ваших папках. Відкриваєте папку, і мініатюри вже на місці, одна клавіша показує зображення великим. Він відтворює MKV, AVI і WebM, відкриває архіви ZIP і RAR як папки та працює без облікового запису й без доступу до мережі.

Schnellbild замість Path Finder?

Schnellbild не файловий менеджер, а переглядач із двома панелями: F5 копіює, F6 переміщує позначені зображення в іншу панель, і обидві дії можна скасувати. Schnellbild і Path Finder поруч: що кожен робить краще, а далі кожна функція з джерелом.

Schnellbild не є повноцінним файловим менеджером: без FTP, SFTP і хмарних підключень, без синхронізації папок, без пакування архівів. Він зроблений для того, щоб переглядати й сортувати фото та відео: мініатюри всього, дві панелі поруч, F5 копіює, F6 переміщує, архіви відкриваються як папки.

Де перевага в Path Finder

  • Модулі: Preview, Info, Terminal, Drop Stack, Git, редактор hex і тексту
  • Size Browser і синхронізація та злиття папок
  • Пакетне перейменування, безпечне видалення, права адміністратора
  • 20 мов інтерфейсу
  • Панель закладок, набори вкладок

Де перевага в Schnellbild

  • Безплатно, з усіма функціями
  • ZIP, RAR, 7z відкриваються як папки
  • Комікси CBZ, CBR
  • Відтворює відео просто з архівів
  • Слайд-шоу через усі підпапки, фото й відео разом
  • Автопокращення й повзунки без зміни файлу
  • Перемотування відео стрілками
