Сильні сторони Imagine

Крихітний і дуже швидкий корейський безплатний переглядач зображень і анімацій для Windows із браузером мініатюр, величезним списком форматів (зокрема JXL, AVIF, HEIF, CLIP, KRA, багато RAW), переглядом архівів, пакетним конвертуванням і перейменуванням, простим малюванням і редактором анімацій. Працює також як плагіни Total Commander.

Що люблять шанувальники Imagine і як це працює в Schnellbild

  • Гортання клавіатурою: Пробіл відкриває зображення, ← → гортають папку.
  • Відкриває папки напряму, без імпорту: Відкрийте папку через ⌘O або перетягніть її у вікно.
  • Сітка мініатюр із прев’ю папок: Папки показують свої перші зображення; папки без них сірі.
  • HEIC, AVIF, JPEG XL, WebP: Через ImageIO, власний засіб macOS.
  • RAW з камер: RAW-формати, які знає macOS, проявляє macOS.
  • Анімовані GIF, PNG, WebP: Програються, масштабуються й повертаються, як будь-яке зображення.
  • Масштаб, зсув, поворот (лише перегляд): + − або жест зведення пальців для масштабу, ⌥← ⌥→ для повороту; файл лишається як є.
  • ZIP, RAR, 7z відкриваються як папки: Відкриваються як папки, нічого не розпаковується на диск.

Де Imagine і далі попереду

  • Величезний список форматів, зокрема KRA, ORA, CLIP, DICOM, HDR-формати
  • Вбудовані редагування, створення анімацій і пакетне перейменування
  • Плагіни Lister/Packer/Content для Total Commander
  • Працює на всьому від Windows 95 до Windows 11 ARM64

Свідомо не додано

  • Редагує зображення (обтинання, розмір, збереження): Переглядач, а не графічний редактор: ваші файли лишаються як є.
  • Пакетне конвертування чи перейменування: Переглядач, а не конвертер.

Спробуйте на власних папках.

Безплатно, без облікового запису, з усіма функціями.
