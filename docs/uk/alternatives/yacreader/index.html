Сильні сторони YACReader

YACReader є читалкою коміксів разом із менеджером бібліотеки (YACReaderLibrary) для великих колекцій, з метаданими Comic Vine, списками читання й домашнім сервером для мобільних програм. Читалка має розворот, режим манґи й безперервне прокручування з налаштуваннями зображення.

Де перевага в YACReader

  • Повноцінна бібліотека коміксів: метадані Comic Vine, списки читання, розумні списки, оцінки
  • Сервер і програми для iOS/Android із синхронізацією прогресу читання
  • Режим манґи, розворот, безперервне прокручування для вебтунів
  • Яскравість, контраст і гама для старих сканів
  • 12 тем і редактор тем; переназначувані клавіші
  • Версії для Windows і Linux

Де перевага в Schnellbild

  • Фото й відео разом в одній сітці
  • Відтворює MKV, WebM, AVI, WMV, FLV
  • Відтворює відео просто з архівів
  • Дві панелі поруч (F5 копіює, F6 переміщує)
  • Слайд-шоу через усі підпапки, фото й відео разом
  • Перемотування відео стрілками
  • Ніколи не виходить у мережу
