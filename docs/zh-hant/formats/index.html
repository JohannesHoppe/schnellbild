Schnellbild 顯示的所有格式

Schnellbild 能顯示 127 種格式、146 種副檔名：圖片、相機 RAW、文件、影片，以及像資料夾一樣打開的壓縮檔。

  • 照片和圖形
  • HDR、影像編輯和醫學
  • 材質
  • 文件和繪圖
  • 相機 RAW
  • 影片
  • 壓縮檔，像資料夾一樣打開
