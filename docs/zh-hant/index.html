一款用起來不惱人的 Mac 圖片與影片檢視器。

為什麼 Schnellbild 不惱人

沒有廣告、沒有追蹤、不需帳號

完全不連網

它只顯示你的照片，不跟任何人通訊。

不推銷

沒有專業版，沒有訂閱，也沒有「解鎖」按鈕。所有功能一應俱全。

不臃腫

不必匯入圖庫，沒有編輯器，沒有雲端。

快速

捲動時縮圖隨即出現，大型檔案夾和網路共享也一樣。

預設就安全

別人傳來的影像、影片和封存檔不會執行任何東西，也不會連上網路，不需要事先開啟任何設定。

不當機

遇到損壞的檔案、奇怪的格式或緩慢的磁碟，只會顯示預留圖，App 不會因此當掉。

四種顯示方式

按 L，從格狀切換到列表，再到地圖集：照片顯示在拍攝地點，地圖或地球儀任選。

功能一覽

放大檢視，按鍵翻頁

按空白鍵，影像會以視窗允許的最大尺寸打開；用 ◀ / ▶ 在檔案夾中翻頁。用觸控式軌跡板或 + / − 縮放，用 ⌥ + ◀ / ⌥ + ▶ 旋轉，按 F 進入全螢幕。帶動畫的 Graphics Interchange Format（.gif） 和 Scalable Vector Graphics（.svg） 同樣支援，Portable Document Format（.pdf） 逐頁顯示（所有格式）。

幻燈片秀（S）會播放檔案夾及其所有子檔案夾的內容，照片和影片都包含在內。幻燈片秀播放的內容就是播放列表：按 P 開啟，可調整順序、移出不需要的項目。

照片在地圖和地球儀上

按 L 依序切換網格、列表和地圖集。在地圖集裡，檔案夾及其子檔案夾裡的照片和影片會出現在拍攝地點。縮得很遠時，地圖變成星空前的地球儀；打開晝夜顯示，夜半球上還會亮起城市燈光。放大後，它會攤平成地圖。

  • 時間軸依時間排列整段旅程：在其中拖選一段，地圖就只顯示這一段
  • 地球儀可向地平線傾斜，還可誇張地形起伏，讓峽灣和山脈凸顯出來
  • 按 T 播放旅程：地圖從一個地點移到下一個，照片放大顯示，影片播放幾秒
  • 地圖內建在 App 裡：不連網，任何位置資訊都不會離開你的 Mac

影片播放器，連 macOS 播不了的也行

全都能播放，支援 HDR：MPEG-4 Part 14（.mp4）、QuickTime File Format（.mov .qt）、Advanced Video Coding High Definition（AVCHD，.mts .m2ts）、Matroska Video（.mkv）、WebM（.webm）、Audio Video Interleave（.avi）、Windows Media Video（.wmv）、Flash Video（.flv）、MPEG Program Stream（MPEG-PS，.mpg .mpeg）、DVD Video Object（.vob）、RealMedia（.rm）、Material Exchange Format（.mxf） 等（所有影片格式）。

  • ◀ / ▶ 跳轉影片的十分之一，⇧ + ◀ / ⇧ + ▶ 跳轉百分之一
  • ▲ / ▼ 調整音量，對所有影片生效
  • ⌘ + ▶ 切到下一個影片，⌘ + ◀ 返回：前一個影片從離開時的位置繼續播放
  • 影片內的字幕（V）從一開始就顯示；播放到一半才打開，也會立刻顯示正在進行的那一句；ASS 字幕保留位置、顏色和字體
  • 音軌、速度（< / >），所有影片共用一條控制列，拖到哪裡就停在哪裡
  • Finder 和快速查看也能顯示 .mkv、.webm、.wmv、.flv 和 .vob 的縮圖

壓縮檔像檔案夾一樣打開

ZIP Archive（.zip）、Roshal Archive（.rar） 和 7-Zip Archive（.7z） 壓縮檔，包括漫畫：Comic Book ZIP Archive（.cbz）、Comic Book RAR Archive（.cbr）、Comic Book 7z Archive（.cb7），分割成多個部分的也可以；ZIP 和 RAR 還支援密碼。不會在磁碟上解壓縮任何內容，影片直接從壓縮檔中播放。

像在 Norton Commander 裡一樣整理旅遊照片

按 D 並排顯示兩個檔案夾。標記影像後，按 F5 拷貝到另一側，按 F6 搬過去，或者直接拖過去。

重新命名、新增檔案夾、垃圾桶、書籤，而且重新命名、丟到垃圾桶、拷貝和搬移都可以還原。

搜尋所有子檔案夾

搜尋欄位會在目前的檔案夾及其下所有位置中，尋找檔案夾、封存檔、影像和影片的名稱。搜尋過程中結果陸續出現，即使在緩慢的網路共享上也一樣。可以忽略大小寫、區分大小寫，或使用正規表示式。

畫面更好看，檔案不更動

按 E 自動增強曝光、對比、飽和度和銳利度，照片和影片都適用。按 A 打開滑桿。這只影響顯示：你的檔案保持原樣。

看清檔案的真面目

按 I 或 ⌘ + I 在圖片旁打開檔案資訊：拍攝的時間和地點（附小地圖和附近的地名）、相機和鏡頭、格式、解析度、編解碼器、位元率、位元深度和色彩描述檔，以及每一個中繼資料鍵（EXIF、GPS、IPTC、XMP、QuickTime），可篩選、可拷貝。時間和地點也可以來自 XMP 附屬檔、GoPro 或 DJI 空拍機的 GPS 資料、Sony 的片段檔，以及檔案夾裡的 GPX 軌跡。

檔案的副檔名和內容不符時會提醒你。名稱看不出類型的檔案依內容辨識，仍在下載的檔案（.part、.crdownload 等）下載到哪裡就顯示到哪裡。

所有按鍵盡在掌握

按 F1 列出所有按鍵，還能列印；按 K 顯示可點按的迷你鍵盤。可以自訂按鍵，也可以換成和 Phiewer 一樣的按鍵。格狀、列表或地圖集（L），依名稱、種類、日期、大小或與某地的距離排序，多個視窗，還有老闆鍵（X）。旁白會朗讀每個縮圖；打開「減少動態效果」後，一切都不再滑動。

淺色還是深色，隨你選

有人離不開深色模式，有人受不了它。所以由你決定：在設定（⌘ + ,）中選擇與系統相同、淺色或深色。

別人傳來的檔案，也能放心看

檢視陌生人傳來的影像、影片和封存檔，正是檢視器的本分。所以 Schnellbild 一開始就把每個檔案都當作不可信任的。

  • 在 Apple 的 App Sandbox 中執行。 完全不連網，不會自行啟動其他程式，只能取用你為它打開的檔案夾，以及「圖片」。 這由 macOS 強制執行，所以就算我們想作弊也做不到：App 根本無法連上網際網路。
  • 只讀不寫。 檢視從不更動任何東西，也從不解壓縮到磁碟。
  • 影片無法連上網路。 實際上是指向網際網路的播放列表的「影片」，什麼都不會播放。
  • 按兩下只打開文件，不打開程式。 App、腳本和安裝程式一律不打開，即使它們偽裝成影像的名稱。
  • 經過簽署和公證， 並啟用 Apple 的 Hardened Runtime。
  • 可證明由公開原始碼建置。 GitHub 以簽章證明每個下載來自哪個提交、哪次建置。任何人都可以驗證。

它具體做了什麼，界限又在哪裡：別人傳來的檔案，也能放心看。

從 Phiewer、IINA 或 Norton Commander 轉過來？

Phiewer 是一款附付費 PRO 版的快速看圖軟體，IINA 是一款用來看影片的完整播放器；它們和雙窗格的 Norton Commander 一樣，都是 Schnellbild 的榜樣。Schnellbild 把檔案夾裡的照片和影片放進一款免費 App，按鍵也能設成和 Phiewer 一樣。Schnellbild 和它們相比如何：免費的 Phiewer 替代方案、用來瀏覽影片的免費 IINA 替代方案、從 Norton Commander 轉到 Mac。
