Schnellbild

一款用起來不惱人的 macOS 影像與影片檢視器。

打開檔案夾，縮圖一目了然；放大檢視單張照片，用鍵盤輕鬆翻頁。影片也能直接播放，MKV、AVI 和 WebM 也不例外。不必匯入圖庫，不必等待，沒有多餘的東西。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

需要 macOS 15 或以上版本，搭載 Apple 晶片的 Mac。以 Developer ID 簽署，經 Apple 公證，在 Apple 的 App Sandbox 中執行。兩個版本是同一個 App，功能完全相同；在 App Store 購買就能支持它的開發。

為什麼不惱人

沒有廣告、沒有追蹤、不需帳號

它只顯示你的照片，不跟任何人通訊。

不推銷

沒有專業版，沒有訂閱，也沒有「解鎖」按鈕。所有功能一應俱全。

不臃腫

不必匯入圖庫，沒有編輯器，沒有雲端。只把一件事做好：看照片和影片。

快速

捲動時縮圖隨即出現，大型檔案夾和網路共享也一樣。

預設就安全

別人傳來的影像、影片和封存檔不會執行任何東西，也不會連上網路，不需要事先開啟任何設定。

不當機

遇到損壞的檔案、奇怪的格式或緩慢的磁碟，只會顯示預留圖，App 不會因此當掉。

功能一覽

放大檢視，按鍵翻頁

按空白鍵，影像會以視窗允許的最大尺寸打開；用 ← → 在檔案夾中翻頁。用觸控式軌跡板或 + − 縮放，用 ⌥← ⌥→ 旋轉，按 f 進入全螢幕。動態 GIF、SVG 和 PDF 同樣支援。

幻燈片秀（s）會播放檔案夾及其所有子檔案夾的內容，照片和影片都包含在內。

影片，連 macOS 播不了的也行

macOS 本身能播放的格式（MP4、MOV、AVCHD 等）由 macOS 播放，其餘格式（MKV、WebM、AVI、WMV、FLV、MPEG、DVD 影片）則由內建的 VLC 引擎播放。

  • ← → 跳轉影片的十分之一，⇧← ⇧→ 跳轉百分之一
  • ↑ ↓ 調整音量，對所有影片生效
  • Finder 和快速查看也能顯示 MKV、WebM、WMV、FLV 和 VOB 的縮圖

封存檔像檔案夾一樣打開

ZIP、RAR 和 7z，包括漫畫（CBZ、CBR），分割成多個部分的也可以；ZIP 和 RAR 還支援密碼。不會在磁碟上解壓縮任何內容，影片直接從封存檔中播放。（7z 需要較新的 macOS：macOS 15 無法讀取大多數 7z 封存檔。）

像在 Norton Commander 裡一樣整理旅遊照片

按 D 並排顯示兩個檔案夾。標記影像後，按 F5 拷貝到另一側，按 F6 搬過去，或者直接拖過去。

重新命名、新增檔案夾、垃圾桶、書籤，而且重新命名、丟到垃圾桶、拷貝和搬移都可以還原。

搜尋所有子檔案夾

搜尋欄位會在目前的檔案夾及其下所有位置中，尋找檔案夾、封存檔、影像和影片的名稱。搜尋過程中結果陸續出現，即使在緩慢的網路共享上也一樣。可以忽略大小寫、區分大小寫，或使用正規表示式。

畫面更好看，檔案不更動

按 E 自動增強曝光、對比、飽和度和銳利度，照片和影片都適用。按 A 打開滑桿。這只影響顯示：你的檔案保持原樣。

看清檔案的真面目

按 I 顯示格式、解析度、編解碼器、位元率、位元深度、色彩描述檔和相機；如果檔案的副檔名和內容不符，也會提醒你。

所有按鍵盡在掌握

按 F1 列出所有按鍵，還能列印；按 K 顯示可點按的迷你鍵盤。格狀或列表（L），依名稱、種類、日期或大小排序，多個視窗，還有老闆鍵（X）。

別人傳來的檔案，也能放心看

檢視陌生人傳來的影像、影片和封存檔，正是檢視器的本分。所以 Schnellbild 一開始就把每個檔案都當作不可信任的。

  • 在 Apple 的 App Sandbox 中執行。 完全不連網，不會自行啟動其他程式，只能取用你為它打開的檔案夾，以及「圖片」「影片」和「下載項目」。
  • 只讀不寫。 檢視從不更動任何東西，也從不解壓縮到磁碟。
  • 影片無法連上網路。 實際上是指向網際網路的播放列表的「影片」，什麼都不會播放。
  • 按兩下只打開文件，不打開程式。 App、腳本和安裝程式一律不打開，即使它們偽裝成影像的名稱。
  • 經過簽署和公證， 並啟用 Apple 的 Hardened Runtime。

它具體做了什麼，界限又在哪裡：別人傳來的檔案，也能放心看。

從 Phiewer、IINA 或 Norton Commander 轉過來？

它們都是 Schnellbild 的榜樣：Phiewer 用鍵盤瀏覽影像，IINA 快速處理影片，Norton Commander 的雙窗格。Schnellbild 和它們相比如何：免費的 Phiewer 替代方案、用來瀏覽影片的免費 IINA 替代方案。
