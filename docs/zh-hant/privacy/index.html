隱私權政策

Schnellbild 是一款 macOS 影像與影片檢視器。GDPR 所稱的控管者為 HAUS HOPPE - ITS（Johannes Hoppe）；完整地址請見法律聲明。本政策適用於這個 App（無論是從 GitHub 下載或在 Mac App Store 購買，兩者是同一個 App）以及本網站。

App

Schnellbild 不蒐集任何個人資料。它沒有帳號、分析、廣告和追蹤，也不會連上網際網路：它執行所在的 App Sandbox 完全不允許它存取網路。

以下內容儲存在你的 Mac 上，而且只儲存在那裡：

  • 設定（上次打開的檔案夾、排序方式、書籤、音量⋯⋯），儲存在 App 本身的偏好設定中。
  • 檔案夾存取權：你為 Schnellbild 打開的檔案夾，以 macOS 書籤的形式儲存，讓它在重新啟動後能再次顯示。可在「設定」→「忘記檔案夾取用⋯」中清除它們。
  • 你輸入的封存檔密碼，儲存在你的登入鑰匙圈中（項目「Schnellbild archive passwords」）；在「設定」中按一下「忘記已儲存的密碼」即可將其移除。
  • 縮圖，儲存在 macOS 本身的縮圖快取中。

Schnellbild 讀取你的影像、影片和封存檔，只是為了顯示給你看。它從不將這些檔案、檔案名稱或任何相關資訊傳送到任何地方。下載與購買由 Apple 依據其本身的隱私權政策處理，Apple 只會提供我們不含你身分的數據：銷售量，以及當你在 macOS 中允許與 App 開發者分享時的當機報告和使用統計資料。

本網站

本網站不使用 Cookie、分析工具，也不載入來自其他伺服器的內容（沒有網路字型，沒有嵌入影片）。本網站託管於 GitHub Pages，這是 GitHub, Inc.（美國）提供的服務。你造訪本網站時，GitHub 基於安全目的會記錄並儲存你的 IP 位址；請參閱GitHub Pages：資料蒐集和GitHub 隱私權聲明。GitHub 保存這些記錄多久由 GitHub 決定；我們無法存取這些記錄。GitHub 參與歐盟-美國資料隱私框架（EU-U.S. Data Privacy Framework），歐盟執委會已認定美國在此框架下提供適足的保護水準（GDPR 第 45 條）。法律依據是我們安全提供本網站的正當利益（歐盟《一般資料保護規則》（GDPR）第 6 條第 1 項第 (f) 款）。App 的下載同樣來自 GitHub。

你的權利

依據 GDPR，你享有查閱、更正、刪除、限制處理及資料可攜的權利，並有權向資料保護監管機關提出申訴。你有權基於與你特殊情況有關的理由，反對基於我們正當利益所進行的處理（GDPR 第 21 條）。由於 App 和本網站都不保存自己的個人資料，我們這邊根本沒有任何可查詢或刪除的內容。因此，對查閱請求的答覆會非常簡短：我們對你一無所知。
