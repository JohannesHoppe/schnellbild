免費的 Mac 版 nPlayer 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 nPlayer？

Schnellbild 不是完整的媒體播放器。它把檔案夾裡的影片以縮圖形式放在照片旁邊，能播放 MKV、AVI 和 WebM，方向鍵每次跳轉影片的十分之一。Schnellbild 和 nPlayer 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

nPlayer 比較強的地方

  • 網路通訊協定（SMB、NFS、SFTP、WebDAV、UPnP）
  • 進階字幕（樣式、同步、SMI、SUP）
  • A-B 段重複播放、語言學習用的「聽力練習」
  • 子母畫面、播放速度
  • 音訊等化器和同步

Schnellbild 比較強的地方

  • 免費，功能完整
  • 照片和影片在同一個格狀檢視中
  • ZIP、RAR、7z 像檔案夾一樣打開
  • 漫畫 CBZ、CBR
  • 直接播放壓縮檔中的影片
  • 雙窗格並排（F5 拷貝、F6 搬移）
  • 幻燈片秀涵蓋所有子檔案夾，照片和影片混合播放

熱門 iOS 播放器 nPlayer 的付費 Mac 版：幾乎能播放所有影片、音訊和字幕格式，可從 SMB、NFS、WebDAV、FTP、UPnP 和雲端服務串流，字幕樣式設定很強，有 A-B 段重複播放和子母畫面。Mac 版很少更新。
