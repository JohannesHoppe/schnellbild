你的漫畫二話不說就跟著搬到了 Mac。BandiView 卻沒擠上這班車。

BandiView 擅長什麼

Bandizip 開發商推出的 Honeyview 後繼者：Windows 10/11 上快速的單張看圖軟體，可閱讀壓縮檔和漫畫，有智慧雙頁和條漫模式、HDR 輸出及快速的批次轉檔工具。在韓國很受歡迎，常用來看漫畫和條漫。

BandiView 的愛用者喜歡什麼，Schnellbild 又怎麼做

  • 用鍵盤翻頁: 空白鍵打開影像，← → 在檔案夾中翻頁。
  • 直接瀏覽檔案夾，不必匯入: 用 ⌘O 打開檔案夾，或直接拖到視窗上。
  • 縮圖格狀顯示，附檔案夾預覽: 檔案夾顯示其中的前幾張影像；沒有影像的檔案夾會變灰。
  • HEIC、AVIF、JPEG XL、WebP: 透過 macOS 本身的 ImageIO。
  • 相機 RAW: macOS 認得的 RAW 格式，由 macOS 顯影。
  • 動態 GIF、PNG、WebP: 會播放，也能像一般影像一樣縮放和旋轉。
  • 縮放、平移、旋轉（僅檢視）: 用 + − 或雙指開合縮放，⌥← ⌥→ 旋轉；檔案保持原樣。
  • ZIP、RAR、7z 像檔案夾一樣打開: 像檔案夾一樣打開，不在磁碟上解壓縮任何東西。

BandiView 仍然領先的地方

  • HDR 影像的 HDR 輸出（PRO）
  • 條漫直式捲動模式和智慧雙頁漫畫模式
  • 支援 Clip Studio Paint、HEIC（PRO）和多種壓縮格式（ALZ、EGG、ISO、ZPAQ …）
  • 快速的多執行緒批次轉檔
  • 可自訂鍵盤和滑鼠快速鍵，免費版也可以

刻意不做的功能

  • 雙頁並排、由右至左的日漫模式: 一次一張，以視窗允許的最大尺寸顯示。
  • 編輯影像（裁切、調整大小、儲存）: 只顯示影像，不做修改：你的檔案保持原樣。
  • 批次轉檔或重新命名: 批次轉檔和批次重新命名交給其他 App。
