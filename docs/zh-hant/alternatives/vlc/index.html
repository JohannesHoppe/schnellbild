免費的 Mac 版 VLC 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 VLC？

Schnellbild 不是完整的媒體播放器。它把檔案夾裡的影片以縮圖形式放在照片旁邊，能播放 MKV、AVI 和 WebM，方向鍵每次跳轉影片的十分之一。Schnellbild 和 VLC 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

VLC 比較強的地方

  • 幾乎能播放所有格式、光碟（DVD/Blu-ray）、網路串流和擷取裝置
  • 可在所有桌面和行動作業系統上執行
  • 檔案和線上字幕（VLSub）、音軌、速度、濾鏡、轉檔/串流輸出
  • 已儲存的播放清單、音樂、視覺效果
  • 快速鍵完全可重新對應

Schnellbild 比較強的地方

  • 照片和影片在同一個格狀檢視中
  • 漫畫 CBZ、CBR
  • 雙窗格並排（F5 拷貝、F6 搬移）
  • 還原重新命名、搬移、丟到垃圾桶
  • 在 Apple 的 App Sandbox 中執行
  • Finder 和快速查看顯示 MKV 等格式的縮圖
