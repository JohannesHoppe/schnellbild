2345看图王 有 Mac 版嗎？這裡有替代方案

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

用 Schnellbild 取代 2345看图王？

Schnellbild 打開檔案夾即可瀏覽，不必匯入，用方向鍵翻看圖片：支援 HEIC、RAW、PSD、動態 GIF 和 PDF，檔案夾裡的影片也在同一個格狀檢視中。恭喜搬到 Mac！照片跟來了，手指的習慣也跟來了，偏偏 2345看图王 留在舊電腦上看家。不過，不必一直這樣下去。

2345看图王 的愛用者喜歡什麼，Schnellbild 又怎麼做

  • 用鍵盤翻頁: 空白鍵打開影像，← → 在檔案夾中翻頁。
  • 直接瀏覽檔案夾，不必匯入: 用 ⌘O 打開檔案夾，或直接拖到視窗上。
  • 縮圖格狀顯示，附檔案夾預覽: 檔案夾顯示其中的前幾張影像；沒有影像的檔案夾會變灰。
  • HEIC、AVIF、JPEG XL、WebP: 透過 macOS 本身的 ImageIO。
  • 相機 RAW: macOS 認得的 RAW 格式，由 macOS 顯影。
  • 動態 GIF、PNG、WebP: 會播放，也能像一般影像一樣縮放和旋轉。
  • 縮放、平移、旋轉（僅檢視）: 用 + − 或雙指開合縮放，⌥← ⌥→ 旋轉；檔案保持原樣。
  • ZIP、RAR、7z 像檔案夾一樣打開: 像檔案夾一樣打開，不在磁碟上解壓縮任何東西。

2345看图王 仍然領先的地方

  • 影像格式清單非常廣（PSD/PSB、AI、RAW、CAD、OFD）
  • 內建編輯、批次轉檔/重新命名、OCR、證件照和列印工具
  • 中國的 Windows 使用者很熟悉，快速鍵與 ACDSee 相容

刻意不做的功能

  • 編輯影像（裁切、調整大小、儲存）: 只顯示影像，不做修改：你的檔案保持原樣。
  • 批次轉檔或重新命名: 批次轉檔和批次重新命名交給其他 App。
  • 圖庫、目錄、標籤、評分: 用檔案夾代替圖庫：沒有東西要匯入。
  • 雲端同步、線上分享: 原則上絕不連網。
