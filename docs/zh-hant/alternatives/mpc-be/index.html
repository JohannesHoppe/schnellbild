MPC-BE 有 Mac 版嗎？這裡有替代方案

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 MPC-BE？

Schnellbild 不是完整的媒體播放器。它把檔案夾裡的影片以縮圖形式放在照片旁邊，能播放 MKV、AVI 和 WebM，方向鍵每次跳轉影片的十分之一。新 Mac，老片庫，搬家時唯獨 MPC-BE 沒跟上。你的 MKV 檔還在排隊等著播呢。

MPC-BE 的愛用者喜歡什麼，Schnellbild 又怎麼做

  • 用鍵盤翻頁: 空白鍵打開影像，← → 在檔案夾中翻頁。
  • 直接瀏覽檔案夾，不必匯入: 用 ⌘O 打開檔案夾，或直接拖到視窗上。
  • HEIC、AVIF、JPEG XL、WebP: 透過 macOS 本身的 ImageIO。
  • 縮放、平移、旋轉（僅檢視）: 用 + − 或雙指開合縮放，⌥← ⌥→ 旋轉；檔案保持原樣。
  • 播放 MKV、WebM、AVI、WMV、FLV: 由內建的 VLC 引擎播放。
  • 影片內嵌字幕: 按 V 開關字幕，⌃⌘S 選擇字幕軌道；播放到一半才打開，也會立刻顯示正在進行的那一句，ASS 字幕保留其樣式。
  • 選擇音軌: ⌃⌘A 或控制列。
  • 播放速度: < 和 > 從 0.5× 到 2×，人聲音調不變。

MPC-BE 仍然領先的地方

  • 輕巧的 Windows 播放器，更新頻繁
  • 深色主題，許多呈現器和解碼器選項
  • 字幕下載、yt-dlp 串流
  • 老闆鍵、可設定的按鍵

刻意不做的功能

  • 載入影片旁的字幕檔: 只讀取影片本身，不讀旁邊的檔案。
  • 儲存播放清單: 用檔案夾代替播放清單：清單由幻燈片秀產生。
  • 音訊檔、音樂模式: 只處理影像和影片；音訊檔用專屬的 App 打開。
  • 播放網路串流和網址: 原則上絕不連網。
  • 從網路下載字幕: 原則上絕不連網。
