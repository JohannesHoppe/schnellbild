新 Mac，老片庫，搬家時唯獨 GOM Player 沒跟上。你的 MKV 檔還在排隊等著播呢。

價格免費，有廣告；無廣告的 GOM Player+：永久授權（韓國售價 ₩11,000）或 GOM Easy Pass 訂閱（每月 $4.90 起）；AI 功能使用點數

GOM Player 的 Mac 版自 2020 年起一直停在 1.0.0，是為 Intel Mac 建置的。

GOM Player 擅長什麼

GOM Player 是韓國很受歡迎的免費 Windows 媒體播放器，有龐大的線上字幕庫、AI 語音轉字幕、360° VR、A-B 段重複播放和外觀主題；免費版有廣告，GOM Player+ 則沒有。另有以 mpv 為基礎的 Mac 版，但自 2020 年以來未再更新，而且只支援 Intel。

GOM Player 的愛用者喜歡什麼，Schnellbild 又怎麼做

  • 用鍵盤翻頁: 空白鍵打開影像，← → 在檔案夾中翻頁。
  • 直接瀏覽檔案夾，不必匯入: 用 ⌘O 打開檔案夾，或直接拖到視窗上。
  • 動態 GIF、PNG、WebP: 會播放，也能像一般影像一樣縮放和旋轉。
  • 縮放、平移、旋轉（僅檢視）: 用 + − 或雙指開合縮放，⌥← ⌥→ 旋轉；檔案保持原樣。
  • 播放 MKV、WebM、AVI、WMV、FLV: 由內建的 VLC 引擎播放。
  • 影片內嵌字幕: 按 V 開關字幕，⌃⌘S 選擇字幕軌道。
  • 選擇音軌: ⌃⌘A 或控制列。
  • 播放速度: < 和 > 從 0.5× 到 2×，人聲音調不變。

GOM Player 仍然領先的地方

  • 龐大的線上字幕庫和 AI 字幕產生
  • 360° VR 播放、A-B 和多段重複播放
  • 串流網址和 YouTube
  • 音樂播放，附等化器
  • GOM Player+：同時播放四部影片、AI 放大解析度

刻意不做的功能

  • 載入影片旁的字幕檔: 只讀取影片本身，不讀旁邊的檔案。
  • 儲存播放清單: 用檔案夾代替播放清單：清單由幻燈片秀產生。
  • 子母畫面: 它為瀏覽檔案夾而做；想邊做事邊看，影片播放器更合適。
  • 音訊檔、音樂模式: 只處理影像和影片；音訊檔用專屬的 App 打開。
  • 播放網路串流和網址: 原則上絕不連網。
  • 從網路下載字幕: 原則上絕不連網。
