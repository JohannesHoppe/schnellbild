你的漫畫二話不說就跟著搬到了 Mac。CDisplayEx 卻沒擠上這班車。

價格桌面版免費；Android Lite（有廣告）和 Premium（付費）

最近更新2015-06-20（桌面版；開發者表示桌面版已停止開發）
平台Windows、Android

CDisplayEx 擅長什麼

CDisplayEx 是老牌的輕量 Windows 漫畫閱讀器，CDisplay 的後繼者，以載入快速、Lanczos 縮放和完全可自訂的按鍵著稱。桌面版已不再開發；開發重心轉到 Android App。

CDisplayEx 的愛用者喜歡什麼，Schnellbild 又怎麼做

  • 用鍵盤翻頁: 空白鍵打開影像，← → 在檔案夾中翻頁。
  • 縮圖格狀顯示，附檔案夾預覽: 檔案夾顯示其中的前幾張影像；沒有影像的檔案夾會變灰。
  • HEIC、AVIF、JPEG XL、WebP: 透過 macOS 本身的 ImageIO。
  • 動態 GIF、PNG、WebP: 會播放，也能像一般影像一樣縮放和旋轉。
  • 縮放、平移、旋轉（僅檢視）: 用 + − 或雙指開合縮放，⌥← ⌥→ 旋轉；檔案保持原樣。
  • ZIP、RAR、7z 像檔案夾一樣打開: 像檔案夾一樣打開，不在磁碟上解壓縮任何東西。
  • 漫畫 CBZ、CBR: CBZ 和 CBR 像檔案夾一樣打開；用 ← → 翻頁。
  • 幻燈片秀: 按 S 開始，空白鍵暫停。

CDisplayEx 仍然領先的地方

  • 每個功能都能設定成你自己的按鍵
  • 針對舊掃描檔的自動色彩校正和 Gamma 調整
  • 雙頁和日式（由右至左）模式
  • 在 Windows 檔案總管中顯示漫畫檔縮圖

刻意不做的功能

  • 雙頁並排、由右至左的日漫模式: 一次一張，以視窗允許的最大尺寸顯示。
