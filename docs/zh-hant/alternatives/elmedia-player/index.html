免費的 Mac 版 Elmedia Player 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 Elmedia Player？

Schnellbild 不是完整的媒體播放器。它把檔案夾裡的影片以縮圖形式放在照片旁邊，能播放 MKV、AVI 和 WebM，方向鍵每次跳轉影片的十分之一。Schnellbild 和 Elmedia Player 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

Elmedia Player 比較強的地方

  • 串流到智慧電視、Chromecast、Roku、DLNA；AirPlay 接收器
  • 音樂播放，附等化器和視覺效果
  • 線上影片和 OpenSubtitles 搜尋
  • 可移動的獨立控制視窗、色彩主題、自訂快速鍵

Schnellbild 比較強的地方

  • 照片和影片在同一個格狀檢視中
  • ZIP、RAR、7z 像檔案夾一樣打開
  • 漫畫 CBZ、CBR
  • 直接播放壓縮檔中的影片
  • 雙窗格並排（F5 拷貝、F6 搬移）
  • 幻燈片秀涵蓋所有子檔案夾，照片和影片混合播放
  • 在所有子檔案夾中搜尋名稱

Elmedia Player 擅長什麼
