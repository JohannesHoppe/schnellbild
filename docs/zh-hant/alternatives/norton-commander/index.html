Norton Commander 有 Mac 版嗎？這裡有替代方案

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 Norton Commander？

Schnellbild 不是檔案管理器，而是有兩個窗格的看圖軟體：F5 把標記的圖片拷貝到另一個窗格，F6 移動過去，兩者都能還原。兩個窗格、一排功能鍵，手指的記憶比有些同事的年資還久。然後換了 Mac，Norton Commander 被擋在門外。

Norton Commander 的愛用者喜歡什麼，Schnellbild 又怎麼做

  • 用鍵盤翻頁: 空白鍵打開影像，← → 在檔案夾中翻頁。
  • 直接瀏覽檔案夾，不必匯入: 用 ⌘O 打開檔案夾，或直接拖到視窗上。
  • ZIP、RAR、7z 像檔案夾一樣打開: 像檔案夾一樣打開，不在磁碟上解壓縮任何東西。
  • 雙窗格並排（F5 拷貝、F6 搬移）: 按 D 顯示雙窗格，F5 拷貝，F6 搬移。
  • 重新命名、丟到垃圾桶、新增檔案夾: Return 或 F2 重新命名，⌘⌫ 丟到垃圾桶，⇧⌘N 新增檔案夾。
  • 拖到檔案夾中搬移和拷貝: 把縮圖拖到檔案夾上。
  • 在所有子檔案夾中搜尋名稱: 搜尋欄位（⌘F）會搜尋整個檔案夾及所有子檔案夾。
  • 分欄列表顯示: 按 L 在格狀和列表之間切換。

Norton Commander 仍然領先的地方

  • 確立了雙窗格、F 鍵操作的工作流程
  • 文字模式下極小又快速
  • 目錄同步，以及結果可顯示在窗格中的檔案搜尋

平台MS-DOS、Windows（NC for Windows 2.01）、OS/2

MS-DOS 上元祖級的經典雙窗格檔案管理器（1986 到 1998 年），確立了 F3 檢視、F5 拷貝、F6 搬移的配置，Total Commander、Midnight Commander 等許多軟體都沿用至今。出於懷舊，至今仍有很多人搜尋；現在只能在 DOS 或模擬器中執行。
