免費的 Mac 版 Phiewer 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 Phiewer？

Schnellbild 打開檔案夾即可瀏覽，不必匯入，用方向鍵翻看圖片：支援 HEIC、RAW、PSD、動態 GIF 和 PDF，檔案夾裡的影片也在同一個格狀檢視中。Schnellbild 和 Phiewer 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

Phiewer 比較強的地方

  • 重複檔案搜尋，最多 9 張影像的比較檢視
  • Showcases：跨檔案夾儲存的虛擬相簿
  • Finder 標籤和註解，可依標籤/EXIF/日期搜尋
  • 音訊檔和列印
  • PRO 可編輯影像（裁切、濾鏡、調整大小）
  • 劇院模式

Schnellbild 比較強的地方

  • ZIP、RAR、7z 像檔案夾一樣打開
  • 漫畫 CBZ、CBR
  • 直接播放壓縮檔中的影片
  • 雙窗格並排（F5 拷貝、F6 搬移）
  • 開放原始碼
  • 絕不連網
  • Finder 和快速查看顯示 MKV 等格式的縮圖
