免費的 Mac 版 nomacs 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 nomacs？

Schnellbild 打開檔案夾即可瀏覽，不必匯入，用方向鍵翻看圖片：支援 HEIC、RAW、PSD、動態 GIF 和 PDF，檔案夾裡的影片也在同一個格狀檢視中。Schnellbild 和 nomacs 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

nomacs 比較強的地方

  • 批次處理和基本影像編輯
  • 同步多個視窗以比較影像
  • 詮釋資料面板、直方圖和星級評分
  • 外掛（繪圖、合成、變形）
  • 可在 Windows、Linux、FreeBSD 和 Haiku 上執行

Schnellbild 比較強的地方

  • 照片和影片在同一個格狀檢視中
  • 播放 MKV、WebM、AVI、WMV、FLV
  • 直接播放壓縮檔中的影片
  • 用方向鍵快速瀏覽影片
  • 還原重新命名、搬移、丟到垃圾桶
  • 絕不連網
  • 在 Apple 的 App Sandbox 中執行

nomacs 擅長什麼

nomacs（「Image Lounge」）是免費、開放原始碼的看圖軟體，支援 RAW 和 PSD，有詮釋資料面板、影像調整和批次處理。特色是可同步多個視窗，並排比較影像。目前有 Apple 晶片和 Intel 的 macOS 版本，但沒有經過公證。
