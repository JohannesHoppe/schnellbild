免費的 Mac 版 OpenComic 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 OpenComic？

Schnellbild 像打開檔案夾一樣打開 CBZ、CBR、ZIP、RAR 和 7z，不往磁碟上解壓縮任何東西，用方向鍵翻頁。Schnellbild 和 OpenComic 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

OpenComic 比較強的地方

  • 支援多種格式，包括 EPUB、MOBI、SVG、JPEG XL、ACE/LZH 壓縮檔
  • 日漫、條漫、雙頁和導覽檢視
  • 直接連線 SMB/FTP/SFTP/WebDAV/S3 和 OPDS
  • AI 放大解析度、去網紋和去除壓縮雜訊
  • 分頁和多視窗；自訂快速鍵和遊戲手把

Schnellbild 比較強的地方

  • 照片和影片在同一個格狀檢視中
  • 播放 MKV、WebM、AVI、WMV、FLV
  • 直接播放壓縮檔中的影片
  • 雙窗格並排（F5 拷貝、F6 搬移）
  • 幻燈片秀涵蓋所有子檔案夾，照片和影片混合播放
  • 用方向鍵快速瀏覽影片
  • 還原重新命名、搬移、丟到垃圾桶
