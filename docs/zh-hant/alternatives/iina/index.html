免費的 Mac 版 IINA 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 IINA？

Schnellbild 不是完整的媒體播放器。它把檔案夾裡的影片以縮圖形式放在照片旁邊，能播放 MKV、AVI 和 WebM，方向鍵每次跳轉影片的十分之一。Schnellbild 和 IINA 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

IINA 比較強的地方

  • 完整的播放功能：章節、逐格、A-B 循環、子母畫面、音樂模式
  • 線上字幕搜尋和智慧比對本機字幕
  • 外掛、mpv 設定和腳本、瀏覽器延伸功能
  • 支援 macOS 12 和 Intel Mac
  • 進度列縮圖、播放記錄和續播

Schnellbild 比較強的地方

  • 照片和影片在同一個格狀檢視中
  • ZIP、RAR、7z 像檔案夾一樣打開
  • 漫畫 CBZ、CBR
  • 雙窗格並排（F5 拷貝、F6 搬移）
  • 幻燈片秀涵蓋所有子檔案夾，照片和影片混合播放
  • 還原重新命名、搬移、丟到垃圾桶
  • 絕不連網

IINA 擅長什麼

IINA 是以 mpv 為基礎的免費、開放原始碼 macOS 影片播放器，有現代化的 Mac 介面。它擅長看片：字幕（包括線上搜尋）、子母畫面、音樂模式、播放清單、進度列縮圖和外掛。
