免費的 Mac 版 ImageGlass 替代軟體

Schnellbild 和 ImageGlass 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

ImageGlass 擅長什麼

快速的開放原始碼看圖軟體，v10 以 .NET/Avalonia 重新打造，支援 Windows、macOS（Apple 晶片）和 Linux。格式支援廣（90 多種，包括 RAW、JXL、HEIC、AVIF、HDR、原生 SVG），有智慧快取、佈景主題、自訂快速鍵和解碼器外掛。它是附縮圖列的單張看圖器，不是檔案夾瀏覽器，也不播放影片。

ImageGlass 比較強的地方

  • 同一套程式碼在 Windows、macOS 和 Linux 上執行
  • AVIF、JPEG XL、HDR 和 EXR 的 HDR 色調對應
  • 原生呈現動態 SVG
  • 解碼器外掛 SDK，可支援更多格式
  • 內建裁切、調整大小和取色器
  • 佈景主題和自訂版面
  • 免費版即可自訂快速鍵

Schnellbild 比較強的地方

  • 照片和影片在同一個格狀檢視中
  • 播放 MKV、WebM、AVI、WMV、FLV
  • ZIP、RAR、7z 像檔案夾一樣打開
  • 漫畫 CBZ、CBR
  • 直接播放壓縮檔中的影片
  • 雙窗格並排（F5 拷貝、F6 搬移）
  • 在所有子檔案夾中搜尋名稱
