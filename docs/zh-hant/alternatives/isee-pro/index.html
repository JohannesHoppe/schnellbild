免費的 Mac 版 iSee Pro 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 iSee Pro？

Schnellbild 打開檔案夾即可瀏覽，不必匯入，用方向鍵翻看圖片：支援 HEIC、RAW、PSD、動態 GIF 和 PDF，檔案夾裡的影片也在同一個格狀檢視中。Schnellbild 和 iSee Pro 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

iSee Pro 比較強的地方

  • 非常便宜（Pro $0.99）又小巧（4.4 MB）
  • 記住壓縮檔密碼
  • 可依影像尺寸和 Draw Things 參數搜尋
  • 動態桌布/桌面功能

Schnellbild 比較強的地方

  • 照片和影片在同一個格狀檢視中
  • 播放 MKV、WebM、AVI、WMV、FLV
  • 直接播放壓縮檔中的影片
  • 雙窗格並排（F5 拷貝、F6 搬移）
  • 自動增強和滑桿，不更動檔案
  • 用方向鍵快速瀏覽影片
  • 開放原始碼

iSee Pro 是 Mac App Store 上的小型看圖軟體，會載入檔案夾及其子檔案夾中的所有影像，並預先讀取以便快速翻頁。有列表、縮圖和原尺寸檢視，可依名稱/大小/日期搜尋，有 EXIF 疊加資訊和放大鏡，能打開 ZIP/RAR 壓縮檔並記住密碼。需要 macOS 12。
