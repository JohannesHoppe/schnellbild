美图看看 有 Mac 版嗎？這裡有替代方案

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 美图看看？

Schnellbild 打開檔案夾即可瀏覽，不必匯入，用方向鍵翻看圖片：支援 HEIC、RAW、PSD、動態 GIF 和 PDF，檔案夾裡的影片也在同一個格狀檢視中。恭喜搬到 Mac！照片跟來了，手指的習慣也跟來了，偏偏 美图看看 留在舊電腦上看家。不過，不必一直這樣下去。

美图看看 的愛用者喜歡什麼，Schnellbild 又怎麼做

  • 用鍵盤翻頁: 空白鍵打開影像，← → 在檔案夾中翻頁。
  • 直接瀏覽檔案夾，不必匯入: 用 ⌘O 打開檔案夾，或直接拖到視窗上。
  • 縮圖格狀顯示，附檔案夾預覽: 檔案夾顯示其中的前幾張影像；沒有影像的檔案夾會變灰。
  • 相機 RAW: macOS 認得的 RAW 格式，由 macOS 顯影。
  • 動態 GIF、PNG、WebP: 會播放，也能像一般影像一樣縮放和旋轉。
  • 縮放、平移、旋轉（僅檢視）: 用 + − 或雙指開合縮放，⌥← ⌥→ 旋轉；檔案保持原樣。
  • 幻燈片秀: 按 S 開始，空白鍵暫停。
  • 檔案資訊：EXIF、編解碼器、位元率: 按 I 顯示格式、相機、編解碼器和位元率，在小地圖上顯示拍攝地點，以及每一個中繼資料鍵。

美图看看 仍然領先的地方

  • 極小，在舊電腦上也很輕快
  • 一次顯示所有子檔案夾中的全部影像（穿透文件夹）
  • CMYK 的 PSD 顯示效果和 Photoshop 一樣

刻意不做的功能

  • 編輯影像（裁切、調整大小、儲存）: 只顯示影像，不做修改：你的檔案保持原樣。
  • 批次轉檔或重新命名: 批次轉檔和批次重新命名交給其他 App。
  • 雲端同步、線上分享: 原則上絕不連網。
