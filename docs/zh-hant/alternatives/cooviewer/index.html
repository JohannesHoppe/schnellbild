免費的 Mac 版 cooViewer 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 cooViewer？

Schnellbild 像打開檔案夾一樣打開 CBZ、CBR、ZIP、RAR 和 7z，不往磁碟上解壓縮任何東西，用方向鍵翻頁。Schnellbild 和 cooViewer 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

cooViewer 比較強的地方

  • 專門的漫畫閱讀器：由右至左雙頁跨頁，自動偵測單頁，每本書分別儲存
  • 具名頁面書籤，每本書記住上次的頁面
  • 每個按鍵和滑鼠動作都能自訂，預設可單手操作
  • 能打開極多種壓縮格式，包括分割的 RAR/ZIP 和有密碼的壓縮檔
  • Core Image 檢視濾鏡、放大鏡
  • CBZ/CBR/ZIP/RAR/7z 在 Finder 中有縮圖和快速查看

Schnellbild 比較強的地方

  • 照片和影片在同一個格狀檢視中
  • 播放 MKV、WebM、AVI、WMV、FLV
  • 直接播放壓縮檔中的影片
  • 雙窗格並排（F5 拷貝、F6 搬移）
  • 在所有子檔案夾中搜尋名稱
  • 用方向鍵快速瀏覽影片
  • 還原重新命名、搬移、丟到垃圾桶

cooViewer 擅長什麼

價格免費
版本1.7.1（ysmx 分支）；coo-ona 原版停在 1.2b25（2020）
最近更新2026-10-30
平台macOS

老牌的日本 Mac 漫畫檢視器，現在由持續更新的開放原始碼分支維護，提供通用二進位檔。可將檔案夾、PDF 和幾乎所有壓縮檔（ZIP、RAR、7z、LHA、分割壓縮檔、有密碼的壓縮檔）當成一本書打開，支援由右至左的跨頁、頁面書籤、可自由設定的按鍵和滑鼠操作，以及 Finder 中的漫畫壓縮檔縮圖。
