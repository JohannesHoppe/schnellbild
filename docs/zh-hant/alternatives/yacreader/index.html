免費的 Mac 版 YACReader 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 YACReader？

Schnellbild 像打開檔案夾一樣打開 CBZ、CBR、ZIP、RAR 和 7z，不往磁碟上解壓縮任何東西，用方向鍵翻頁。Schnellbild 和 YACReader 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

YACReader 比較強的地方

  • 完整的漫畫書庫：Comic Vine 詮釋資料、閱讀清單、智慧清單、評分
  • 伺服器和 iOS/Android App，閱讀進度同步
  • 日漫模式、雙頁、條漫用的連續捲動
  • 舊掃描檔可調整亮度/對比/Gamma
  • 12 種主題加主題編輯器；可重新指定快速鍵
  • 有 Windows 和 Linux 版

Schnellbild 比較強的地方

  • 照片和影片在同一個格狀檢視中
  • 播放 MKV、WebM、AVI、WMV、FLV
  • 直接播放壓縮檔中的影片
  • 雙窗格並排（F5 拷貝、F6 搬移）
  • 幻燈片秀涵蓋所有子檔案夾，照片和影片混合播放
  • 用方向鍵快速瀏覽影片
  • 絕不連網

YACReader 是漫畫閱讀器加上書庫管理器（YACReaderLibrary），適合大型收藏，有 Comic Vine 詮釋資料、閱讀清單，以及供行動 App 使用的家用伺服器。閱讀器提供雙頁、日漫和連續捲動模式，還能調整影像。
