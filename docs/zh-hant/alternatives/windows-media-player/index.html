Windows Media Player 有 Mac 版嗎？這裡有替代方案

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 Windows Media Player？

Schnellbild 不是完整的媒體播放器。它把檔案夾裡的影片以縮圖形式放在照片旁邊，能播放 MKV、AVI 和 WebM，方向鍵每次跳轉影片的十分之一。新 Mac，老片庫，搬家時唯獨 Windows Media Player 沒跟上。你的 MKV 檔還在排隊等著播呢。

Windows Media Player 的愛用者喜歡什麼，Schnellbild 又怎麼做

  • 用鍵盤翻頁: 空白鍵打開影像，← → 在檔案夾中翻頁。
  • 縮放、平移、旋轉（僅檢視）: 用 + − 或雙指開合縮放，⌥← ⌥→ 旋轉；檔案保持原樣。
  • 播放 MKV、WebM、AVI、WMV、FLV: 由內建的 VLC 引擎播放。
  • 影片內嵌字幕: 按 V 開關字幕，⌃⌘S 選擇字幕軌道；播放到一半才打開，也會立刻顯示正在進行的那一句，ASS 字幕保留其樣式。
  • 選擇音軌: ⌃⌘A 或控制列。
  • 播放速度: < 和 > 從 0.5× 到 2×，人聲音調不變。
  • 用方向鍵快速瀏覽影片: ← → 跳轉影片的十分之一，加 ⇧ 跳轉百分之一。
  • 檔案資訊：EXIF、編解碼器、位元率: 按 I 顯示格式、相機、編解碼器和位元率，在小地圖上顯示拍攝地點，以及每一個中繼資料鍵。

Windows Media Player 仍然領先的地方

  • Windows 預先安裝，不必設定
  • 音樂庫，附專輯封面、播放清單和 CD 轉錄
  • 迷你播放器、投放到裝置
  • 跟隨 Windows 的字幕和主題設定

刻意不做的功能

  • 載入影片旁的字幕檔: 只讀取影片本身，不讀旁邊的檔案。
  • 儲存播放清單: 用檔案夾代替播放清單：清單由幻燈片秀產生。
  • 子母畫面: 它為瀏覽檔案夾而做；想邊做事邊看，影片播放器更合適。
  • 音訊檔、音樂模式: 只處理影像和影片；音訊檔用專屬的 App 打開。
  • 批次轉檔或重新命名: 批次轉檔和批次重新命名交給其他 App。
  • 圖庫、目錄、標籤、評分: 用檔案夾代替圖庫：沒有東西要匯入。

Windows Media Player 擅長什麼

價格隨 Windows 附贈；HEVC 視訊延伸模組 $0.99，其他解碼器為 Store 附加元件
版本媒體播放器 11.2610.5.0（Insider，2026 年 11 月）；Windows Media Player 舊版 12
最近更新2026-11（Insider 版本資訊）
平台Windows

Windows 內建的播放器：以音樂為主的媒體庫 App，也能播放本機影片，有字幕、音軌、播放速度、畫面調整、迷你播放器和投放。HEVC 和 AV1 需要付費或從 Store 取得的附加元件，評測認為它比經典的 Windows Media Player 舊版更慢、更笨重，Microsoft 仍將舊版保留為選用功能。
