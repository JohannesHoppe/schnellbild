免費的 Mac 版 mpv 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 mpv？

Schnellbild 不是完整的媒體播放器。它把檔案夾裡的影片以縮圖形式放在照片旁邊，能播放 MKV、AVI 和 WebM，方向鍵每次跳轉影片的十分之一。Schnellbild 和 mpv 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

mpv 比較強的地方

  • 以 gpu-next、HDR、Dolby Vision 呈現影片
  • 可透過 mpv.conf、input.conf 和腳本高度自訂
  • 直接播放 ZIP/RAR/7z 和多卷 RAR 中的媒體
  • 跨平台（macOS、Windows、Linux）
  • 透過 yt-dlp 播放串流和 YouTube，支援 DVD/Blu-ray 選單

Schnellbild 比較強的地方

  • 照片和影片在同一個格狀檢視中
  • 雙窗格並排（F5 拷貝、F6 搬移）
  • 在所有子檔案夾中搜尋名稱
  • 還原重新命名、搬移、丟到垃圾桶
  • 在 Apple 的 App Sandbox 中執行
  • Finder 和快速查看顯示 MKV 等格式的縮圖
  • 老闆鍵（一鍵隱藏所有視窗）

mpv 擅長什麼

mpv 是極簡、可用腳本控制的命令列媒體播放器，支援 GPU 呈現（HDR、Dolby Vision），格式支援極廣。透過文字檔和 Lua/JS 腳本設定，畫面上只有小小的控制器。
