免費的 Mac 版 Double Commander 替代軟體

Schnellbild 是一款免費的 Mac App，用來看你檔案夾裡的圖片和影片：打開檔案夾，縮圖馬上就在，按一個鍵就能放大看圖。它能播放 MKV、AVI 和 WebM，像打開檔案夾一樣打開 ZIP 和 RAR 壓縮檔，不需帳號，也不連網。

免費下載Schnellbild.dmg Mac App Store即將上架，用來支持開發

用 Schnellbild 取代 Double Commander？

Schnellbild 不是檔案管理器，而是有兩個窗格的看圖軟體：F5 把標記的圖片拷貝到另一個窗格，F6 移動過去，兩者都能還原。Schnellbild 和 Double Commander 並排比較：先看各自的強項，再逐項列出每個功能和資料來源。

Schnellbild 不是完整的檔案管理器：沒有 FTP、SFTP 或雲端連線，沒有檔案夾同步，也不能建立壓縮檔。它是為瀏覽和整理照片與影片而做的：所有東西都有縮圖，雙窗格並排，F5 拷貝、F6 搬移，壓縮檔像檔案夾一樣打開。

Double Commander 比較強的地方

  • Mac 上完整的 Total Commander 式檔案管理器：同步目錄、批次重新命名、校驗和、FTP/SFTP
  • 可執行 Total Commander 外掛（WCX/WDX/WFX/WLX）
  • 跨平台（macOS、Windows、Linux）
  • 檢視器可裁切、調整大小和儲存影像
  • Lua 腳本和工具列自訂

Schnellbild 比較強的地方

  • 幻燈片秀涵蓋所有子檔案夾，照片和影片混合播放
  • 自動增強和滑桿，不更動檔案
  • 還原重新命名、搬移、丟到垃圾桶
  • 絕不連網
  • 在 Apple 的 App Sandbox 中執行
  • Finder 和快速查看顯示 MKV 等格式的縮圖
  • 提醒副檔名與內容不符的檔案
