Politique de confidentialité

Schnellbild est une visionneuse d’images et de vidéos pour macOS. Le responsable du traitement au sens du RGPD est HAUS HOPPE - ITS, Johannes Hoppe ; l’adresse complète figure dans les mentions légales. La présente politique couvre l’app, qu’elle soit téléchargée depuis GitHub ou achetée sur le Mac App Store (il s’agit de la même app), ainsi que ce site web.

L’app

Schnellbild ne collecte aucune donnée personnelle. Elle n’a ni compte, ni mesure d’audience, ni publicité, ni pistage, et ne se connecte pas à Internet : l’App Sandbox dans laquelle elle s’exécute ne lui donne aucun accès réseau.

Ce qui reste sur votre Mac, et uniquement là :

  • Réglages (dernier dossier, ordre de tri, signets, volume…) dans les préférences propres à l’app.
  • Accès aux dossiers : les dossiers que vous avez ouverts à Schnellbild, sous forme de signets macOS, pour qu’elle puisse les afficher à nouveau après un redémarrage. Réglages → Oublier l’accès aux dossiers les oublie.
  • Mots de passe des archives que vous avez saisis, dans votre trousseau de session (élément « Schnellbild archive passwords ») ; Réglages → Oublier les mots de passe enregistrés les supprime.
  • Vignettes, dans le cache de vignettes de macOS.

Schnellbild lit vos images, vidéos et archives uniquement pour vous les montrer. Elle ne les envoie jamais nulle part, pas plus que leurs noms ou quoi que ce soit les concernant. Apple gère le téléchargement et l’achat conformément à sa propre politique de confidentialité et ne nous transmet que des chiffres qui ne vous identifient pas : les ventes et, si vous avez autorisé dans macOS le partage avec les développeurs d’apps, des rapports de plantage et des statistiques d’utilisation.

Ce site web

Ce site web n’utilise ni cookies, ni outil de mesure d’audience, ni contenu provenant d’autres serveurs (pas de polices web, pas de vidéos intégrées). Il est hébergé sur GitHub Pages, un service de GitHub, Inc. (États-Unis). Lorsque vous le consultez, GitHub enregistre et conserve votre adresse IP à des fins de sécurité ; voir GitHub Pages : collecte de données et la déclaration de confidentialité de GitHub. La durée de conservation de ces journaux est fixée par GitHub ; nous n’y avons pas accès. GitHub adhère au cadre de protection des données UE-États-Unis (EU-U.S. Data Privacy Framework), pour lequel la Commission européenne a constaté que les États-Unis assurent un niveau de protection adéquat (art. 45 du RGPD). La base juridique est notre intérêt légitime à fournir le site web de manière sécurisée (art. 6, par. 1, point f) du RGPD). Le téléchargement de l’app provient lui aussi de GitHub.

Vos droits

En vertu du RGPD, vous disposez d’un droit d’accès, de rectification, d’effacement, de limitation du traitement et de portabilité des données, ainsi que du droit d’introduire une réclamation auprès d’une autorité de contrôle chargée de la protection des données. Vous avez le droit de vous opposer, pour des raisons tenant à votre situation particulière, au traitement fondé sur notre intérêt légitime (art. 21 du RGPD). Comme ni l’app ni ce site web ne conservent eux-mêmes de données personnelles, il n’y a absolument rien à consulter ni à supprimer de notre côté. Une demande d’accès recevra donc une réponse très courte : nous ne savons absolument rien de vous.
