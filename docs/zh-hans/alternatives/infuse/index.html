用 Schnellbild 代替 Infuse？

Schnellbild 不是完整的媒体播放器。它把文件夹里的视频以缩略图形式放在照片旁边，能播放 MKV、AVI 和 WebM，方向键每次跳转视频的十分之一。Schnellbild 与 Infuse 并排对比：先看各自强在哪里，再逐项列出所有功能及来源。

Infuse 更强的地方

  • 带 TMDB 海报和元数据的电影/剧集媒体库
  • 从 NAS、媒体服务器和云服务串流
  • 在 iPhone、iPad、Apple TV、Mac 和 Vision Pro 间同步进度
  • OpenSubtitles 下载、Trakt 同步、AirPlay 和 Google Cast
  • 光盘映像（ISO、VIDEO_TS、BDMV）

Schnellbild 更强的地方

  • 照片和视频在同一网格中
  • ZIP、RAR、7z 像文件夹一样打开
  • 漫画 CBZ、CBR
  • 直接播放归档中的视频
  • 双窗格并排显示（F5 拷贝，F6 移动）
  • 幻灯片涵盖所有子文件夹，照片和视频混合播放
  • 自动增强和滑块，不改动文件
