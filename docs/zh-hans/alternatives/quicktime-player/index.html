免费的 Mac 版 QuickTime Player 替代软件

Schnellbild 是一款免费的 Mac 应用，用来看你文件夹里的图片和视频：打开文件夹，缩略图马上就在，按一个键就能放大看图。它能播放 MKV、AVI 和 WebM，像打开文件夹一样打开 ZIP 和 RAR 压缩包，无需账户，也不联网。

用 Schnellbild 代替 QuickTime Player？

Schnellbild 不是完整的媒体播放器。它把文件夹里的视频以缩略图形式放在照片旁边，能播放 MKV、AVI 和 WebM，方向键每次跳转视频的十分之一。Schnellbild 与 QuickTime Player 并排对比：先看各自强在哪里，再逐项列出所有功能及来源。

QuickTime Player 更强的地方

  • 已经安装好，无需下载
  • 录制屏幕、影片和音频
  • 简单的视频编辑：修剪、分割、旋转、移除音频、导出
  • 画中画和空间视频

Schnellbild 更强的地方

  • 直接浏览文件夹，无需导入
  • 照片和视频在同一网格中
  • 播放 MKV、WebM、AVI、WMV、FLV
  • ZIP、RAR、7z 像文件夹一样打开
  • 漫画 CBZ、CBR
  • 直接播放归档中的视频
  • 双窗格并排显示（F5 拷贝，F6 移动）
