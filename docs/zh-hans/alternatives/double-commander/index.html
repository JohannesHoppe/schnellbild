免费的 Mac 版 Double Commander 替代软件

Schnellbild 是一款免费的 Mac 应用，用来看你文件夹里的图片和视频：打开文件夹，缩略图马上就在，按一个键就能放大看图。它能播放 MKV、AVI 和 WebM，像打开文件夹一样打开 ZIP 和 RAR 压缩包，无需账户，也不联网。

用 Schnellbild 代替 Double Commander？

Schnellbild 不是文件管理器，而是有两个窗格的看图软件：F5 把标记的图片拷贝到另一个窗格，F6 移动过去，两者都能撤销。Schnellbild 与 Double Commander 并排对比：先看各自强在哪里，再逐项列出所有功能及来源。

Schnellbild 不是完整的文件管理器：没有 FTP、SFTP 或云连接，没有文件夹同步，也不能打包归档。它是为浏览和整理照片与视频而做的：所有文件都有缩略图，双窗格并排显示，F5 拷贝、F6 移动，归档像文件夹一样打开。

Double Commander 更强的地方

  • Mac 上完整的 Total Commander 式文件管理器：目录同步、批量重命名、校验和、FTP/SFTP
  • 可运行 Total Commander 插件（WCX/WDX/WFX/WLX）
  • 跨平台（macOS、Windows、Linux）
  • 查看器可裁剪、调整大小和保存图像
  • Lua 脚本和工具栏自定义

Schnellbild 更强的地方

  • 幻灯片涵盖所有子文件夹，照片和视频混合播放
  • 自动增强和滑块，不改动文件
  • 撤销重新命名、移动、移到废纸篓
  • 从不联网
  • 运行在 Apple 的 App Sandbox 中
  • 访达和快速查看中显示 MKV 等格式的缩略图
  • 提示扩展名与内容不符的文件
