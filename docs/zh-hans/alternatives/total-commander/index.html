想找 Total Commander Mac 版？这里有替代软件

Schnellbild 是一款免费的 Mac 应用，用来看你文件夹里的图片和视频：打开文件夹，缩略图马上就在，按一个键就能放大看图。它能播放 MKV、AVI 和 WebM，像打开文件夹一样打开 ZIP 和 RAR 压缩包，无需账户，也不联网。

用 Schnellbild 代替 Total Commander？

Schnellbild 不是文件管理器，而是有两个窗格的看图软件：F5 把标记的图片拷贝到另一个窗格，F6 移动过去，两者都能撤销。双窗格、功能键，这套手感你练了多少年？换到 Mac 以后，偏偏 Total Commander 没能跟过来。

Total Commander 的用户喜欢什么，Schnellbild 又是怎么做的

  • 用键盘翻页: 空格键打开图片，← → 在文件夹中翻页。
  • 直接浏览文件夹，无需导入: 用 ⌘O 打开文件夹，或把它拖到窗口上。
  • 带文件夹预览的缩略图网格: 文件夹显示其中的头几张图片；没有图片的文件夹显示为灰色。
  • HEIC、AVIF、JPEG XL、WebP: 通过 macOS 自带的 ImageIO。
  • 相机 RAW: macOS 认识的 RAW 格式，由 macOS 冲印。
  • 动态 GIF、PNG、WebP: 可以播放，也能像普通图片一样缩放和旋转。
  • 缩放、平移、旋转（仅限显示）: + − 或双指捏合缩放，⌥← ⌥→ 旋转；文件保持原样。
  • ZIP、RAR、7z 像文件夹一样打开: 像文件夹一样打开，不向磁盘解压任何内容。

Total Commander 依然领先的地方

  • 双窗格文件管理：目录同步、比较、批量重命名、校验和
  • 内置 FTP/FTPS 客户端
  • 庞大的插件生态（Lister、打包、文件系统插件）
  • Lister 播放器可切换字幕/音轨和速度
  • 可在 Windows 95 到 11 上运行，另有免费的 Android App

有意不做的功能

  • 加载视频旁边的字幕文件: 只读取视频本身，不碰旁边的任何文件。
  • 音频文件，音乐模式: 只管图片和视频；音频文件用专门的 App 打开。
  • 批量转换或重新命名: 批量转换和批量重命名交给其他应用。
  • 图库、目录、标签、评分: 用文件夹代替图库：没有什么需要导入。
  • 云同步、在线分享: 原则上从不联网。
