免费的 Mac 版 看图 Kantu 替代软件

Schnellbild 是一款免费的 Mac 应用，用来看你文件夹里的图片和视频：打开文件夹，缩略图马上就在，按一个键就能放大看图。它能播放 MKV、AVI 和 WebM，像打开文件夹一样打开 ZIP 和 RAR 压缩包，无需账户，也不联网。

用 Schnellbild 代替 看图 Kantu？

Schnellbild 没有图库：照片和视频在磁盘上的哪里，它就在哪里显示，附带元数据里的拍摄日期和地点，不上传任何东西。Schnellbild 与 看图 Kantu 并排对比：先看各自强在哪里，再逐项列出所有功能及来源。

看图 Kantu 更强的地方

  • 人脸识别、地点地图、查找重复、精选相册
  • 直接从手机、相机和 PTP 设备导入
  • 评分和大文件筛选

Schnellbild 更强的地方

  • ZIP、RAR、7z 像文件夹一样打开
  • 自动增强和滑块，不改动文件
  • 用方向键快速浏览视频
  • 开源
  • 从不联网
