想找 MangaMeeya Mac 版？这里有替代软件

Schnellbild 是一款免费的 Mac 应用，用来看你文件夹里的图片和视频：打开文件夹，缩略图马上就在，按一个键就能放大看图。它能播放 MKV、AVI 和 WebM，像打开文件夹一样打开 ZIP 和 RAR 压缩包，无需账户，也不联网。

用 Schnellbild 代替 MangaMeeya？

Schnellbild 像打开文件夹一样打开 CBZ、CBR、ZIP、RAR 和 7z，不往磁盘上解压任何东西，用方向键翻页。漫画一本不落地搬上了 Mac，MangaMeeya 却没赶上这趟车。

MangaMeeya 的用户喜欢什么，Schnellbild 又是怎么做的

  • 用键盘翻页: 空格键打开图片，← → 在文件夹中翻页。
  • 直接浏览文件夹，无需导入: 用 ⌘O 打开文件夹，或把它拖到窗口上。
  • 带文件夹预览的缩略图网格: 文件夹显示其中的头几张图片；没有图片的文件夹显示为灰色。
  • ZIP、RAR、7z 像文件夹一样打开: 像文件夹一样打开，不向磁盘解压任何内容。
  • 漫画 CBZ、CBR: CBZ 和 CBR 像文件夹一样打开；用 ← → 翻页。
  • 幻灯片: 按 S 开始，空格键暂停。
  • 一切都能用键盘完成: 每个操作都有对应的按键。
  • 自定义快捷键: 免费设置自己的按键，还有与 Phiewer 相同的预设。
