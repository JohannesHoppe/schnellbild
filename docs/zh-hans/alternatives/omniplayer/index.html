用 Schnellbild 代替 OmniPlayer？

Schnellbild 不是完整的媒体播放器。它把文件夹里的视频以缩略图形式放在照片旁边，能播放 MKV、AVI 和 WebM，方向键每次跳转视频的十分之一。Schnellbild 与 OmniPlayer 并排对比：先看各自强在哪里，再逐项列出所有功能及来源。

OmniPlayer 更强的地方

  • 在线字幕搜索
  • 播放速度低至 0.1 倍，可逐帧
  • 投屏到电视（DLNA、Chromecast、Roku）
  • YouTube/Vimeo 网址、SMB/FTP 源
  • 音频均衡器、音乐播放
  • 画面调整和 GIF 导出

Schnellbild 更强的地方

  • 照片和视频在同一网格中
  • ZIP、RAR、7z 像文件夹一样打开
  • 漫画 CBZ、CBR
  • 直接播放归档中的视频
  • 双窗格并排显示（F5 拷贝，F6 移动）
  • 幻灯片涵盖所有子文件夹，照片和视频混合播放
  • 撤销重新命名、移动、移到废纸篓
