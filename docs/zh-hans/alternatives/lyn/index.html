用 Schnellbild 代替 Lyn？

Schnellbild 打开文件夹即可浏览，无需导入，用方向键翻看图片：支持 HEIC、RAW、PSD、动态 GIF 和 PDF，文件夹里的视频也在同一个网格中。Schnellbild 与 Lyn 并排对比：先看各自强在哪里，再逐项列出所有功能及来源。

Lyn 更强的地方

  • 在地图上添加地理标记
  • 非破坏性的颜色编辑
  • 能打开照片/Aperture/Lightroom 图库
  • 分享到 Flickr、Dropbox、SmugMug
  • 能在旧版 macOS（10.13 及以上）上运行

Schnellbild 更强的地方

  • 免费，全部功能
  • 播放 MKV、WebM、AVI、WMV、FLV
  • ZIP、RAR、7z 像文件夹一样打开
  • 漫画 CBZ、CBR
  • 直接播放归档中的视频
  • 撤销重新命名、移动、移到废纸篓
  • 开源
