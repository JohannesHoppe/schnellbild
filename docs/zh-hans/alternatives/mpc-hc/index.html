用 Schnellbild 代替 MPC-HC？

Schnellbild 不是完整的媒体播放器。它把文件夹里的视频以缩略图形式放在照片旁边，能播放 MKV、AVI 和 WebM，方向键每次跳转视频的十分之一。新 Mac 到手，视频全都拷过来了，就差 MPC-HC 没跟着上车。那些 MKV 文件还在等你打开呢。

MPC-HC 的用户喜欢什么，Schnellbild 又是怎么做的

  • 用键盘翻页: 空格键打开图片，← → 在文件夹中翻页。
  • 直接浏览文件夹，无需导入: 用 ⌘O 打开文件夹，或把它拖到窗口上。
  • 缩放、平移、旋转（仅限显示）: + − 或双指捏合缩放，⌥← ⌥→ 旋转；文件保持原样。
  • 播放 MKV、WebM、AVI、WMV、FLV: 由内置的 VLC 引擎播放。
  • 视频内嵌字幕: 按 V 打开或关闭字幕，⌃⌘S 选择字幕轨道；播放中途打开，也会立刻显示正在进行的那一句，ASS 字幕保留其样式。
  • 选择音轨: ⌃⌘A 或控制条。
  • 播放速度: < 和 > 在 0.5× 到 2× 之间调节，人声音调保持不变。
  • 用方向键快速浏览视频: ← → 跳转视频的十分之一，加 ⇧ 跳转百分之一。

MPC-HC 依然领先的地方

  • 非常轻巧，启动很快
  • 面向发烧友的渲染器和着色器（madVR、MPC VR）
  • 字幕搜索和下载、yt-dlp 串流
  • 老板键、逐帧步进、大量可配置按键

有意不做的功能

  • 加载视频旁边的字幕文件: 只读取视频本身，不碰旁边的任何文件。
  • 保存的播放列表: 用文件夹代替播放列表：幻灯片会自己生成列表。
  • 音频文件，音乐模式: 只管图片和视频；音频文件用专门的 App 打开。
  • 播放互联网上的流媒体和网址: 原则上从不联网。
  • 从互联网下载字幕: 原则上从不联网。
