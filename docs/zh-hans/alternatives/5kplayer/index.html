用 Schnellbild 代替 5KPlayer？

Schnellbild 不是完整的媒体播放器。它把文件夹里的视频以缩略图形式放在照片旁边，能播放 MKV、AVI 和 WebM，方向键每次跳转视频的十分之一。Schnellbild 与 5KPlayer 并排对比：先看各自强在哪里，再逐项列出所有功能及来源。

5KPlayer 更强的地方

  • AirPlay 接收和屏幕镜像录制
  • DLNA 服务器/渲染器
  • 在线视频下载（YouTube 等）
  • 播放 DVD 和 ISO
  • 音乐库、电台、IPTV
  • 播放速度、视频剪切、提取 MP3

Schnellbild 更强的地方

  • 直接浏览文件夹，无需导入
  • 照片和视频在同一网格中
  • ZIP、RAR、7z 像文件夹一样打开
  • 漫画 CBZ、CBR
  • 直接播放归档中的视频
  • 双窗格并排显示（F5 拷贝，F6 移动）
  • 幻灯片涵盖所有子文件夹，照片和视频混合播放
