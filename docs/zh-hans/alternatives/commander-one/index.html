Commander One 擅长什么

Total Commander 风格的 macOS 双窗格文件管理器，以功能键操作为主，支持正则搜索，内置 F3 查看器（文本、十六进制、图像、媒体），能处理归档。PRO 套件增加 RAR/7z、FTP/SFTP、云盘、终端和主题。

Schnellbild 不是完整的文件管理器：没有 FTP、SFTP 或云连接，没有文件夹同步，也不能打包归档。它是为浏览和整理照片与视频而做的：所有文件都有缩略图，双窗格并排显示，F5 拷贝、F6 移动，归档像文件夹一样打开。

Commander One 更强的地方

  • 经典的功能键 Commander 工作方式和操作队列
  • 正则和内容搜索，归档内和 FTP 上也可以
  • PRO：FTP/SFTP 和众多云服务，MTP/iOS/Android 设备
  • 内置十六进制/文本/二进制查看器
  • 进程查看器、终端（PRO）

Schnellbild 更强的地方

  • 播放 MKV、WebM、AVI、WMV、FLV
  • 漫画 CBZ、CBR
  • 幻灯片涵盖所有子文件夹，照片和视频混合播放
  • 自动增强和滑块，不改动文件
  • 用方向键快速浏览视频
  • 撤销重新命名、移动、移到废纸篓
  • 开源
