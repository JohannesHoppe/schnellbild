免费的 Mac 版 qView 替代软件

Schnellbild 是一款免费的 Mac 应用，用来看你文件夹里的图片和视频：打开文件夹，缩略图马上就在，按一个键就能放大看图。它能播放 MKV、AVI 和 WebM，像打开文件夹一样打开 ZIP 和 RAR 压缩包，无需账户，也不联网。

用 Schnellbild 代替 qView？

Schnellbild 打开文件夹即可浏览，无需导入，用方向键翻看图片：支持 HEIC、RAW、PSD、动态 GIF 和 PDF，文件夹里的视频也在同一个网格中。Schnellbild 与 qView 并排对比：先看各自强在哪里，再逐项列出所有功能及来源。

qView 更强的地方

  • 极其简洁，窗口没有多余界面
  • 也能在 Windows、Linux 和旧版 macOS 上运行（10.13 及以上的旧版构建）
  • 动态图像可逐帧步进和调速
  • 可直接从网址打开图片

Schnellbild 更强的地方

  • 照片和视频在同一网格中
  • 播放 MKV、WebM、AVI、WMV、FLV
  • ZIP、RAR、7z 像文件夹一样打开
  • 漫画 CBZ、CBR
  • 直接播放归档中的视频
  • 双窗格并排显示（F5 拷贝，F6 移动）
  • 幻灯片涵盖所有子文件夹，照片和视频混合播放
