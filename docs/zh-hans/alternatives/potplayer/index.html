用 Schnellbild 代替 PotPlayer？

Schnellbild 不是完整的媒体播放器。它把文件夹里的视频以缩略图形式放在照片旁边，能播放 MKV、AVI 和 WebM，方向键每次跳转视频的十分之一。新 Mac 到手，视频全都拷过来了，就差 PotPlayer 没跟着上车。那些 MKV 文件还在等你打开呢。

PotPlayer 的用户喜欢什么，Schnellbild 又是怎么做的

  • 用键盘翻页: 空格键打开图片，← → 在文件夹中翻页。
  • 直接浏览文件夹，无需导入: 用 ⌘O 打开文件夹，或把它拖到窗口上。
  • 带文件夹预览的缩略图网格: 文件夹显示其中的头几张图片；没有图片的文件夹显示为灰色。
  • HEIC、AVIF、JPEG XL、WebP: 通过 macOS 自带的 ImageIO。
  • 动态 GIF、PNG、WebP: 可以播放，也能像普通图片一样缩放和旋转。
  • 缩放、平移、旋转（仅限显示）: + − 或双指捏合缩放，⌥← ⌥→ 旋转；文件保持原样。
  • ZIP、RAR、7z 像文件夹一样打开: 像文件夹一样打开，不向磁盘解压任何内容。
  • 播放 MKV、WebM、AVI、WMV、FLV: 由内置的 VLC 引擎播放。

PotPlayer 依然领先的地方

  • 设置、渲染器和滤镜极多（madVR、HDR 色调映射、倍帧）
  • 在线下载字幕、字幕翻译和语音转字幕（Whisper）
  • 串流（YouTube、HLS/DASH）、电视/DVD/蓝光、3D 和 360° VR
  • 快捷键和皮肤完全可自定义
  • 音乐播放，带专辑封面、歌词、ReplayGain

有意不做的功能

  • 加载视频旁边的字幕文件: 只读取视频本身，不碰旁边的任何文件。
  • 保存的播放列表: 用文件夹代替播放列表：幻灯片会自己生成列表。
  • 画中画: 它为翻看文件夹而做；想边干别的边看，视频播放器更合适。
  • 音频文件，音乐模式: 只管图片和视频；音频文件用专门的 App 打开。
  • 播放互联网上的流媒体和网址: 原则上从不联网。
  • 从互联网下载字幕: 原则上从不联网。
  • 图库、目录、标签、评分: 用文件夹代替图库：没有什么需要导入。
