免费的 Mac 版 Apple 照片 替代软件

Schnellbild 是一款免费的 Mac 应用，用来看你文件夹里的图片和视频：打开文件夹，缩略图马上就在，按一个键就能放大看图。它能播放 MKV、AVI 和 WebM，像打开文件夹一样打开 ZIP 和 RAR 压缩包，无需账户，也不联网。

用 Schnellbild 代替 Apple 照片？

Schnellbild 没有图库：照片和视频在磁盘上的哪里，它就在哪里显示，附带元数据里的拍摄日期和地点，不上传任何东西。Schnellbild 与 Apple 照片 并排对比：先看各自强在哪里，再逐项列出所有功能及来源。

Apple 照片 更强的地方

  • 与 iPhone 和 iPad 通过 iCloud 同步
  • 照片和视频的非破坏性编辑
  • 按人物、地点和内容搜索
  • 回忆、配乐幻灯片、共享相簿

Schnellbild 更强的地方

  • 直接浏览文件夹，无需导入
  • 播放 MKV、WebM、AVI、WMV、FLV
  • ZIP、RAR、7z 像文件夹一样打开
  • 漫画 CBZ、CBR
  • 直接播放归档中的视频
  • 双窗格并排显示（F5 拷贝，F6 移动）
  • 用方向键快速浏览视频
