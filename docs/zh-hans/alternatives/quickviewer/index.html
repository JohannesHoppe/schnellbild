QuickViewer 擅长什么

基于 OpenGL 的快速图片和漫画查看器，无需解压即可读取归档，支持双页跨页。有目录数据库，便于管理大量漫画收藏。开发者因病于 2025 年 11 月结束了这个项目；1.2.8 是修复 UnRAR 安全问题的版本。

QuickViewer 的用户喜欢什么，Schnellbild 又是怎么做的

  • 用键盘翻页: 空格键打开图片，← → 在文件夹中翻页。
  • 直接浏览文件夹，无需导入: 用 ⌘O 打开文件夹，或把它拖到窗口上。
  • 带文件夹预览的缩略图网格: 文件夹显示其中的头几张图片；没有图片的文件夹显示为灰色。
  • HEIC、AVIF、JPEG XL、WebP: 通过 macOS 自带的 ImageIO。
  • 相机 RAW: macOS 认识的 RAW 格式，由 macOS 冲印。
  • 动态 GIF、PNG、WebP: 可以播放，也能像普通图片一样缩放和旋转。
  • 缩放、平移、旋转（仅限显示）: + − 或双指捏合缩放，⌥← ⌥→ 旋转；文件保持原样。
  • ZIP、RAR、7z 像文件夹一样打开: 像文件夹一样打开，不向磁盘解压任何内容。

QuickViewer 依然领先的地方

  • 可管理数千本漫画的目录数据库
  • 借助 OpenGL 翻页非常快
  • 归档支持广泛，包括 tar.gz/bz2/xz 和 cab
  • 正确显示 CMYK JPEG

有意不做的功能

  • 双页显示，从右到左的日漫模式: 一次一张图，以窗口允许的最大尺寸显示。
  • 编辑图像（裁剪、调整大小、保存）: 这是查看器，不是图像编辑器：你的文件保持原样。
  • 图库、目录、标签、评分: 用文件夹代替图库：没有什么需要导入。
