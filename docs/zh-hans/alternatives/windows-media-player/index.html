想找 Windows Media Player Mac 版？这里有替代软件

Schnellbild 是一款免费的 Mac 应用，用来看你文件夹里的图片和视频：打开文件夹，缩略图马上就在，按一个键就能放大看图。它能播放 MKV、AVI 和 WebM，像打开文件夹一样打开 ZIP 和 RAR 压缩包，无需账户，也不联网。

用 Schnellbild 代替 Windows Media Player？

Schnellbild 不是完整的媒体播放器。它把文件夹里的视频以缩略图形式放在照片旁边，能播放 MKV、AVI 和 WebM，方向键每次跳转视频的十分之一。新 Mac 到手，视频全都拷过来了，就差 Windows Media Player 没跟着上车。那些 MKV 文件还在等你打开呢。

Windows Media Player 的用户喜欢什么，Schnellbild 又是怎么做的

  • 用键盘翻页: 空格键打开图片，← → 在文件夹中翻页。
  • 缩放、平移、旋转（仅限显示）: + − 或双指捏合缩放，⌥← ⌥→ 旋转；文件保持原样。
  • 播放 MKV、WebM、AVI、WMV、FLV: 由内置的 VLC 引擎播放。
  • 视频内嵌字幕: 按 V 打开或关闭字幕，⌃⌘S 选择字幕轨道；播放中途打开，也会立刻显示正在进行的那一句，ASS 字幕保留其样式。
  • 选择音轨: ⌃⌘A 或控制条。
  • 播放速度: < 和 > 在 0.5× 到 2× 之间调节，人声音调保持不变。
  • 用方向键快速浏览视频: ← → 跳转视频的十分之一，加 ⇧ 跳转百分之一。
  • 文件信息：EXIF、编解码器、码率: 按 I 显示格式、相机、编解码器和码率，在小地图上显示拍摄地点，以及每一个元数据键。

Windows Media Player 依然领先的地方

  • Windows 预装，无需设置
  • 带专辑封面、播放列表和 CD 抓轨的音乐库
  • 迷你播放器，投屏到设备
  • 跟随 Windows 的字幕和主题设置

有意不做的功能

  • 加载视频旁边的字幕文件: 只读取视频本身，不碰旁边的任何文件。
  • 保存的播放列表: 用文件夹代替播放列表：幻灯片会自己生成列表。
  • 画中画: 它为翻看文件夹而做；想边干别的边看，视频播放器更合适。
  • 音频文件，音乐模式: 只管图片和视频；音频文件用专门的 App 打开。
  • 批量转换或重新命名: 批量转换和批量重命名交给其他应用。
  • 图库、目录、标签、评分: 用文件夹代替图库：没有什么需要导入。
