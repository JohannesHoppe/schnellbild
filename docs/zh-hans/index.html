为什么 Schnellbild 不闹心

无广告、无跟踪、无需账户

它只显示你的图片，不和任何人通信。

不推销

没有专业版，没有订阅，也没有“解锁”按钮。所有功能一应俱全。

不臃肿

无需导入图库，没有编辑器，没有云。只做好一件事：看照片和视频。

快

滚动时缩略图随即出现，大文件夹和网络共享也一样。

默认安全

别人发来的图片、视频和归档不会运行任何东西，也不会联网，无需事先打开任何设置。

不崩溃

遇到损坏的文件、奇怪的格式或缓慢的磁盘，只会显示占位图，App 不会因此崩溃。

功能一览

大图查看，按键翻页

按空格键，图像会以窗口允许的最大尺寸打开；用 ← → 在文件夹中翻页。用触控板或 + − 缩放，用 ⌥← ⌥→ 旋转，按 f 全屏。动态 GIF、SVG 和 PDF 同样支持。

幻灯片（s）会播放文件夹及其所有子文件夹中的内容，照片和视频都包括在内。

视频，包括 macOS 播放不了的

macOS 自身能播放的格式（MP4、MOV、AVCHD 等）由 macOS 播放，其余格式（MKV、WebM、AVI、WMV、FLV、MPEG、DVD 视频）则由内置的 VLC 引擎播放。

  • ← → 跳转视频的十分之一，⇧← ⇧→ 跳转百分之一
  • ↑ ↓ 调节音量，对所有视频生效
  • 访达和快速查看也能显示 MKV、WebM、WMV、FLV 和 VOB 的缩略图

归档像文件夹一样打开

ZIP、RAR 和 7z，包括漫画（CBZ、CBR），分卷的也可以；ZIP 和 RAR 还支持密码。不会向磁盘解压任何内容，视频直接从归档中播放。

像在 Norton Commander 里一样整理旅行照片

按 D 并排显示两个文件夹。标记图像后，按 F5 拷贝到另一侧，按 F6 移过去，或者直接拖过去。

重新命名、新建文件夹、废纸篓、书签，而且重新命名、移到废纸篓、拷贝和移动都可以撤销。

搜索所有子文件夹

搜索栏会在当前文件夹及其下所有位置中查找文件夹、归档、图像和视频的名称。搜索过程中结果陆续出现，即使在缓慢的网络共享上也是如此。可以忽略大小写、区分大小写，或使用正则表达式。

画面更好看，文件不改动

按 E 自动增强曝光、对比度、饱和度和锐度，照片和视频都适用。按 A 打开滑块。这只影响显示：你的文件保持原样。

看清文件的真面目

按 I 显示格式、分辨率、编解码器、码率、位深度、颜色描述文件和相机；如果文件扩展名与内容不符，也会提示。

所有按键尽在掌握

按 F1 列出所有按键，还可以打印；按 K 显示可点按的迷你键盘。网格或列表（L），按名称、种类、日期或大小排序，多个窗口，还有老板键（X）。

别人发来的文件，也能放心看

查看陌生人发来的图片、视频和归档，正是查看器的本职工作。所以 Schnellbild 开箱即把每个文件都视为不可信。

  • 运行在 Apple 的 App Sandbox 中。 完全不联网，不会自行启动其他程序，只能访问你为它打开的文件夹，以及“图片”“影片”和“下载”。
  • 只读不写。 查看从不改动任何东西，也从不解压到磁盘。
  • 视频无法联网。 实际上是指向互联网的播放列表的“视频”，什么都不会播放。
  • 连按两次只打开文稿，不打开程序。 App、脚本和安装器一律不打开，即使它们伪装成图片的名称。
  • 经过签名和公证， 并启用 Apple 的 Hardened Runtime。
  • 可证明由公开源代码构建。 GitHub 以签名证明每个下载来自哪个提交、哪次构建。任何人都可以验证。

它具体做了什么，界限又在哪里：别人发来的文件，也能放心看。

从 Phiewer、IINA 或 Norton Commander 转过来？

它们都是 Schnellbild 的榜样：Phiewer 用键盘浏览图片，IINA 快速处理视频，Norton Commander 的双窗格。Schnellbild 与它们相比如何：免费的 Phiewer 替代品、用来浏览视频的免费 IINA 替代品。
