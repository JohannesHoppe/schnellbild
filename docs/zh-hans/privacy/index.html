隐私政策

Schnellbild 是一款 macOS 图像和视频查看器。GDPR 意义上的控制者为 HAUS HOPPE - ITS（Johannes Hoppe）；完整地址见法律声明。本政策适用于该 App（无论是从 GitHub 下载还是在 Mac App Store 购买，两者是同一个 App）以及本网站。

App

Schnellbild 不收集任何个人数据。它没有账户、分析、广告和跟踪，也不连接互联网：它所运行的 App Sandbox 完全不允许它访问网络。

以下内容保存在你的 Mac 上，且仅保存在那里：

  • 设置（上次打开的文件夹、排序方式、书签、音量……），保存在 App 自己的偏好设置中。
  • 文件夹访问权限：你为 Schnellbild 打开的文件夹，以 macOS 书签的形式保存，以便重新启动后能再次显示。可在“设置”→“忘记文件夹访问”中清除它们。
  • 你输入的归档密码，保存在你的登录钥匙串中（条目“Schnellbild archive passwords”）；在“设置”中点按“忘记已存储的密码”即可将其移除。
  • 缩略图，保存在 macOS 自身的缩略图缓存中。

Schnellbild 读取你的图像、视频和归档，仅仅是为了向你显示它们。它从不将这些文件、文件名或任何相关信息发送到任何地方。下载和购买由 Apple 根据其自身的隐私政策处理，Apple 只向我们提供不含你身份信息的数据：销量，以及在你于 macOS 中允许与 App 开发者共享时的崩溃报告和使用统计。

本网站

本网站不使用 Cookie、分析工具，也不加载来自其他服务器的内容（没有网络字体，没有嵌入视频）。本网站托管于 GitHub Pages，这是 GitHub, Inc.（美国）提供的服务。你访问本网站时，GitHub 出于安全目的会记录并存储你的 IP 地址；参见GitHub Pages：数据收集和GitHub 隐私声明。GitHub 将这些日志保留多久由 GitHub 决定；我们无法访问这些日志。GitHub 参与了欧盟—美国数据隐私框架（EU-U.S. Data Privacy Framework），欧盟委员会已认定美国在该框架下提供充分的保护水平（GDPR 第 45 条）。法律依据是我们安全提供本网站的合法利益（欧盟《通用数据保护条例》（GDPR）第 6 条第 1 款第 (f) 项）。App 的下载同样来自 GitHub。

你的权利

根据 GDPR，你享有访问、更正、删除、限制处理和数据可携带的权利，并有权向数据保护监管机构提出投诉。<strong>你有权基于与你的特殊情况相关的理由，反对基于我们合法利益进行的处理</strong>（GDPR 第 21 条）。由于 App 和本网站都不保存自己的个人数据，我们这边通常没有可查询或删除的内容。
