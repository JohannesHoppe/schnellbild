What GraphicConverter is good at

GraphicConverter is a long-running Mac 'pocket knife for pictures': a file and picture browser, slideshow, editor and batch converter that opens about 200 formats. Its browser also plays QuickTime-compatible movies and audio, handles extensive metadata and has duplicate finding, flat views and Spotlight search.

Where GraphicConverter is stronger

  • Opens ~200 image formats, exports ~80, including legacy and scientific formats
  • Full image editor and powerful batch conversion with actions
  • Deep metadata editing (EXIF/IPTC/XMP, faces, GPS map)
  • Rich slideshow options (transitions, random, metadata, sorting during the show)
  • List, Cover Flow and thumbnail views, flat view of all subfolders
  • Duplicate finder, contact sheets, web galleries
  • Custom shortcuts, 14 languages, light/dark setting

Where Schnellbild is stronger

  • Free, every feature
  • Plays MKV, WebM, AVI, WMV, FLV
  • Comic books CBZ, CBR
  • Plays videos straight from archives
  • Two panes side by side (F5 copy, F6 move)
  • Open source
  • Never goes online
