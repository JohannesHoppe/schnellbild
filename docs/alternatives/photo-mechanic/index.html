What Photo Mechanic is good at

Photo Mechanic is a fast ingest, culling and metadata tool for working photographers, especially press, sports and wedding shooters. It opens folders and memory cards directly, shows RAW files instantly from their embedded previews, and is built for captions, IPTC metadata, keywording, batch renaming and uploading on deadline.

Where Photo Mechanic is stronger

  • Ingest from multiple memory cards at once, with renaming and metadata during copy
  • IPTC/XMP metadata, code replacements, variables and structured keywords for captioning on deadline
  • Star ratings, colour classes and tags to cull thousands of RAW files quickly
  • Batch rename, Save As/resize/watermark and direct upload to FTP, Dropbox, S3, PhotoShelter and more
  • Regular-expression find and replace across filenames and metadata
  • Fully customizable shortcuts with presets, and printable shortcut PDFs
  • Windows version with the same feature set

Where Schnellbild is stronger

  • Free, every feature
  • ZIP, RAR, 7z open like folders
  • Comic books CBZ, CBR
  • Plays videos straight from archives
  • Two panes side by side (F5 copy, F6 move)
  • Auto enhance and sliders without changing the file
  • Skim videos with the arrow keys
