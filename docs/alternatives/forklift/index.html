A free ForkLift alternative for Mac

Schnellbild is a free Mac app for the pictures and videos in your folders: open a folder and its thumbnails are there, one key shows a picture large. It plays MKV, AVI and WebM, opens ZIP and RAR archives like folders, and works without an account and without network access.

Schnellbild instead of ForkLift?

Schnellbild isn't a file manager. It is a viewer with two panes: F5 copies and F6 moves the marked pictures into the other pane, and both can be undone. Schnellbild and ForkLift side by side: what each does better, then every feature with a source.

Schnellbild isn't a complete file manager: no FTP, SFTP or cloud connections, no folder sync, no packing of archives. It is made for looking through photos and videos and sorting them: thumbnails of everything, two panes side by side with F5 to copy and F6 to move, archives open like folders.

Where ForkLift is stronger

  • Remote and cloud connections (SFTP, FTP, WebDAV, S3, Google Drive, OneDrive, Dropbox)
  • Folder sync and file compare
  • Multi-Rename with regex and metadata
  • Git status, tags, workspaces, app deleter
  • Full file manager: undo, conflict handling, transfer queue

Where Schnellbild is stronger

  • Free, every feature
  • Comic books CBZ, CBR
  • Slideshow through all subfolders, photos and videos mixed
  • Auto enhance and sliders without changing the file
  • Skim videos with the arrow keys
  • Open source
  • Never goes online
