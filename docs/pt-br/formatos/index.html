Todos os formatos que o Schnellbild mostra

O Schnellbild mostra 127 formatos com 146 extensões de arquivo. As imagens passam pelo ImageIO, a biblioteca do macOS, então um macOS mais novo lê mais; o que o macOS não lê, o Schnellbild decodifica sozinho ou com a LibRaw. Os vídeos que o macOS não reproduz passam pelo mecanismo do VLC integrado, e os arquivos compactados abrem como pastas.

  • HDR, edição e medicina
  • Texturas
  • Decodificados pelo Schnellbild
  • Documentos e desenhos
  • RAW de câmera, revelados pelo macOS
