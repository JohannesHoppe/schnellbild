No que o digiKam é bom

O digiKam é uma suíte completa de código aberto do KDE para gerenciar grandes coleções de fotos. Ele indexa pastas num banco de dados e oferece etiquetas, reconhecimento facial, geolocalização, busca por semelhança, um editor de imagens competente, processamento em lote e muitos destinos de exportação.

Onde o digiKam é mais forte

  • Banco de dados com etiquetas, rótulos, reconhecimento facial, busca por semelhança e duplicatas, busca por mapa e linha do tempo
  • Busca em linguagem natural e avançada em todas as coleções
  • Editor de imagens completo e Batch Queue Manager com versões
  • Processamento RAW pelo LibRaw, 16 bits e gerenciamento de cores
  • Controle de velocidade e avanço quadro a quadro em vídeos
  • Muitos destinos de exportação (Dropbox, OneDrive, Flickr, Piwigo, galerias HTML) e DLNA
  • Grátis, código aberto, roda também no Linux e no Windows

Onde o Schnellbild é mais forte

  • ZIP, RAR, 7z abrem como pastas
  • Quadrinhos CBZ, CBR
  • Reproduz vídeos direto do arquivo compactado
  • Percorrer vídeos com as setas
  • Nunca se conecta à internet
