Uma alternativa grátis ao Path Finder para Mac

O Schnellbild é um app gratuito para Mac para as imagens e vídeos das suas pastas: abra uma pasta e as miniaturas já estão lá, uma tecla mostra uma imagem grande. Ele reproduz MKV, AVI e WebM, abre arquivos ZIP e RAR como pastas e funciona sem conta e sem acesso à rede.

Schnellbild no lugar do Path Finder?

O Schnellbild não é um gerenciador de arquivos, e sim um visualizador com dois painéis: F5 copia e F6 move as imagens marcadas para o outro painel, e as duas ações podem ser desfeitas. Schnellbild e Path Finder lado a lado: o que cada um faz melhor e, depois, cada recurso com sua fonte.

O Schnellbild não é um gerenciador de arquivos completo: sem conexões FTP, SFTP ou de nuvem, sem sincronização de pastas, sem criar arquivos compactados. Ele é feito para ver fotos e vídeos e organizá-los: miniaturas de tudo, dois painéis lado a lado com F5 para copiar e F6 para mover, arquivos compactados que abrem como pastas.

Onde o Path Finder é mais forte

  • Módulos: Preview, Info, Terminal, Drop Stack, Git, editor hex/texto
  • Size Browser e sincronização/mesclagem de pastas
  • Renomeação em lote, exclusão segura, acesso de administrador
  • Interface em 20 idiomas
  • Barra de favoritos, predefinições de abas

Onde o Schnellbild é mais forte

  • Grátis, com todos os recursos
  • ZIP, RAR, 7z abrem como pastas
  • Quadrinhos CBZ, CBR
  • Reproduz vídeos direto do arquivo compactado
  • Apresentação por todas as subpastas, fotos e vídeos misturados
  • Melhoria automática e controles sem alterar o arquivo
  • Percorrer vídeos com as setas
