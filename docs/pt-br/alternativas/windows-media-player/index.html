Windows Media Player para Mac? Aqui está a alternativa

O Schnellbild é um app gratuito para Mac para as imagens e vídeos das suas pastas: abra uma pasta e as miniaturas já estão lá, uma tecla mostra uma imagem grande. Ele reproduz MKV, AVI e WebM, abre arquivos ZIP e RAR como pastas e funciona sem conta e sem acesso à rede.

Baixar grátisSchnellbild.dmg Mac App Storeem breve, para apoiar o projeto

Schnellbild no lugar do Windows Media Player?

O Schnellbild não é um player completo. Ele mostra os vídeos de uma pasta como miniaturas ao lado das fotos, reproduz MKV, AVI e WebM, e as setas pulam um décimo do vídeo. Mac novo, os mesmos vídeos, e o Windows Media Player foi o único que não subiu no caminhão da mudança. Seus arquivos MKV continuam esperando o play.

O que os fãs do Windows Media Player gostam, e como isso funciona no Schnellbild

  • Navegar pelas imagens com o teclado: Espaço abre uma imagem, ← → percorrem a pasta.
  • Ampliar, mover, girar (só na visualização): + − ou pinça para ampliar, ⌥← ⌥→ para girar; o arquivo continua como está.
  • Reproduz MKV, WebM, AVI, WMV, FLV: Pelo mecanismo do VLC integrado.
  • Legendas embutidas no vídeo: V liga e desliga, ⌃⌘S escolhe a faixa; ligadas no meio, a linha em curso aparece na hora, e o ASS mantém seus estilos.
  • Escolher a faixa de áudio: ⌃⌘A ou a barra de controle.
  • Velocidade de reprodução: < e > de 0,5× a 2×, as vozes mantêm o tom.
  • Percorrer vídeos com as setas: ← → pulam um décimo do vídeo, com ⇧ um centésimo.
  • Informações do arquivo: EXIF, codecs, taxa de bits: I mostra formato, câmera, codecs e taxa de bits, onde foi feita num pequeno mapa e cada chave de metadados.

Onde o Windows Media Player continua na frente

  • Pré-instalado no Windows, nada para configurar
  • Biblioteca de música com capas, playlists e extração de CDs
  • Miniplayer, transmissão para aparelhos
  • Segue os ajustes de legenda e tema do Windows

Deixado de fora de propósito

  • Carrega arquivos de legenda ao lado do vídeo: Lê só o próprio vídeo, nada que esteja ao lado dele.
  • Playlists salvas: Pastas em vez de playlists: a apresentação monta a lista.
  • Picture in Picture: Feito para percorrer pastas; para assistir de canto, um player de vídeo serve melhor.
  • Arquivos de áudio, modo música: Só imagens e vídeos; arquivos de áudio abrem no app deles.
  • Converter ou renomear em lote: Converter e renomear em lote fica para outros apps.
  • Biblioteca, catálogo, etiquetas, avaliações: Pastas em vez de biblioteca: nada para importar.
