Política de privacidade

O Schnellbild é um visualizador de imagens e vídeos para macOS. O responsável pelo tratamento dos dados, nos termos do GDPR, é a HAUS HOPPE - ITS, Johannes Hoppe; o endereço completo está no aviso legal. Esta política abrange o app, tanto baixado do GitHub quanto comprado na Mac App Store (os dois são o mesmo app), e este site.

O app

O Schnellbild não coleta dados pessoais. Ele não tem conta, análises, publicidade nem rastreamento, e não se conecta à internet: a App Sandbox em que ele é executado não lhe dá nenhum acesso à rede.

O que fica no seu Mac, e somente nele:

  • Ajustes (a última pasta, a ordenação, os favoritos, o volume…) nas preferências do próprio app.
  • Acesso a pastas: as pastas que você abriu para o Schnellbild, como marcadores do macOS, para que ele possa mostrá-las de novo depois de reiniciar. Ajustes → Esquecer acesso às pastas as esquece.
  • Senhas de arquivos compactados que você digitou, no seu chaveiro de início de sessão (item “Schnellbild archive passwords”); Ajustes → Esquecer senhas salvas as remove.
  • Miniaturas, no cache de miniaturas do próprio macOS.

O Schnellbild lê suas imagens, vídeos e arquivos compactados apenas para mostrá-los a você. Ele nunca os envia a lugar nenhum, nem seus nomes, nem qualquer informação sobre eles. A Apple cuida do download e da compra de acordo com a própria política de privacidade e só nos repassa números que não identificam você: as vendas e, se você permitiu no macOS o compartilhamento com desenvolvedores de apps, relatórios de falhas e estatísticas de uso.

Este site

Este site não usa cookies, análises nem conteúdo de outros servidores (nada de fontes web, nada de vídeos incorporados). Ele é hospedado no GitHub Pages, um serviço da GitHub, Inc. (EUA). Quando você o visita, o GitHub registra e armazena seu endereço IP para fins de segurança; veja GitHub Pages: coleta de dados e a Declaração de Privacidade do GitHub. Por quanto tempo o GitHub guarda esses registros é decisão do GitHub; nós não temos acesso a eles. O GitHub participa do EU-U.S. Data Privacy Framework, para o qual a Comissão Europeia decidiu que os EUA garantem um nível adequado de proteção (art. 45 do GDPR). A base legal é o nosso legítimo interesse em disponibilizar o site com segurança (art. 6º, n.º 1, alínea f, do Regulamento Geral sobre a Proteção de Dados da UE, o GDPR). O download do app também vem do GitHub.

Seus direitos

Pelo GDPR, você tem direito de acesso, retificação, apagamento, limitação do tratamento e portabilidade dos dados, além do direito de apresentar reclamação a uma autoridade de controle de proteção de dados. <strong>Você tem o direito de se opor</strong>, por motivos relacionados à sua situação particular, ao tratamento baseado no nosso legítimo interesse (art. 21 do GDPR). Como nem o app nem este site guardam dados pessoais próprios, normalmente não há nada do nosso lado para consultar ou apagar.
