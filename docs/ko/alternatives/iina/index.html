맥용 무료 IINA 대안

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

무료 다운로드Schnellbild.dmg Mac App Store곧 출시, 개발 후원용

IINA 대신 Schnellbild?

Schnellbild는 본격적인 미디어 플레이어가 아닙니다. 폴더의 동영상을 사진 옆에 썸네일로 보여 주고, MKV, AVI, WebM을 재생하며, 화살표 키로 동영상의 10분의 1씩 이동합니다. Schnellbild와 IINA을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

IINA이(가) 더 나은 점

  • 완전한 재생 기능: 챕터, 프레임 단위 이동, A-B 반복, PIP, 음악 모드
  • 온라인 자막 검색과 똑똑한 로컬 자막 매칭
  • 플러그인, mpv 설정과 스크립트, 브라우저 확장 프로그램
  • macOS 12와 Intel Mac 지원
  • 탐색 막대 썸네일, 재생 기록과 이어 보기

Schnellbild가 더 나은 점

  • 사진과 동영상을 한 격자에
  • ZIP, RAR, 7z를 폴더처럼 열기
  • 만화책 CBZ, CBR
  • 나란히 놓인 두 패널(F5 복사, F6 이동)
  • 모든 하위 폴더의 사진과 동영상을 섞어서 슬라이드 쇼
  • 이름 변경, 이동, 휴지통 실행 취소
  • 인터넷에 접속하지 않음
