맥용 JPEGView? 무료 대안은 여기 있습니다

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

JPEGView 대신 Schnellbild?

Schnellbild는 가져오기 없이 폴더를 바로 열고, 화살표 키로 이미지를 넘깁니다. HEIC, RAW, PSD, 움직이는 GIF, PDF도 되고, 폴더의 동영상도 같은 격자에 나옵니다. 드디어 Mac으로 이사 오셨군요. 사진도, 손에 익은 단축키도 다 따라왔는데 JPEGView만 옛 PC에 남았습니다. 계속 그럴 필요는 없습니다.

JPEGView 팬들이 좋아하는 점, 그리고 Schnellbild에서는

  • 키보드로 넘겨 보기: 스페이스 바로 이미지를 열고 ← →로 폴더를 넘겨 봄.
  • 가져오기 없이 폴더를 바로 탐색: ⌘O로 폴더를 열거나 윈도우에 끌어다 놓기.
  • HEIC, AVIF, JPEG XL, WebP: macOS 자체의 ImageIO로.
  • 카메라 RAW: macOS가 아는 RAW 포맷을 macOS가 현상.
  • 애니메이션 GIF, PNG, WebP: 재생되며, 다른 이미지처럼 확대와 회전도 가능.
  • 확대, 이동, 회전(보기 전용): + − 또는 핀치로 확대, ⌥← ⌥→로 회전, 파일은 그대로.
  • 슬라이드 쇼: S로 시작, 스페이스 바로 일시 정지.
  • 모든 하위 폴더의 사진과 동영상을 섞어서 슬라이드 쇼: 모든 하위 폴더, 사진과 동영상을 섞어서, 정렬 순서대로.

JPEGView이(가) 여전히 앞서는 점

  • 보는 동안 실시간 자동 색상, 대비, 국소 밀도 보정
  • 아주 작고 설치 없이 실행
  • KeyMap.txt로 모든 키 재지정
  • JPEG 무손실 자르기/회전
  • 이미지 시리즈를 지정한 프레임 속도로 동영상처럼 재생

일부러 뺀 기능

  • 재생 목록 저장: 재생 목록 대신 폴더: 목록은 슬라이드 쇼가 만듦.
  • 이미지 편집(자르기, 크기 조절, 저장): 이미지를 보여 줄 뿐 바꾸지 않습니다: 파일은 그대로.
  • 일괄 변환, 일괄 이름 변경: 일괄 변환과 일괄 이름 변경은 다른 앱에 맡깁니다.

JPEGView의 장점

가격무료
버전1.3.46
최근 업데이트2023-10-07 (마지막 릴리스, 마지막 커밋 2024-07-06)
플랫폼Windows

최소한의 전체 화면 GUI, 실시간 이미지 보정(자동 대비, 국소 밀도, 선명하게), 편집 가능한 KeyMap으로 키보드 조작을 하는 가볍고 아주 빠른 Windows 이미지 뷰어입니다. 최신 포맷과 RAW를 지원합니다. 썸네일, 동영상, 파일 브라우저는 없으며, 포크는 2023년 이후 새 릴리스가 없습니다.
