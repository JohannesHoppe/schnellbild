맥용 무료 digiKam 대안

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

무료 다운로드Schnellbild.dmg Mac App Store곧 출시, 개발 후원용

digiKam 대신 Schnellbild?

Schnellbild에는 보관함이 없습니다. 사진과 동영상을 디스크에 있는 그대로, 메타데이터의 촬영 날짜와 장소와 함께 보여 주고, 아무것도 업로드하지 않습니다. Schnellbild와 digiKam을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

digiKam이(가) 더 나은 점

  • 태그, 레이블, 얼굴 인식, 유사·중복 검색, 지도와 타임라인 검색이 있는 데이터베이스
  • 모든 컬렉션을 대상으로 한 자연어 검색과 고급 검색
  • 버전 관리가 되는 이미지 편집기와 일괄 대기열 관리자
  • LibRaw를 통한 RAW 처리, 16비트와 색상 관리
  • 동영상 재생 속도 조절과 프레임 단위 이동
  • 다양한 내보내기 대상(Dropbox, OneDrive, Flickr, Piwigo, HTML 갤러리)과 DLNA
  • 무료, 오픈 소스, Linux와 Windows에서도 실행

Schnellbild가 더 나은 점

  • ZIP, RAR, 7z를 폴더처럼 열기
  • 만화책 CBZ, CBR
  • 아카이브 속 동영상 바로 재생
  • 화살표 키로 동영상 훑어보기
  • 인터넷에 접속하지 않음

digiKam의 장점

가격무료
버전9.1.0
최근 업데이트2026-06-07
플랫폼macOS, Windows, Linux

digiKam은 대규모 사진 모음을 위한 KDE의 오픈 소스 사진 관리 도구입니다. 폴더를 데이터베이스에 색인하고 태그, 얼굴 인식, 위치 정보, 유사 이미지 검색, 유능한 이미지 편집기, 일괄 처리, 다양한 내보내기 대상을 제공합니다.
