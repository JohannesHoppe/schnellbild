맥용 무료 FlowVision 대안

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

무료 다운로드Schnellbild.dmg Mac App Store곧 출시, 개발 후원용

FlowVision 대신 Schnellbild?

Schnellbild는 가져오기 없이 폴더를 바로 열고, 화살표 키로 이미지를 넘깁니다. HEIC, RAW, PSD, 움직이는 GIF, PDF도 되고, 폴더의 동영상도 같은 격자에 나옵니다. Schnellbild와 FlowVision을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

FlowVision이(가) 더 나은 점

  • 폭포형과 정렬형 썸네일 레이아웃
  • 오른쪽 클릭 마우스 제스처로 폴더 이동
  • 필터가 있는 Finder 태그와 XMP 별점
  • HDR 표시
  • 레이아웃 프리셋 프로필
  • macOS 11 이상에서 실행

Schnellbild가 더 나은 점

  • ZIP, RAR, 7z를 폴더처럼 열기
  • 만화책 CBZ, CBR
  • 아카이브 속 동영상 바로 재생
  • 나란히 놓인 두 패널(F5 복사, F6 이동)
  • 파일을 바꾸지 않는 자동 향상과 슬라이더
  • 이름 변경, 이동, 휴지통 실행 취소
  • Apple의 App Sandbox에서 실행

FlowVision은 폭포형/정렬형 썸네일 레이아웃과 Finder 같은 파일 관리를 중심으로 한 네이티브 오픈 소스 macOS 이미지 뷰어입니다. 아주 큰 폴더에 맞게 조정되어 있고, Mac 기본 동영상 포맷을 재생하며, 하위 폴더 포함 모드, Finder 태그, 별점, 폴더 사이를 오가는 마우스 제스처를 제공합니다.
