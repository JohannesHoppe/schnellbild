맥용 무료 QSpace 대안

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

QSpace 대신 Schnellbild?

Schnellbild는 파일 관리자가 아니라 두 개의 패널이 있는 뷰어입니다. F5는 표시한 이미지를 다른 패널로 복사하고 F6은 이동하며, 둘 다 되돌릴 수 있습니다. Schnellbild와 QSpace을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

Schnellbild는 완전한 파일 관리자가 아닙니다. FTP, SFTP, 클라우드 연결도, 폴더 동기화도, 압축 파일 만들기도 없습니다. 사진과 동영상을 훑어보고 정리하기 위해 만들었습니다. 모든 파일의 썸네일, 나란히 놓인 두 패널(F5로 복사, F6으로 이동), 폴더처럼 열리는 아카이브.

QSpace이(가) 더 나은 점

  • 최대 12가지 패널 레이아웃과 작업 공간 저장
  • 단축키, 오른쪽 클릭 메뉴, 도구 막대, 색상 사용자 지정
  • 폴더 동기화, 파일 해시, 파일 템플릿
  • 빠른 이미지 동작(회전, 변환, 배경 제거)
  • 동영상 메타데이터 열(프레임 속도, 데이터 속도)

Schnellbild가 더 나은 점

  • 무료, 모든 기능
  • 파일을 바꾸지 않는 자동 향상과 슬라이더
  • 화살표 키로 동영상 훑어보기
  • 오픈 소스
  • 인터넷에 접속하지 않음
  • Finder와 훑어보기에서 MKV 등의 썸네일
  • 확장자가 내용과 맞지 않는 파일 알림

12가지 레이아웃, 작업 공간, 폭넓은 사용자 지정(단축키, 오른쪽 클릭 메뉴, 색상), 정규식 검색을 갖춘 Finder 스타일의 다중 패널 파일 관리자입니다. 유료 확장 기능으로 아카이브 탐색, 서버/클라우드 연결, 고급 일괄 이름 변경이 추가됩니다.
