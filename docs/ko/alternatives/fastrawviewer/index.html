맥용 무료 FastRawViewer 대안

Schnellbild와 FastRawViewer을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

가격$23.99 일회성 구매(2026년 11월 할인가, 25% 할인, 라이선스당 컴퓨터 2대), 30일 체험판

플랫폼macOS, Windows

FastRawViewer의 장점

FastRawViewer는 사진가를 위한 빠른 RAW 뷰어이자 선별 도구입니다. RAW 히스토그램, 노출 경고, XMP에 저장되는 빠른 화이트 밸런스/노출 보정과 함께 실제 RAW 데이터를 보여 주며, 카탈로그 없이 사진에 별점, 레이블, 필터, 이름 변경, 복사, 이동을 할 수 있습니다.

FastRawViewer이(가) 더 나은 점

  • RAW 히스토그램, 노출 과다/부족 표시, 포커스 피킹이 있는 정확한 RAW 렌더링
  • Lightroom 등과 호환되는 별점/레이블/XMP
  • PCRE 정규식 파일 이름 필터
  • 동기화 확대가 되는 2/4분할 비교
  • 완전히 사용자 지정 가능한 단축키, 다른 앱을 흉내 내는 키 배치
  • NAS와 느린 매체용 튜닝
  • Windows에서도

Schnellbild가 더 나은 점

  • 무료, 모든 기능
  • 사진과 동영상을 한 격자에
  • MKV, WebM, AVI, WMV, FLV 재생
  • ZIP, RAR, 7z를 폴더처럼 열기
  • 만화책 CBZ, CBR
  • 아카이브 속 동영상 바로 재생
  • 나란히 놓인 두 패널(F5 복사, F6 이동)
