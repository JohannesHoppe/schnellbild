맥용 팟플레이어? 무료 대안은 여기 있습니다

Mac은 새것, 동영상은 그대로. 그런데 이삿짐에서 팟플레이어만 빠졌네요. MKV 파일들이 아직 재생을 기다리고 있습니다.

팟플레이어의 장점

팟플레이어는 카카오의 설정 폭이 매우 넓은 Windows 미디어 플레이어로, 코덱 내장, 하드웨어 디코딩, 3D/360° 출력, Whisper 음성 자막 생성을 포함한 자막 도구, 스트리밍을 갖췄습니다. 정지 이미지도 열고, ZIP/RAR 아카이브에서 미디어를 바로 재생합니다.

팟플레이어 팬들이 좋아하는 점, 그리고 Schnellbild에서는

  • 키보드로 넘겨 보기: 스페이스 바로 이미지를 열고 ← →로 폴더를 넘겨 봄.
  • 가져오기 없이 폴더를 바로 탐색: ⌘O로 폴더를 열거나 윈도우에 끌어다 놓기.
  • 폴더 미리보기가 있는 썸네일 격자: 폴더에 첫 이미지들이 표시되고, 이미지가 없는 폴더는 흐리게 표시.
  • HEIC, AVIF, JPEG XL, WebP: macOS 자체의 ImageIO로.
  • 애니메이션 GIF, PNG, WebP: 재생되며, 다른 이미지처럼 확대와 회전도 가능.
  • 확대, 이동, 회전(보기 전용): + − 또는 핀치로 확대, ⌥← ⌥→로 회전, 파일은 그대로.
  • ZIP, RAR, 7z를 폴더처럼 열기: 폴더처럼 열리며, 디스크에 아무것도 풀지 않음.
  • MKV, WebM, AVI, WMV, FLV 재생: 내장된 VLC 엔진으로.

팟플레이어이(가) 여전히 앞서는 점

  • 엄청나게 많은 설정, 렌더러, 필터(madVR, HDR 톤 매핑, 프레임 보간)
  • 온라인 자막 다운로드, 자막 번역, 음성 자막 생성(Whisper)
  • 스트리밍(YouTube, HLS/DASH), TV/DVD/Blu-ray, 3D와 360° VR
  • 단축키와 스킨 완전 사용자 지정
  • 앨범 아트, 가사, ReplayGain이 있는 음악 재생

일부러 뺀 기능

  • 동영상 옆의 자막 파일 불러오기: 동영상 파일만 읽고, 옆에 있는 파일은 읽지 않음.
  • 재생 목록 저장: 재생 목록 대신 폴더: 목록은 슬라이드 쇼가 만듦.
  • PIP(화면 속 화면): 폴더를 훑어보기 위한 앱입니다. 다른 일을 하며 옆에 띄워 보려면 동영상 플레이어가 더 맞습니다.
  • 오디오 파일, 음악 모드: 이미지와 동영상만, 오디오 파일은 전용 앱에서.
  • 인터넷 스트림과 주소 재생: 원칙적으로 인터넷에 접속하지 않음.
  • 인터넷에서 자막 내려받기: 원칙적으로 인터넷에 접속하지 않음.
  • 보관함, 카탈로그, 태그, 별점: 보관함 대신 폴더: 가져올 것이 없음.

내 폴더로 직접 써 보세요.
