맥용 무료 Sequential 대안

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

무료 다운로드Schnellbild.dmg Mac App Store곧 출시, 개발 후원용

Sequential 대신 Schnellbild?

Schnellbild는 CBZ, CBR, ZIP, RAR, 7z를 디스크에 풀지 않고 폴더처럼 열며, 화살표 키로 페이지를 넘깁니다. Schnellbild와 Sequential을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

Sequential이(가) 더 나은 점

  • 페이지 이동과 색상 반전 모드로 PDF를 페이지별로 읽기
  • 만화용 오른쪽에서 왼쪽 읽기 방향
  • 일시 정지/이어 보기로 아카이브 속 읽던 위치 저장
  • 분할 7z를 포함해 XADMaster로 다양한 아카이브 포맷
  • 오래된 macOS(Intel은 10.14, Apple 실리콘은 11.4)에서 실행

Schnellbild가 더 나은 점

  • 사진과 동영상을 한 격자에
  • MKV, WebM, AVI, WMV, FLV 재생
  • 아카이브 속 동영상 바로 재생
  • 나란히 놓인 두 패널(F5 복사, F6 이동)
  • 파일을 바꾸지 않는 자동 향상과 슬라이더
  • 화살표 키로 동영상 훑어보기
  • 이름 변경, 이동, 휴지통 실행 취소

Sequential의 장점

가격무료
버전2.6.0
최근 업데이트2024-09-07
플랫폼macOS

Sequential은 폴더, PDF, 아카이브(ZIP/CBZ, RAR/CBR, 7z)를 열어 한 윈도우에서 넘겨 보는 고전적인 오픈 소스 Mac 이미지·만화 뷰어입니다. chuchusoft 포크가 Apple 실리콘의 macOS 11.4 이상용 유니버설 앱으로 현대화했으며, 관리자는 추가 개발 가능성이 낮다고 말합니다. 원래의 btrask/Sequential은 2013년에 마지막으로 업데이트되었습니다.
