Pixea의 장점

미니멀한 이미지·동영상 뷰어에서 마스크, 개체 지우기, 업스케일링을 갖춘 사진 편집기로 자랐습니다. 폴더, 사진 보관함, ZIP/CBZ 아카이브를 탐색하고, 자막과 오디오 트랙 선택이 되는 MKV를 재생합니다. 검색, 정렬, 사용자 지정 단축키는 Pixea Plus가 필요합니다.

Pixea이(가) 더 나은 점

  • 이미지 편집기(마스크, 개체 지우기, 업스케일링, LUT)
  • 일괄 편집과 변환
  • 내장 자막, 오디오 트랙, 재생 속도
  • 사진 보관함 열기
  • XMP 사이드카를 쓰는 태그와 별점
  • 중복 검색

Schnellbild가 더 나은 점

  • 나란히 놓인 두 패널(F5 복사, F6 이동)
  • 오픈 소스
  • Finder와 훑어보기에서 MKV 등의 썸네일
  • 확장자가 내용과 맞지 않는 파일 알림
