맥용 MPC-BE? 무료 대안은 여기 있습니다

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

MPC-BE 대신 Schnellbild?

Schnellbild는 본격적인 미디어 플레이어가 아닙니다. 폴더의 동영상을 사진 옆에 썸네일로 보여 주고, MKV, AVI, WebM을 재생하며, 화살표 키로 동영상의 10분의 1씩 이동합니다. Mac은 새것, 동영상은 그대로. 그런데 이삿짐에서 MPC-BE만 빠졌네요. MKV 파일들이 아직 재생을 기다리고 있습니다.

MPC-BE 팬들이 좋아하는 점, 그리고 Schnellbild에서는

  • 키보드로 넘겨 보기: 스페이스 바로 이미지를 열고 ← →로 폴더를 넘겨 봄.
  • 가져오기 없이 폴더를 바로 탐색: ⌘O로 폴더를 열거나 윈도우에 끌어다 놓기.
  • HEIC, AVIF, JPEG XL, WebP: macOS 자체의 ImageIO로.
  • 확대, 이동, 회전(보기 전용): + − 또는 핀치로 확대, ⌥← ⌥→로 회전, 파일은 그대로.
  • MKV, WebM, AVI, WMV, FLV 재생: 내장된 VLC 엔진으로.
  • 동영상에 들어 있는 자막: V로 켜고 끄기, ⌃⌘S로 트랙 선택. 중간에 켜도 지금 나오는 대사가 바로 보이고, ASS는 스타일을 그대로 유지합니다.
  • 오디오 트랙 선택: ⌃⌘A 또는 컨트롤 막대.
  • 재생 속도: < >로 0.5배에서 2배까지, 목소리 음높이는 그대로.

MPC-BE이(가) 여전히 앞서는 점

  • 자주 업데이트되는 가벼운 Windows 플레이어
  • 다크 테마, 다양한 렌더러와 디코더 옵션
  • 자막 다운로드, yt-dlp 스트리밍
  • 보스 키, 키 설정 가능

일부러 뺀 기능

  • 동영상 옆의 자막 파일 불러오기: 동영상 파일만 읽고, 옆에 있는 파일은 읽지 않음.
  • 재생 목록 저장: 재생 목록 대신 폴더: 목록은 슬라이드 쇼가 만듦.
  • 오디오 파일, 음악 모드: 이미지와 동영상만, 오디오 파일은 전용 앱에서.
  • 인터넷 스트림과 주소 재생: 원칙적으로 인터넷에 접속하지 않음.
  • 인터넷에서 자막 내려받기: 원칙적으로 인터넷에 접속하지 않음.
