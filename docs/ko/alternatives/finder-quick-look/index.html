맥용 무료 Finder와 훑어보기 대안

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

Finder와 훑어보기 대신 Schnellbild?

Schnellbild에는 보관함이 없습니다. 사진과 동영상을 디스크에 있는 그대로, 메타데이터의 촬영 날짜와 장소와 함께 보여 주고, 아무것도 업로드하지 않습니다. Schnellbild와 Finder와 훑어보기을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

Schnellbild는 완전한 파일 관리자가 아닙니다. FTP, SFTP, 클라우드 연결도, 폴더 동기화도, 압축 파일 만들기도 없습니다. 사진과 동영상을 훑어보고 정리하기 위해 만들었습니다. 모든 파일의 썸네일, 나란히 놓인 두 패널(F5로 복사, F6으로 이동), 폴더처럼 열리는 아카이브.

Finder와 훑어보기이(가) 더 나은 점

  • macOS에 내장, 거의 모든 파일 형식에서 작동
  • 태그, 스마트 폴더, Spotlight 검색
  • 일괄 이름 변경과 빠른 동작
  • iCloud Drive와 AirDrop

Schnellbild가 더 나은 점

  • MKV, WebM, AVI, WMV, FLV 재생
  • ZIP, RAR, 7z를 폴더처럼 열기
  • 만화책 CBZ, CBR
  • 아카이브 속 동영상 바로 재생
  • 나란히 놓인 두 패널(F5 복사, F6 이동)
  • 모든 하위 폴더의 사진과 동영상을 섞어서 슬라이드 쇼
  • 파일을 바꾸지 않는 자동 향상과 슬라이더

Mac의 파일 관리자와, 거의 모든 파일을 스페이스 바로 미리 보는 훑어보기입니다. 사진이나 MP4를 잠깐 보거나 일상적인 파일 관리에는 충분합니다.
