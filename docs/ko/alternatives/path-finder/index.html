맥용 무료 Path Finder 대안

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

Path Finder 대신 Schnellbild?

Schnellbild는 파일 관리자가 아니라 두 개의 패널이 있는 뷰어입니다. F5는 표시한 이미지를 다른 패널로 복사하고 F6은 이동하며, 둘 다 되돌릴 수 있습니다. Schnellbild와 Path Finder을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

Schnellbild는 완전한 파일 관리자가 아닙니다. FTP, SFTP, 클라우드 연결도, 폴더 동기화도, 압축 파일 만들기도 없습니다. 사진과 동영상을 훑어보고 정리하기 위해 만들었습니다. 모든 파일의 썸네일, 나란히 놓인 두 패널(F5로 복사, F6으로 이동), 폴더처럼 열리는 아카이브.

Path Finder이(가) 더 나은 점

  • 모듈: 미리보기, 정보, 터미널, Drop Stack, Git, 16진수/텍스트 편집기
  • 용량 브라우저와 폴더 동기화/병합
  • 일괄 이름 변경, 안전한 삭제, 관리자 권한 접근
  • 20개 인터페이스 언어
  • 책갈피 막대, 탭 프리셋

Schnellbild가 더 나은 점

  • 무료, 모든 기능
  • ZIP, RAR, 7z를 폴더처럼 열기
  • 만화책 CBZ, CBR
  • 아카이브 속 동영상 바로 재생
  • 모든 하위 폴더의 사진과 동영상을 섞어서 슬라이드 쇼
  • 파일을 바꾸지 않는 자동 향상과 슬라이더
  • 화살표 키로 동영상 훑어보기
