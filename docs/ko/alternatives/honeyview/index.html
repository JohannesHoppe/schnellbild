맥용 꿀뷰? 무료 대안은 여기 있습니다

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

꿀뷰 대신 Schnellbild?

Schnellbild는 CBZ, CBR, ZIP, RAR, 7z를 디스크에 풀지 않고 폴더처럼 열며, 화살표 키로 페이지를 넘깁니다. 만화책은 군말 없이 Mac으로 건너왔습니다. 꿀뷰만 이삿짐 트럭을 놓쳤을 뿐.

꿀뷰 팬들이 좋아하는 점, 그리고 Schnellbild에서는

  • 키보드로 넘겨 보기: 스페이스 바로 이미지를 열고 ← →로 폴더를 넘겨 봄.
  • 가져오기 없이 폴더를 바로 탐색: ⌘O로 폴더를 열거나 윈도우에 끌어다 놓기.
  • 폴더 미리보기가 있는 썸네일 격자: 폴더에 첫 이미지들이 표시되고, 이미지가 없는 폴더는 흐리게 표시.
  • HEIC, AVIF, JPEG XL, WebP: macOS 자체의 ImageIO로.
  • 카메라 RAW: macOS가 아는 RAW 포맷을 macOS가 현상.
  • 애니메이션 GIF, PNG, WebP: 재생되며, 다른 이미지처럼 확대와 회전도 가능.
  • 확대, 이동, 회전(보기 전용): + − 또는 핀치로 확대, ⌥← ⌥→로 회전, 파일은 그대로.
  • ZIP, RAR, 7z를 폴더처럼 열기: 폴더처럼 열리며, 디스크에 아무것도 풀지 않음.

꿀뷰이(가) 여전히 앞서는 점

  • 오래된 Windows(XP부터 11, 32비트)에서도 아주 가볍고 빠름
  • 스마트 두 쪽 보기, 오른쪽에서 왼쪽 만화 모드
  • 더 많은 압축 포맷(LZH, TAR)과 BPG

일부러 뺀 기능

  • 두 쪽 보기, 오른쪽에서 왼쪽 만화 모드: 한 번에 이미지 한 장, 윈도우에 맞게 최대한 크게.
  • 이미지 편집(자르기, 크기 조절, 저장): 이미지를 보여 줄 뿐 바꾸지 않습니다: 파일은 그대로.
  • 일괄 변환, 일괄 이름 변경: 일괄 변환과 일괄 이름 변경은 다른 앱에 맡깁니다.
