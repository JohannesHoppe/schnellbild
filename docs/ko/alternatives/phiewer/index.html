맥용 무료 Phiewer 대안

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

Phiewer 대신 Schnellbild?

Schnellbild는 가져오기 없이 폴더를 바로 열고, 화살표 키로 이미지를 넘깁니다. HEIC, RAW, PSD, 움직이는 GIF, PDF도 되고, 폴더의 동영상도 같은 격자에 나옵니다. Schnellbild와 Phiewer을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

Phiewer이(가) 더 나은 점

  • 중복 찾기와 최대 9장 비교 보기
  • Showcases: 여러 폴더에 걸친 가상 앨범 저장
  • Finder 태그와 설명, 태그/EXIF/날짜로 검색
  • 오디오 파일과 인쇄
  • PRO의 이미지 편집(자르기, 필터, 크기 조절)
  • 극장 모드

Schnellbild가 더 나은 점

  • ZIP, RAR, 7z를 폴더처럼 열기
  • 만화책 CBZ, CBR
  • 아카이브 속 동영상 바로 재생
  • 나란히 놓인 두 패널(F5 복사, F6 이동)
  • 오픈 소스
  • 인터넷에 접속하지 않음
  • Finder와 훑어보기에서 MKV 등의 썸네일
