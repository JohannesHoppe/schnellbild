맥용 무료 ImageGlass 대안

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

무료 다운로드Schnellbild.dmg Mac App Store곧 출시, 개발 후원용

ImageGlass 대신 Schnellbild?

Schnellbild는 가져오기 없이 폴더를 바로 열고, 화살표 키로 이미지를 넘깁니다. HEIC, RAW, PSD, 움직이는 GIF, PDF도 되고, 폴더의 동영상도 같은 격자에 나옵니다. Schnellbild와 ImageGlass을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

ImageGlass이(가) 더 나은 점

  • 하나의 코드로 Windows, macOS, Linux에서 실행
  • AVIF, JPEG XL, HDR, EXR의 HDR 톤 매핑
  • 애니메이션 SVG 네이티브 렌더링
  • 추가 포맷용 코덱 플러그인 SDK
  • 자르기, 크기 조절, 색상 추출 도구 내장
  • 테마와 사용자 지정 레이아웃
  • 무료판에서도 사용자 지정 단축키

Schnellbild가 더 나은 점

  • 사진과 동영상을 한 격자에
  • MKV, WebM, AVI, WMV, FLV 재생
  • ZIP, RAR, 7z를 폴더처럼 열기
  • 만화책 CBZ, CBR
  • 아카이브 속 동영상 바로 재생
  • 나란히 놓인 두 패널(F5 복사, F6 이동)
  • 모든 하위 폴더에서 이름 검색

ImageGlass의 장점

가격Classic 무료, Pro Individual $14.90 일회성, Pro Team $69 일회성(사용자 3명), Pro Business는 수량별(25명 연 $290부터)
버전10.0.6.906
최근 업데이트2026-09-05
플랫폼Windows, macOS, Linux

빠른 오픈 소스 이미지 뷰어로, v10에서 .NET/Avalonia 기반으로 새로 만들어져 Windows, macOS(Apple 실리콘), Linux에서 실행됩니다. 폭넓은 포맷(RAW, JXL, HEIC, AVIF, HDR, 네이티브 SVG 포함 90가지 이상), 똑똑한 캐싱, 테마, 사용자 지정 단축키, 코덱 플러그인을 갖췄습니다. 갤러리 띠가 있는 단일 이미지 뷰어로, 폴더 브라우저가 아니며 동영상은 재생하지 않습니다.
