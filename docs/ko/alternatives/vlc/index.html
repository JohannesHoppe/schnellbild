VLC의 장점

가장 유명한 무료 오픈 소스 미디어 플레이어입니다. 코덱 팩 없이 모든 플랫폼에서 거의 모든 파일, 디스크, 스트림을 재생합니다. 무엇보다 플레이어이며, 이미지는 일정 시간 표시되는 정지 화면이고 파일 브라우저나 썸네일 격자는 없습니다.

VLC이(가) 더 나은 점

  • 거의 모든 포맷, 디스크(DVD/Blu-ray), 네트워크 스트림, 캡처 장치 재생
  • 모든 데스크톱과 모바일 OS에서 실행
  • 파일과 온라인(VLSub) 자막, 오디오 트랙, 속도, 필터, 변환/스트리밍 출력
  • 재생 목록 저장, 음악, 시각화
  • 모든 단축키 재지정 가능

Schnellbild가 더 나은 점

  • 사진과 동영상을 한 격자에
  • 만화책 CBZ, CBR
  • 나란히 놓인 두 패널(F5 복사, F6 이동)
  • 이름 변경, 이동, 휴지통 실행 취소
  • Apple의 App Sandbox에서 실행
  • Finder와 훑어보기에서 MKV 등의 썸네일
