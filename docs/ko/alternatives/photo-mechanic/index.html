Photo Mechanic의 장점

Photo Mechanic은 현업 사진가, 특히 보도, 스포츠, 웨딩 사진가를 위한 빠른 가져오기·선별·메타데이터 도구입니다. 폴더와 메모리 카드를 바로 열고, RAW 파일을 내장 미리보기로 즉시 보여 주며, 마감에 쫓기는 캡션, IPTC 메타데이터, 키워드, 일괄 이름 변경, 업로드를 위해 만들어졌습니다.

Photo Mechanic이(가) 더 나은 점

  • 여러 메모리 카드에서 동시에 가져오며, 복사하면서 이름 변경과 메타데이터 입력
  • 마감용 캡션을 위한 IPTC/XMP 메타데이터, 코드 치환, 변수, 구조화된 키워드
  • 별점, 색상 등급, 태그로 수천 장의 RAW를 빠르게 선별
  • 일괄 이름 변경, 다른 이름으로 저장/크기 조절/워터마크, FTP, Dropbox, S3, PhotoShelter 등으로 바로 업로드
  • 파일 이름과 메타데이터 전체에서 정규식 찾기와 바꾸기
  • 프리셋이 있는 완전한 단축키 사용자 지정, 인쇄용 단축키 PDF
  • 같은 기능의 Windows판

Schnellbild가 더 나은 점

  • 무료, 모든 기능
  • ZIP, RAR, 7z를 폴더처럼 열기
  • 만화책 CBZ, CBR
  • 아카이브 속 동영상 바로 재생
  • 나란히 놓인 두 패널(F5 복사, F6 이동)
  • 파일을 바꾸지 않는 자동 향상과 슬라이더
  • 화살표 키로 동영상 훑어보기
