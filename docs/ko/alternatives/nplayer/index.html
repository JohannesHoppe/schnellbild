맥용 무료 nPlayer 대안

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

nPlayer 대신 Schnellbild?

Schnellbild는 본격적인 미디어 플레이어가 아닙니다. 폴더의 동영상을 사진 옆에 썸네일로 보여 주고, MKV, AVI, WebM을 재생하며, 화살표 키로 동영상의 10분의 1씩 이동합니다. Schnellbild와 nPlayer을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

nPlayer이(가) 더 나은 점

  • 네트워크 프로토콜(SMB, NFS, SFTP, WebDAV, UPnP)
  • 고급 자막(스타일, 싱크, SMI, SUP)
  • A-B 구간 반복, 어학용 '듣기 연습'
  • PIP, 재생 속도
  • 오디오 이퀄라이저와 싱크

Schnellbild가 더 나은 점

  • 무료, 모든 기능
  • 사진과 동영상을 한 격자에
  • ZIP, RAR, 7z를 폴더처럼 열기
  • 만화책 CBZ, CBR
  • 아카이브 속 동영상 바로 재생
  • 나란히 놓인 두 패널(F5 복사, F6 이동)
  • 모든 하위 폴더의 사진과 동영상을 섞어서 슬라이드 쇼
