맥용 무료 qView 대안

Schnellbild는 폴더 속 이미지와 동영상을 위한 무료 Mac 앱입니다. 폴더를 열면 썸네일이 바로 나오고, 키 하나로 이미지를 크게 봅니다. MKV, AVI, WebM을 재생하고, ZIP과 RAR 압축 파일을 폴더처럼 열며, 계정도 네트워크 연결도 필요 없습니다.

무료 다운로드Schnellbild.dmg Mac App Store곧 출시, 개발 후원용

qView 대신 Schnellbild?

Schnellbild는 가져오기 없이 폴더를 바로 열고, 화살표 키로 이미지를 넘깁니다. HEIC, RAW, PSD, 움직이는 GIF, PDF도 되고, 폴더의 동영상도 같은 격자에 나옵니다. Schnellbild와 qView을(를) 나란히: 각자 더 잘하는 점, 그리고 모든 기능을 출처와 함께.

qView이(가) 더 나은 점

  • 군더더기 없는 아주 미니멀한 윈도우
  • Windows와 Linux, 오래된 macOS(10.13 이상 레거시 빌드)에서도 실행
  • 애니메이션 이미지 프레임 단위 이동과 속도 조절
  • URL에서 이미지를 바로 열기

Schnellbild가 더 나은 점

  • 사진과 동영상을 한 격자에
  • MKV, WebM, AVI, WMV, FLV 재생
  • ZIP, RAR, 7z를 폴더처럼 열기
  • 만화책 CBZ, CBR
  • 아카이브 속 동영상 바로 재생
  • 나란히 놓인 두 패널(F5 복사, F6 이동)
  • 모든 하위 폴더의 사진과 동영상을 섞어서 슬라이드 쇼

qView는 도구 막대가 없는 미니멀한 크로스 플랫폼 이미지 뷰어입니다. 파일 하나를 열고 나머지 폴더를 넘겨 보게 해 줍니다. 빨리 시작되고, 이웃 이미지를 미리 불러오며, Qt 플러그인으로 애니메이션 이미지와 다양한 포맷을 지원합니다.
