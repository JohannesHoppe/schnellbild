개인정보 처리방침

Schnellbild는 macOS용 이미지·비디오 뷰어입니다. GDPR상 컨트롤러(개인정보 처리 책임자)는 HAUS HOPPE - ITS(Johannes Hoppe)입니다. 전체 주소는 법적 고지에 있습니다. 이 방침은 GitHub에서 다운로드한 앱과 Mac App Store에서 구입한 앱(둘은 같은 앱입니다), 그리고 이 웹사이트에 적용됩니다.

앱

Schnellbild는 개인 데이터를 수집하지 않습니다. 계정, 분석, 광고, 추적이 없으며 인터넷에 연결하지 않습니다. 앱이 실행되는 App Sandbox는 네트워크 접근을 전혀 허용하지 않습니다.

사용자의 Mac에만 저장되는 항목:

  • 설정(마지막 폴더, 정렬 순서, 책갈피, 음량 등): 앱 자체의 환경설정에 저장됩니다.
  • 폴더 접근: Schnellbild에 열어 준 폴더가 재시작 후에도 다시 표시될 수 있도록 macOS 책갈피로 저장됩니다. 설정 → ‘폴더 접근 지우기’에서 지울 수 있습니다.
  • 입력한 아카이브 암호: 로그인 키체인에 저장됩니다(항목 이름 'Schnellbild archive passwords'). 설정 → ‘저장된 암호 지우기’ 버튼으로 삭제할 수 있습니다.
  • 썸네일: macOS 자체의 썸네일 캐시에 저장됩니다.

Schnellbild는 사용자에게 보여 주기 위해서만 이미지, 비디오, 아카이브를 읽습니다. 파일 자체나 그 이름, 그에 관한 어떤 정보도 어디로도 보내지 않습니다. 다운로드와 구입은 Apple이 자체 개인정보 처리방침에 따라 처리하며, 당사에는 사용자의 신원이 포함되지 않은 수치만 제공합니다. 판매량, 그리고 macOS에서 앱 개발자와의 공유를 허용한 경우 충돌 리포트와 사용 통계입니다.

이 웹사이트

이 웹사이트는 쿠키, 분석, 다른 서버의 콘텐츠(웹 폰트, 임베드된 비디오 등)를 사용하지 않습니다. 호스팅은 GitHub, Inc.(미국)의 서비스인 GitHub Pages를 이용합니다. 방문 시 GitHub는 보안 목적으로 IP 주소를 기록하고 저장합니다. 자세한 내용은 GitHub Pages: 데이터 수집 및 GitHub 개인정보처리방침을 참조하세요. GitHub가 이 로그를 얼마나 오래 보관하는지는 GitHub가 정하며, 당사는 로그에 접근할 수 없습니다. GitHub는 EU-U.S. Data Privacy Framework에 참여하고 있으며, 유럽연합 집행위원회는 이 프레임워크에 따라 미국이 적정한 보호 수준을 보장한다고 결정했습니다(GDPR 제45조). 법적 근거는 웹사이트를 안전하게 제공하려는 당사의 정당한 이익입니다(EU 일반 개인정보 보호법(GDPR) 제6조 제1항 (f)). 앱 다운로드도 GitHub에서 제공됩니다.

사용자의 권리

GDPR에 따라 사용자는 열람, 정정, 삭제, 처리 제한, 데이터 이동의 권리와 개인정보 보호 감독 기관에 민원을 제기할 권리를 가집니다. <strong>또한 자신의 특수한 상황과 관련된 사유로 당사의 정당한 이익에 근거한 처리에 반대할 권리가 있습니다</strong>(GDPR 제21조). 앱과 이 웹사이트 모두 자체적으로 개인 데이터를 보관하지 않으므로, 일반적으로 당사 측에서 조회하거나 삭제할 데이터는 없습니다.
