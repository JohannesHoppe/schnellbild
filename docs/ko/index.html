주요 기능

크게 보고, 키로 넘기기

스페이스 바를 누르면 이미지가 윈도우에 맞게 최대한 크게 열리고, ◀ / ▶로 폴더를 넘겨 봅니다. 트랙패드나 + / −로 확대, ⌥ + ◀ / ⌥ + ▶로 회전, F로 전체 화면. 애니메이션이 있는 Graphics Interchange Format(.gif), Scalable Vector Graphics(.svg)도 지원하고, Portable Document Format(.pdf)는 한 페이지씩 보여 줍니다(모든 형식).

슬라이드 쇼(S)는 폴더와 모든 하위 폴더를 사진과 동영상 구분 없이 보여 줍니다. 슬라이드 쇼가 재생하는 것이 곧 재생 목록입니다. P를 누르면 열려서 순서를 바꾸거나 필요 없는 항목을 뺄 수 있습니다.

지도와 지구본 위의 내 사진

L을 누를 때마다 격자, 목록, 아틀라스 순으로 바뀝니다. 아틀라스에서는 폴더와 하위 폴더의 사진과 동영상이 촬영한 장소에 표시됩니다. 멀리 축소하면 지도는 별이 가득한 하늘 앞의 지구본이 되고, 원하면 낮과 밤을 켜서 밤 쪽에 도시의 불빛을 볼 수 있습니다. 확대하면 평평한 지도로 펼쳐집니다.

  • 타임라인은 여행을 시간순으로 펼칩니다. 한 구간을 드래그하면 지도에는 그 부분만 표시됩니다
  • 지구본을 지평선 쪽으로 기울일 수 있고, 원하면 지형을 과장해 피오르와 산이 도드라집니다
  • T로 여행을 재생합니다. 지도가 장소에서 장소로 이동하고, 사진이 크게 나오고, 동영상이 몇 초씩 재생됩니다
  • 지도는 앱에 들어 있습니다. 인터넷에 접속하지 않고, 어떤 위치도 Mac 밖으로 나가지 않습니다

MKV, AVI까지, macOS가 재생하지 못하는 동영상도

모두 재생되며 HDR도 지원합니다. MPEG-4 Part 14(.mp4), QuickTime File Format(.mov .qt), Advanced Video Coding High Definition(AVCHD, .mts .m2ts), Matroska Video(.mkv), WebM(.webm), Audio Video Interleave(.avi), Windows Media Video(.wmv), Flash Video(.flv), MPEG Program Stream(MPEG-PS, .mpg .mpeg), DVD Video Object(.vob), RealMedia(.rm), Material Exchange Format(.mxf) 등(모든 동영상 형식).

  • ◀ / ▶로 동영상의 10분의 1, ⇧ + ◀ / ⇧ + ▶로 100분의 1씩 이동
  • ▲ / ▼로 음량 조절, 모든 동영상에 적용
  • ⌘ + ▶로 다음 동영상으로, ⌘ + ◀로 돌아오면 앞의 동영상은 멈췄던 곳부터 이어집니다
  • 동영상 속 자막(V)은 처음부터 표시되고, 재생 중간에 켜도 지금 나오는 대사가 바로 보입니다. ASS 자막은 위치, 색상, 글꼴도 그대로입니다
  • 오디오 트랙, 속도(< / >), 모든 동영상에 같은 컨트롤 막대. 끌어다 놓은 곳에 그대로 있습니다
  • Finder와 훑어보기에서도 .mkv, .webm, .wmv, .flv, .vob 썸네일 표시

ZIP·RAR 만화책도 폴더처럼 열기

ZIP Archive(.zip), Roshal Archive(.rar), 7-Zip Archive(.7z)는 물론 만화 Comic Book ZIP Archive(.cbz), Comic Book RAR Archive(.cbr), Comic Book 7z Archive(.cb7)까지, 여러 개로 분할된 파일도 열리며, ZIP과 RAR은 암호가 걸려 있어도 열립니다. 디스크에는 아무것도 풀지 않으며, 동영상도 아카이브에서 바로 재생됩니다.

여행 사진을 Norton Commander처럼 정리하기

D를 누르면 두 폴더가 나란히 표시됩니다. 이미지를 표시한 다음 F5로 반대편에 복사하고 F6로 이동하세요. 드래그해도 됩니다.

이름 변경, 새로운 폴더, 휴지통, 책갈피, 그리고 이름 변경, 휴지통으로 이동, 복사, 이동의 실행 취소까지.

모든 하위 폴더 검색

검색 필드는 보고 있는 폴더와 그 아래 모든 곳에서 폴더, 아카이브, 이미지, 동영상의 이름을 찾습니다. 검색하는 동안 결과가 바로바로 나타나며, 느린 네트워크 공유에서도 마찬가지입니다. 대소문자 무시, 대소문자 구분, 정규 표현식 중에서 고를 수 있습니다.

더 나은 화면, 그대로인 파일

E를 누르면 노출, 대비, 채도, 선명도가 자동으로 향상됩니다. 사진과 동영상 모두에 적용됩니다. A를 누르면 슬라이더가 열립니다. 바뀌는 것은 화면뿐, 파일은 그대로입니다.

파일의 진짜 정체

I 또는 ⌘ + I를 누르면 이미지 옆에 파일 정보가 열립니다. 언제 어디서 찍었는지(작은 지도와 가까운 지명 포함), 카메라와 렌즈, 포맷, 해상도, 코덱, 비트레이트, 비트 심도, 색상 프로파일, 그리고 모든 메타데이터 키(EXIF, GPS, IPTC, XMP, QuickTime)를 필터링하고 복사할 수 있습니다. 시간과 장소는 XMP 사이드카, GoPro나 DJI 드론의 GPS 데이터, 소니의 클립 파일, 폴더 안의 GPX 트랙에서도 읽어 옵니다.

확장자가 내용과 맞지 않는 파일은 알려 줍니다. 이름만으로는 알 수 없는 파일은 내용으로 판단하고, 다운로드 중인 파일(.part, .crdownload 등)은 받은 데까지 보여 줍니다.

모든 키를 한눈에

F1은 모든 키를 보여 주며 인쇄도 할 수 있습니다. K는 클릭해서 쓰는 작은 키보드를 띄웁니다. 키를 직접 지정하거나 Phiewer와 같은 키 배치로 바꿀 수 있습니다. 격자, 목록 또는 아틀라스(L), 이름, 종류, 날짜, 크기, 특정 장소로부터의 거리로 정렬, 여러 윈도우, 그리고 보스 키(X)까지. VoiceOver가 모든 타일을 읽어 주고, ‘동작 줄이기’를 켜면 아무것도 미끄러지지 않습니다.

라이트든 다크든, 원하는 대로

다크 모드만 고집하는 사람도, 질색하는 사람도 있습니다. 그래서 선택은 당신 몫입니다. 설정(⌘ + ,)에서 시스템과 동일, 라이트, 다크 중에서 고르세요.

다른 사람이 보낸 파일도 안전하게

모르는 사람이 보낸 사진, 동영상, 아카이브를 보는 것이 바로 뷰어가 하는 일입니다. 그래서 Schnellbild는 처음부터 모든 파일을 위험한 것으로 취급합니다.

  • Apple의 App Sandbox에서 실행. 네트워크에 전혀 접속하지 않고 스스로 다른 프로그램을 실행하지도 않으며, 사용자가 열어 준 폴더와 사진 폴더에만 접근합니다. 이는 macOS가 강제하므로, 저희가 원하더라도 속일 수 없습니다. 앱은 아예 인터넷에 접속할 수 없습니다.
  • 읽기만 합니다. 보는 것만으로 파일이 바뀌거나 디스크에 풀리는 일은 없습니다.
  • 동영상이 인터넷에 접속하지 않습니다. 알고 보니 인터넷을 가리키는 재생 목록인 '동영상'은 아무것도 재생하지 않습니다.
  • 이중 클릭으로는 문서만 열립니다. 프로그램은 열리지 않습니다. 앱, 스크립트, 설치 프로그램은 이미지 이름 뒤에 숨어 있어도 절대 열리지 않습니다.
  • 서명과 공증 완료, Apple의 Hardened Runtime 적용.
  • 공개된 소스 코드로 빌드되었음을 증명할 수 있습니다. 각 다운로드가 어떤 커밋과 어떤 빌드에서 나왔는지 GitHub가 서명으로 증명합니다. 누구나 확인할 수 있습니다.

구체적으로 무엇을 하는지, 그리고 한계는 어디인지: 다른 사람이 보낸 파일도 안전하게.

Phiewer, IINA, Norton Commander를 쓰다가 오셨나요?

Phiewer는 유료 PRO 버전이 있는 빠른 사진 뷰어이고, IINA는 동영상 감상을 위한 본격적인 플레이어입니다. 둘 다 Schnellbild의 본보기였고, 이중 패널은 Norton Commander가 본보기였습니다. Schnellbild는 폴더 속 사진과 동영상을 무료 앱 하나에 담았고, 원하면 키를 Phiewer와 똑같이 쓸 수 있습니다. Schnellbild와 비교해 보세요: 무료 Phiewer 대안, 동영상을 훑어보기 위한 무료 IINA 대안, Norton Commander에서 Mac으로. Windows에서 꿀뷰(Honeyview)나 반디뷰(BandiView)를 쓰던 분도 Mac에서 똑같이 폴더와 ZIP·RAR 속 이미지를 키보드로 넘겨 볼 수 있습니다.
