Schnellbild

짜증 날 일 없는 macOS용 이미지·비디오 뷰어.

폴더를 열면 썸네일이 보입니다. 사진 한 장을 크게 띄우고 키보드로 넘겨 보세요. 비디오도 그 자리에서 재생됩니다. MKV, AVI, WebM까지. 가져올 보관함도, 기다림도, 군더더기도 없습니다.

macOS 15 이상, Apple 실리콘. Developer ID로 서명되고 Apple의 공증을 받았으며 Apple의 App Sandbox에서 실행됩니다. 두 버전 모두 모든 기능을 갖춘 같은 앱입니다. App Store에서 구입하면 개발을 후원하게 됩니다.

짜증 날 일 없는 이유

광고도, 추적도, 계정도 없음

사진을 보여 줄 뿐, 누구와도 통신하지 않습니다.

추가 결제 유도 없음

Pro 버전도, 구독도, '잠금 해제' 버튼도 없습니다. 모든 기능이 이미 들어 있습니다.

군더더기 없음

가져올 보관함도, 편집기도, 클라우드도 없습니다. 사진과 비디오 보기, 그것 하나를 제대로 합니다.

빠름

스크롤하는 동안 썸네일이 나타납니다. 큰 폴더나 네트워크 공유도 마찬가지입니다.

처음부터 안전

다른 사람이 보낸 사진, 비디오, 아카이브는 아무것도 실행하지 않고 어디에도 접속하지 않습니다. 먼저 켜야 할 설정도 없습니다.

멈추지 않음

손상된 파일, 낯선 포맷, 느린 디스크가 있어도 앱이 종료되는 대신 자리 표시자가 나타납니다.

주요 기능

크게 보고, 키로 넘기기

스페이스 바를 누르면 이미지가 윈도우에 맞게 최대한 크게 열리고, ← →로 폴더를 넘겨 봅니다. 트랙패드나 + −로 확대, ⌥← ⌥→로 회전, f로 전체 화면. 애니메이션 GIF, SVG, PDF도 지원합니다.

슬라이드 쇼(s)는 폴더와 모든 하위 폴더를 사진과 비디오 구분 없이 보여 줍니다.

macOS가 재생하지 못하는 비디오까지

macOS가 자체적으로 재생하는 형식(MP4, MOV, AVCHD 등)은 macOS로, 그 밖의 모든 형식(MKV, WebM, AVI, WMV, FLV, MPEG, DVD 비디오)은 내장된 VLC 엔진으로 재생합니다.

  • ← →로 비디오의 10분의 1, ⇧← ⇧→로 100분의 1씩 이동
  • ↑ ↓로 음량 조절, 모든 비디오에 적용
  • Finder와 훑어보기에서도 MKV, WebM, WMV, FLV, VOB 썸네일 표시

아카이브를 폴더처럼 열기

ZIP, RAR, 7z는 물론 만화(CBZ, CBR)까지, 여러 개로 분할된 파일도 열리며, ZIP과 RAR은 암호가 걸려 있어도 열립니다. 디스크에는 아무것도 풀지 않으며, 비디오도 아카이브에서 바로 재생됩니다.

여행 사진을 Norton Commander처럼 정리하기

D를 누르면 두 폴더가 나란히 표시됩니다. 이미지를 표시한 다음 F5로 반대편에 복사하고 F6로 이동하세요. 드래그해도 됩니다.

이름 변경, 새로운 폴더, 휴지통, 책갈피, 그리고 이름 변경, 휴지통으로 이동, 복사, 이동의 실행 취소까지.

모든 하위 폴더 검색

검색 필드는 보고 있는 폴더와 그 아래 모든 곳에서 폴더, 아카이브, 이미지, 비디오의 이름을 찾습니다. 검색하는 동안 결과가 바로바로 나타나며, 느린 네트워크 공유에서도 마찬가지입니다. 대소문자 무시, 대소문자 구분, 정규 표현식 중에서 고를 수 있습니다.

더 나은 화면, 그대로인 파일

E를 누르면 노출, 대비, 채도, 선명도가 자동으로 향상됩니다. 사진과 비디오 모두에 적용됩니다. A를 누르면 슬라이더가 열립니다. 바뀌는 것은 화면뿐, 파일은 그대로입니다.

파일의 진짜 정체

I를 누르면 포맷, 해상도, 코덱, 비트레이트, 비트 심도, 색상 프로파일, 카메라가 표시되고, 파일 확장자가 내용과 맞지 않으면 알려 줍니다.

모든 키를 한눈에

F1은 모든 키를 보여 주며 인쇄도 할 수 있습니다. K는 클릭해서 쓰는 작은 키보드를 띄웁니다. 격자 또는 목록(L), 이름, 종류, 날짜, 크기로 정렬, 여러 윈도우, 그리고 보스 키(X)까지.

다른 사람이 보낸 파일도 안전하게

모르는 사람이 보낸 사진, 비디오, 아카이브를 보는 것이 바로 뷰어가 하는 일입니다. 그래서 Schnellbild는 처음부터 모든 파일을 위험한 것으로 취급합니다.

  • Apple의 App Sandbox에서 실행. 네트워크에 전혀 접속하지 않고 스스로 다른 프로그램을 실행하지도 않으며, 사용자가 열어 준 폴더와 사진, 동영상, 다운로드 폴더에만 접근합니다.
  • 읽기만 합니다. 보는 것만으로 파일이 바뀌거나 디스크에 풀리는 일은 없습니다.
  • 비디오가 인터넷에 접속하지 않습니다. 알고 보니 인터넷을 가리키는 재생 목록인 '비디오'는 아무것도 재생하지 않습니다.
  • 이중 클릭으로는 문서만 열립니다. 프로그램은 열리지 않습니다. 앱, 스크립트, 설치 프로그램은 이미지 이름 뒤에 숨어 있어도 절대 열리지 않습니다.
  • 서명과 공증 완료, Apple의 Hardened Runtime 적용.

구체적으로 무엇을 하는지, 그리고 한계는 어디인지: 다른 사람이 보낸 파일도 안전하게.

Phiewer, IINA, Norton Commander를 쓰다가 오셨나요?

모두 본보기가 된 앱입니다. 키보드로 사진을 넘겨 보는 Phiewer, 비디오를 빠르게 다루는 IINA, 이중 패널의 Norton Commander. Schnellbild와 비교해 보세요: 무료 Phiewer 대안, 비디오를 훑어보기 위한 무료 IINA 대안.
